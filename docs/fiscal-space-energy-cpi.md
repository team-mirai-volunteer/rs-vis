# エネルギーCPIの政策効果調整（参考）

最新データ版のエネルギーCPI 0.6%（2026年7月・前年同月比）に、政策効果を除く参考推計約3.4%を併記する。出典は[総務省の全国CPI 2026年7月分](https://www.stat.go.jp/data/cpi/sokuhou/tsuki/pdf/zenkoku.pdf)（2026年8月21日公表、9月15日確認）。

公表の政策寄与度には補助金とガソリン暫定税率廃止が合算されており、「補助金だけを除いたCPI」とは呼ばない。補助金のみの値は未分離であることを数値の直下に表示する。

## 計算

総合CPI前年比への寄与度（3頁）は当月−0.35%、前年剥落＋0.13%。エネルギー自身の変化率ではないため、総合の前年指数100.1（1頁）とエネルギーのウエイト749/10000（3頁）で指数差へ換算する。当月エネルギー指数102.2（7頁）と前年比0.6%から前年エネルギー指数を逆算する。表の数値は丸め済みなので結果も参考の近似である。

`Eprev = 102.2 / 1.006`

`EcurrentAdjusted = 102.2 + 0.0035 × 100.1 / 0.0749`

`EpreviousAdjusted = Eprev + 0.0013 × 100.1 / 0.0749`

`adjustedRate = EcurrentAdjusted / EpreviousAdjusted − 1 ≈ 3.4%`

前年剥落の寄与は前年の値下げが今年の前年比を押し上げる側に出たもの。前年の指数にも値下げ分を戻す必要がある。当月だけに調整額を足して前年比と呼ぶことや、総合CPI寄与−0.22%をエネルギー前年比0.6%から直接引くことはしない。

調整後の水準比較は実際の補助廃止時の価格転嫁・需要・為替・事業者行動を推定しない。本体の初期CPI・物価閾値・政策乗数は変更しない。

2024年平均は補助の影響があった月が異なり、前年2023年にも補助がある。同じ対象範囲の両年の調整済指数を取得できていないため未推計とする。2024年の電気・ガスだけの当月分寄与度を、燃料油も含む年平均へ流用しない。
