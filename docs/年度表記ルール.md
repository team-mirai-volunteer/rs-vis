# 年度表記ルール

画面に出す年・年度の書き方。新しい画面や文言を足すときもこれに合わせる。

## 基本

| 対象 | 書き方 | 例 |
|------|--------|----|
| 会計年度（4月〜翌3月）のデータ | `YYYY年度` | 2024年度 |
| 暦年（1〜12月）の統計 | `YYYY年`。出典の期間どおりに書き、年度に読み替えない | 家計調査2024年、OECD Taxing Wages 2025 |
| 資料の版 | `YYYY年版＋資料名`。「年版」単独や「シートYYYY」は使わない | 2025年版レビューシート |

## データの種類別

| データ | 主表示 | 補足（版・基準） |
|--------|--------|------------------|
| 行政事業レビュー（RS）の執行 | `YYYY年度実績` | `（YYYY+1年版レビューシート）` |
| RS の翌年度要求額 | `YYYY年度要求` | `（YYYY-1年版レビューシート）` |
| 財務省予算書 | `YYYY年度当初予算`・`YYYY年度補正後予算`・`YYYY年度決算` | — |
| AI評価 | `AI評価の対象：YYYY年度実績` | `（YYYY+1年版レビューシート）` |
| 税・社会保険の制度モデル | `YYYY年の制度に基づく試算` | — |
| 基金 | `YYYY年度実績` | `（YYYY+1年版基金シート）` |

- RS の年度変換は `app/lib/rs-fiscal-year.ts` を通す（`fiscalYearLabel` = 主表示、`rsSheetLabel` = 補足）。シート年度を画面に直接書かない。
- 当初予算と決算・実績のように基準が違う金額を一つの図に並べるときは、列見出しなど図の近くに基準を書く（説明パネルだけに置かない）。
- サンキー図の列見出しの `事業_2024` 形式は、列名＋年度の短縮表記として例外的に使ってよい。測定量（当初予算・支出額など）を必ず添える。
