# 政策レビューへの対応：接続条件と限界

生産供給と物価の現行接続（モデル2026-09-15.5）は [生産関数と政策供給の接続](fiscal-space-production-model.md) を参照。公表物価の一致検証では、以下の初期ギャップ条件に加えて稼働率価格補正を0にする。

## 短期の基準と追加感度

参照：[内閣府・経済財政モデル2026年度版の概要・乗数](https://www5.cao.go.jp/keizai3/econome/ef2rrrrrr-summary.pdf)、主要乗数表の説明と実験①〜⑤（2026-09-15確認）。公表表はGDPギャップがゼロで推移する標準ケースとの差であり、任意の経済状態に対する政策効果の推定ではない。

- 初期ギャップを `g` とし、GDP反応には `exp(-a*g)`、税直接効果を除いたCPI・デフレーター水準反応には `exp(b*g)` を掛ける。指数は−1〜1で制限。初期感度は `a=3, b=5`。これらは未推定のシナリオ係数。
- 政策なしの実質GDP／潜在GDPの経路から計算したギャップ×0.05を基準インフレに加える。既存のインフレ持続率も残す。政策が作ったギャップに対するフィリップス曲線を再加算しない。
- 投資による潜在供給増加を、この感度経由で新たな需要へ変換しない。感度の基準は初期ギャップ。ギャップゼロでは公表反応が再現され、感度をすべて0にすると旧来の線形適用になる。
- 参照表の支出額の実質化は従来の標準物価経路に固定。独自のギャップ補正で原モデルの金融政策・全ての一般均衡反応を再推定したことにはならない。

## 金利から借換へ

表①の1年限り政府支出と、表②〜④の継続政府支出・法人税・所得税（増税の符号反転）の長期金利列を使用する。表⑤も専用の長期金利反応を使用。GDP・物価と同じ名目年額・期間の畳み込みで比率へ換算する。金利列の単位は水準変化率ではなく「%ポイント」。GDP比1%の継続政府支出・固定物価の検算では、5年目は+0.57ポイント。

借換・新発金利＝基準借換金利＋公表政策反応＋外生借換ショック（下限0）。既発債のクーポンは固定し、満期分と新発分にだけ当年の金利を適用する。公表GDPに含まれる金融引締めを再加算しない。基準金利・外生借換ショックの変更は財政感度であり、別の金融政策によるGDP・CPI効果は未推計。2022年モデルの金利列は未接続と記録する。

## 消費税の価格効果

2026年は表⑤の「税率1ポイント増」を符号反転する。年額÷1ポイント当たり減収額で税率ポイントに換算し、標準価格の上昇に応じて一定名目年額に対応するポイント幅を調整する。2022年は所得税の需要反応を代理に使う。

初期の換算は1ポイント3.5兆円、対象CPI比率85%、代表税率10%、価格転嫁100%。税率の混在を一つの代表税率へ近似する仮定で、公表値ではない。対象品目を絞るときは対象比率・減収額・税率を併せて変更する必要がある。

表⑤からCPI0.78%、デフレーター0.50%／税率ポイントの直接効果を分離する仮定を置く。残差にのみギャップ感度を適用し、CPIの直接値下がり `税率引下げ幅/(1+税率)×対象比率×転嫁率` に置換。原表の価格変化に同じ直接効果を重ねない。終了時には直接効果が消失するため、前年比の総合CPIに復税の反動が出る。総合CPIと税直接効果を除いたCPIの両方を同じ上限で判定する。分離後の系列は公的な税調整済みCPIではない。

代表税率がゼロになる額が入力・探索の上限。追加1兆円がこの範囲を超える場合、その政策の追加比較行を除外する。価格転嫁率変更に応じた所得・消費反応の再推定は行わない。

## 産業・電力負荷

係数がない政策は「未評価」。計算済みの初期能力だけを「設定内」と表示しない。既知部分で上限を超える場合は違反を表示する。参考上限の探索は既知の制約についてのみ行うため、未評価を含む参考値である旨を明示する。

任意の `Policy.load` に以下の原単位を入力できる。

| 原単位 | 接続先 |
| --- | --- |
| 支出1兆円当たりの産業稼働率増分 | 対象産業の当年稼働率 |
| 支出1兆円当たり当年ピーク負荷（GW） | 支出年のピーク電力 |
| 投資1兆円当たり稼働後ピーク負荷（GW） | 稼働後の各投資世代の残存負荷 |
| 稼働遅延・稼働期間・減耗 | 支出終了後の稼働負荷の存続と失効 |

金額は初期実質価格へ換算。値は利用者が置く仮定で、ゼロを設定しても実証的なゼロにはならない。全国産業連関表の係数を自動取得したものではなく、他産業への波及と年間電力量・輸入燃料費の換算は未接続。半導体などのピーク負荷の感度は比較できるが、全電力消費の評価が完了するわけではない。

## 生産モデルと長期シナリオ

全期間をレオンチェフ・CES・コブ＝ダグラスのいずれかに固定し、時間だけによる切替を廃止。各モデルで同じ配分の参考上限を並べる。投入指数とCPI上限を同じ感度パネルで変更できる。コブ＝ダグラスは既存の中間財を含まない定式化を維持しており、モデル間の差には投入範囲の違いも含む。

短期評価は公表期間内。長期は別関数 `longRunScenario` で30年まで表示する。公表期間末の政策あり／なしの財政状態を起点とし、短期末のGDP・価格差は5年で解消、別途設定した供給便益へ移行する。公表乗数の末尾は延長しない。

長期初期条件は実質成長1%、基準物価2%、借換金利3%、便益実現50%。各条件は変更可能で、供給側の純追加性とは別の実現率である。投資世代の稼働・耐用年数・減耗、恒久政策の毎年の費用、満期借換を計算する。供給便益は年0価格、政策費用・利払いは当年価格。長期の金融政策効果・産業制約・CPI予測・財政上限は推計しない。

## 検証

`npm run test:fiscal-space`：既存会計・輸入・投資検証とレビュー再現テスト。

`node tests/fiscal-space-review-browser.mjs`：ローカル3108番ポートで入力位置、ギャップ変更、未評価表示、税率の入力限界、モデル変更、長期金利感度、モバイル幅を検証。
