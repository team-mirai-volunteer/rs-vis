# 現金給付・減税と相対的貧困率（2026-09-21）

2024年所得分布に設定した政策年額を適用する、静的な直接効果の条件付き試算。再分配後の相対的貧困率と17歳以下の子どもの貧困率を併記する。将来の貧困率予測、因果推定、政策の総合評価ではない。現物サービスは対象外。

## 公表値と取得

厚生労働省2025年国民生活基礎調査（所得は2024年）の統計表1・3・7、概況表11を利用。

- 統計表： https://www.mhlw.go.jp/toukei/saikin/hw/k-tyosa/k-tyosa25/xlsx/12.xlsx
- 概況表： https://www.mhlw.go.jp/toukei/saikin/hw/k-tyosa/k-tyosa25/xlsx/09.xlsx
- 相対的貧困率15.0%、子ども11.0%、中央値277万円、公表貧困線138万円。
- 全体と子どもの等価可処分所得21階級の相対度数分布を取得。世帯・子ども人数の分母は世帯数×平均人数の近似。所得不詳を除く分布と世帯票の母集団の差がある。
- JSONは `app/lib/fiscal-space/data/poverty-income-2024.json`。原本は `tests/fixtures/fiscal-poverty/`、URL・取得日・SHA-256はJSONの `files`。再生成：`python scripts/generate-fiscal-poverty-data.py`（openpyxl）。

## 分布・家族・税負担の近似

1. 公表階級内を一様とする。公表の中央値と貧困線の丸めの不一致は、中央値277万円の半分138.5万円をモデル上の貧困線とすることで扱う。
2. 全体分布を貧困線未満15%、貧困線〜中央値35%、中央値以上50%に校正。子どもは貧困線未満11%、それ以上89%に校正。生の公表階級値はJSONに残す。
3. 子どもの分布を家族世帯へ割り当て、その世帯員を全体分布から控除して子なし世帯の分布を作る。世帯構成と所得の同時分布を観測したものではない。
4. 中心：大人2人・子2人、子なし2人。子なしの40%を年金所得型、残りを給与所得型。給与所得型の夫婦は67:33の収入配分。家族構成は所得階級を通じて固定する仮定。
5. 比較ケース：子1人・子なし単身・年金型30%・片働き・最上位上端1,500万円、および子2人・子なし2人・年金型50%・片働き・最上位上端3,000万円。中心の最上位上端は2,000万円。3ケースの最小〜最大は信頼区間でも不確実性の全範囲でもない。
6. 各区間を20分割し、中央値から代表世帯の可処分所得を求める。既存2025年度税計算（`computeHousehold`、検証未完了の試作パラメータ）を逆算して所得税・住民税所得割・本人保険料の負担プロファイルを近似。住民税の均等割・森林環境税は除く。
7. プロファイルの加重合計を既存の2024年度税目別収入総額に校正。これは観測税額でも個人への法定税額計算でもない。政策なしの所得には統計上の既存給付が含まれ、代表世帯の給付で置換しない。生活保護世帯等の非課税・保険適用除外、ひとり親の実際の構成は再現できない。

## 政策と収支

- 現金給付：全国民（一般世帯人口で近似）、政策なしの貧困線未満、子ども1人当たりの3方式。受給率100%、予算全額配分、対象判定は政策なしで固定。申請漏れや支給事務費は未計上。
- 子育て：入力予算×現金給付割合を子ども1人当たり配分。初期値100%を画面で明示。残りの現物部分の効果は未推計。
- 所得税・住民税：税額比例減税。入力額÷税目別公表収入を減税率として、校正済み負担に適用する。仮定上の非課税者には配分せず、100%を超える還付は行わない。所得控除や還付付き税額控除とは別の政策。
- 社会保険料：予算×既存の本人軽減割合を本人負担に比例配分。事業主分は家計へ直接加算しない。
- 合計追加所得 `Σ(世帯重み×追加手取り)` は反映対象予算と一致する。全国税収の上限を超えた場合は加算を打ち切る（通常の画面入力は既存の政策上限内）。
- 消費税は所得ベースの相対的貧困率に直接加算しない。購買力への別効果は初版未推計。医療・保育等の現物、投資、雇用、賃金、物価への波及も対象外。
- 保険料控除縮小に伴う所得税増、各種給付の減額・所得制限との相互作用は未反映。税額分布の近似と合わせ、減税効果を厳密な純効果と扱わない。

## 貧困率の再計算と表示

追加手取りを世帯人数の平方根で割って各区間を移動。区間の重なりを含む人数加重CDFから政策後の中央値を求め、その半分未満の人数を数える。全体は人ベース、子どもは子どもの人数ベース。固定貧困線版も併記する。

各適用年に有効な政策だけを反映。一時給付の終了後は直接効果がなくなり、貯蓄や出生への累積は行わない。価格・人口・賃金・所得分布を2024年の水準に固定し、予算をそのまま適用する（将来年の名目予算を現在価値へ換算する機能ではない）。両データプリセットで同じ分布。低位・中位出生の経路にも未接続。

貧困率の配分設定は財政予算や既存のマクロ乗数を変更しない。政策対象による消費性向の差を接続するには別の校正が必要。画面は政策総額と反映額、対象外の経路、実績と試算、条件幅を明示する。
