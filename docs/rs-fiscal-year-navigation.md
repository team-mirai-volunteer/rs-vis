# 実績年度とレビューシート年度

2026-09-24以降、評価一覧・委託構造・バブルチャートの年度選択は実績年度を表示する。サンキーの支出列と同じ年度を追えるようにするため。

サンキーの初期表示は2024年度・決算。決算の金額は執行額であり、予算総額ではない。基準未指定時は決算を優先し、決算未収録年度は当初予算を使う。共有URLには `b=settlement` / `b=initial` 等を常に保存し、明示された基準を再読込時にも保つ。

2025年度の執行・支出先は、RS公開APIからの[暫定取得](rs-api-provisional.md)をサンキーに追加した。`?year=2025&b=initial&view=provisional` で表示し、右側で「統合（暫定）」を選ぶ。左側のMOF基準は `b` に独立して保持する。旧 `b=execution` は当初予算＋統合（暫定）へ読み替える。既存の「2026年度要求」や2025年度シートの評価・委託構造とは別のデータとして扱う。

| 画面・新しいURLの fiscalYear | データ取得APIの year / RSシート年度 |
| --- | --- |
| 2023 | 2024 |
| 2024 | 2025 |
| 2026（要求、評価一覧のみ） | 2026（要求額への変換、元シートは2025） |

2026年度要求は実績とみなさず「要求」と表示する。未収録年度の支出を作らない。

既存の `?year=2025`（評価・委託構造）、`?yr=2025`（バブル）は、従来どおり2025年度レビューシートを選ぶ。新しい画面間リンクと共有URLは `?fiscalYear=2024` を使う。両方指定された場合は対応する `fiscalYear` を優先する。APIのパラメータは変更しない。

上部ナビゲーションも、移動先に同じ年度がある場合は引き継ぐ。移動先に未収録の年度はそのビューの既定年度となる。年度変換は `app/lib/rs-fiscal-year.ts` に集約している。

# ブロック数

名前の種類数ではなく、ブロック番号の種類数を数える。5-1の番号と5-2の番号を合わせ、同名でも別番号なら別ブロックとする。

既存のAI採点を保ったままブロック数だけ委託構造データに同期する場合:

```sh
node --import tsx scripts/sync-quality-block-counts.ts
```

このコマンドは公開 `.json.gz` を読み、スコアデータの `blockCount` のみを更新して `.json` と `.json.gz` を出力する。2024シート797件、2025シート744件を修正した。その他のフィールドは変更前との一致を確認済み。

# スマホ詳細と再委託元

- 共通詳細パネルを72dvhに広げ、画面のヘッダーを避けた拡大・縮小ボタンを追加。
- サンキーでは支出先タブを初期表示し、タブを折り返して表示。概要・評価は開閉可能。
- 委託構造では上部概要をスクロールさせても内訳タブを固定。
- バブル詳細も概要・評価を開閉可能にし、詳細を表示するときは検索フォームを畳める。
- 再委託ブロックの一覧・詳細に委託元の番号と名前を表示。合流時は全委託元を表示し、参考線は含めない。ブロック図にも委託元を併記。
- 列見出しの位置は変更しない。
