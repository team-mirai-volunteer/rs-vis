# 政策効果・政策価値・廃止判断スコア

## 原則

既存の「レビュー可能性」と、政策そのものの評価を分離する。

- レビュー可能性: 説明と検証材料がそろっているか
- 政策効果: 実際にアウトカムへ寄与したか
- 政策価値: 政府が資源を投じる公共的な価値があるか
- 廃止優先度: 継続以外の選択肢を優先的に検討すべきか

証拠が不足する場合、政策効果や廃止優先度を0点にしない。`判定不能` とする。

## 1. 政策効果スコア（0〜100）

| 軸 | 重み | 0点 | 4点 |
|---|---:|---|---|
| アウトカム達成 | 35% | 目標未達または悪化 | 重要な成果目標を達成 |
| 因果寄与・追加性 | 25% | 事業の寄与を確認できない | 比較対象等から寄与を確認 |
| 費用対効果 | 20% | 費用に見合う成果がない | 代替案より効率的 |
| 持続性・到達範囲 | 20% | 効果が一時的・対象へ未到達 | 効果が持続し対象へ十分到達 |

4軸がそろわない場合は、総合点を確定しない。

## 2. 政策価値スコア（0〜100）

各軸を最初に `適用 / 非適用 / 不明` に分類し、適用軸だけを同じ重みで平均する。

- 課題の重要性
- 政府関与の必要性
- 公平性・包摂性
- レジリエンス・外部性
- 戦略的・長期的価値
- 財政持続可能性

政策類型によって適用軸が異なる。年金を供給力で減点したり、研究開発を直接給付で減点したりしない。

## 3. 廃止優先度（0〜100）

高いほど「現状のまま継続」以外を優先的に検討する。

| 要素 | 重み |
|---|---:|
| 政策効果の低さ | 30% |
| 政策価値の低さ | 25% |
| よりよい代替手段の存在 | 15% |
| 他事業との重複 | 15% |
| 費用対効果の低さ | 10% |
| 陳腐化・終了条件の到来 | 5% |

### 計算ゲート

次をすべて満たす場合だけ廃止優先度を計算する。

- 証拠準備度が3以上
- 証拠信頼度が0.70以上
- 政策効果4軸がすべて採点済み
- 政策価値に1つ以上の適用軸がある
- 代替手段、重複、陳腐化を評価済み

法定給付や条約上の義務など法的拘束がある場合、`廃止候補` ではなく `制度見直し` とする。

## 4. 推奨アクション

| コード | 意味 |
|---|---|
| `EVIDENCE_REQUIRED` | 証拠不足のため判定不能 |
| `CONTINUE` | 継続 |
| `CONTINUE_WITH_IMPROVEMENT` | 改善条件付き継続 |
| `REDUCE_OR_RESTRUCTURE` | 縮減・統合・再設計 |
| `ABOLITION_CANDIDATE` | 廃止候補。必ず人間が裁定 |
| `REFORM_LEGAL_SCHEME` | 法制度を含む見直し |

AIの出力は意思決定ではなく、外部有識者・所管府省・政策対象者による検討の入力として扱う。
