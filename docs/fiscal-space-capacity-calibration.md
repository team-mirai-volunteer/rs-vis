# 最大GDPの参考校正

投入指数の直接設定に加え、2024年の統計から労働・設備の参考能力を作るモードを追加。既定・旧リンクは直接設定を維持し、モードと実現条件を共有URLへ保存する。参考校正を選ぶと初期投入指数を通じて、政策なし・政策あり・生産モデル比較・ストレス探索に反映する。

## 公表値（2026-09-21確認）

- 労働力調査2024年報 I-A-12、全産業・男女計：延週間就業時間23.72億時間（BU19）、平均36.3時間（AR19）。[原表](https://www.e-stat.go.jp/stat-search/file-download?statInfId=000040267840&fileKind=0)、2025-04-01公表。休業者等の分母差を避けるため、平均時間×就業者数ではなく公表総時間を分母に使う。
- 労働力調査2025年詳細集計6頁の2024年比較値：失業者195万人、潜在労働力人口33万人、追加就労希望就業者190万人。[資料](https://www.stat.go.jp/data/roudou/sokuhou/nen/dt/pdf/gaiyou.pdf)。失業者は1か月以内に求職した者で、基本集計の完全失業者とは異なる。潜在労働力人口は就業者・失業者を除く。追加就労希望者は就業者の内数。
- 製造工業稼働率の年平均原指数：2024年101.4、2022年108.1（2020年=100）。[2025年10月資料](https://www.meti.go.jp/statistics/tyo/iip/result/pdf/press/b2020_202510nj.pdf)の同一改定時点を採用。指数100は完全稼働を意味しない。2022年は参照水準として選んだ年で、歴史的最大値とは主張しない。

## 計算

労働余力比率 = 1 + (失業者×就業実現割合×新規週時間 + 潜在労働力人口×参加実現割合×新規週時間 + 追加就労希望者×週追加時間) / 延週間就業時間。

設備余力比率 = 1 + max(0,108.1/101.4−1)×回復割合×全産業への換算割合。

既定の参考条件は就業・参加実現割合各50%、新規週30時間、追加週5時間、設備回復100%、全産業換算20%。いずれも推定済みの係数ではない。全産業換算はGDP構成比や設備資本の実測ウエイトでもない。未観測の非製造業余力をゼロと置いた保守的な換算仮定であり、設備能力の上限ではない。

2つの余力比率に初期実質GDP/潜在GDPを掛け、既存モデルの潜在GDP基準の投入指数へ換算。エネルギー・中間財の指数は既存設定を維持。最大GDPは選択された生産関数で計算し、ギャップは(実質GDP−最大GDP)/最大GDP。これにより、参考校正の実測分母とモデルの基準が異なることによる過大・過小評価を避ける。

## 限界

両データセットで2024年の余力比率を使用する。最新月の労働・設備観測に更新した推計ではない。集計統計の接続近似であり、職種・地域・技能の適合、追加時間の分布、非製造業設備、エネルギー・中間財の全国供給上限は未校正。実現割合は摩擦等を考慮する感度設定であり、完全雇用や持続可能な最大能力を実証的に同定したものではない。

未活用人数は初期供給能力の校正だけに用い、将来の雇用者数や人口動態へ加算しない。就業者の追加時間と新規参加者を区別して二重計上を避ける。政策の供給係数・将来の価格補正は既存の仮定を継続する。
