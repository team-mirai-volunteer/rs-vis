# 賃上げ税制：交絡を分離するための分析仕様

2026-09-24作成。対象は2024年改正。分析設計の提案であり、企業データによる推定結果ではない。

追補：同日、公開有報から13社×3年の人数・平均給与を取得した。[予備調査結果](./wage-company-panel-results.md)、[取得経路](./wage-company-data-access.md)を参照。以下の「未取得」は法定適格性や控除額を接続した主分析用データについての状態。公開有報での予備分析は進められる。

## 結論と対象効果

第一候補は、従業員2,000人の境界における改正前後の差の比較（difference-in-discontinuities）。単純な利用企業と非利用企業の比較より自己選択を抑えられる。ただし、同時期の中堅企業支援の影響が重なる。現状は「設計候補」であり、「交絡を除去済み」ではない。

推定対象は、境界付近で中堅枠を利用できることによる、大企業枠に対する給与・雇用の相対的な変化。制度利用者への効果、税制全体の効果、廃止時の全国歳入増とは異なる。大企業側も改正されているため、無政策との比較にはならない。

## 制度差をどう使うか

[財務省の2024年改正資料（40–42ページ）](https://www.mof.go.jp/tax_policy/councils/zeicho/241119_2-1.pdf)と[経産省の2024年制度ガイド](https://www.meti.go.jp/policy/economy/jinzai/syotokukakudaisokushin/r6_chinagesokushinzeisei/r6chinagesokushinzeisei_gb_20250703.pdf)を基準とする。

| 継続雇用者給与の増加率 | 改正後の中堅枠・基本控除率 | 改正後の大企業枠・基本控除率 |
| --- | ---: | ---: |
| 3%以上4%未満 | 10% | 10% |
| 4%以上5%未満 | 25% | 15% |
| 5%以上7%未満 | 25% | 20% |
| 7%以上 | 25% | 25% |

これは控除対象給与増加額に対する率で、法人税額に対する減税率ではない。上乗せ・上限は別。境界で一律10ポイントの差が生じるわけでもない。実現した4%以上の賃上げ企業に限定して推定すると、政策によって変わる結果で標本を選ぶことになるため行わない。

企業の事業年度開始日に基づいて2024年4月1日以後の改正適用を判定する。暦年・決算終了年だけで前後を割り当てない。中堅枠の2,000人以下の人数要件に加え、当該企業が50%超を保有する企業と合わせて10,000人超となる除外条件等を確認する。中小企業向け制度も選べる企業を主分析から外す際は、資本金だけでなく法定区分を再現する。

中堅枠・大企業枠を「利用した企業」ではなく、制度を利用できる企業を比較する。法定の人数定義、判定日、マルチステークホルダー方針の届出等も制度対応表に含める。人数だけでは正確な適格性を再現できない場合は、鋭い境界による推定を実施しない。

## 推定仕様と中止条件

1. **観測単位と期間**：法人×事業年度。まず2019–2023年開始年度を改正前、2024年4月以後の最初の対象年度を改正後の候補とする。改正予告による先取り、コロナ期、決算期変更を別途点検する。後年の追加改正は混ぜず、制度履歴を確認して観測窓を確定する。
2. **主分析**：各期の法定従業員数を用い、境界の左右で局所線形回帰を推定。「改正後の境界での給与差 − 改正前の境界での給与差」を求める。人数は離散値として扱い、同じ法人の誤差相関を考慮する。帯域は改正後の効果を見て選ばず、事前分布・標本数に基づいて確定し、複数帯域の感度を報告する。
3. **主な結果指標**：企業の給与総額の変化。併せて継続雇用者給与、一人当たり給与、雇用者数を報告し、採用増と既存社員の賃上げを分ける。物価調整した値と名目値を区別する。事業再編で法人の範囲が変わる観測は接続方法を記録する。
4. **必要仮定**：政策がなければ境界での給与差が期間を通じて安定し、構成の不連続な変化や同じ境界での別政策の変化がないこと。単に企業固定効果と年度固定効果を入れても、この仮定は満たせない。
5. **検証**：改正前の境界差の推移、偽の改正時点・境界、人数の集中、企業属性の連続性、出入り・分割を確認する。検出力が弱い「有意差なし」を仮定の証明としない。重大な構成変化や異なる事前推移が残れば、税制単独の因果推定を中止する。
6. **副分析**：改正前の人数で企業群を固定した近傍企業の差の差。改正後の人数調整に影響されにくい一方、実際の適格性とずれるため、これは局所的な企業群比較であり、法定境界の回帰不連続と呼ばない。両者の結果が違えば理由を調べる。

方法の参考：[Difference-in-Discontinuities: Estimation, Inference and Validity Tests](https://arxiv.org/abs/2405.18531)。この方法が除けるのは安定した既存の境界差であり、新たに同じ境界で導入された政策差ではない。

## 最も大きい交絡：中堅企業向けの同時施策

経産省は[中堅企業政策](https://www.meti.go.jp/policy/economy/chuuken/index.html)として設備投資・M&A等の支援を掲載している。[2024年度税制改正資料](https://www.meti.go.jp/main/zeisei/zeisei_fy2024/zeisei_k/pdf/zeiseikaisei.pdf)には地域未来投資促進税制の中堅企業枠があり、[2024年9月施行の説明](https://www.meti.go.jp/press/2024/09/20240902001/20240902001.html)には事業再編支援がある。賃上げ以外の施策も投資・給与を変え得る。

分析前に、各制度の施行日、人数の定義、資本・所有要件、地域・業種、計画認定、給与への経路を一覧化する。中堅の呼称だけで全制度の対象が一致すると仮定しない。

分離の優先順位は以下とする。

- 改正前に決まる地域・業種等により、他の同時施策の対象外である部分集団を法令上特定できれば、その範囲の比較を候補とする。標本数と左右の比較可能性も必要。
- 他施策だけを別途識別できる適格性・開始時期の差があれば追加設計を作る。年次決算では施行月のずれだけで分離できると見なさない。
- 両方とも成立しなければ、結果は「境界付近の中堅向け支援パッケージの相対効果」に限定する。賃上げ税制単独の評価点の根拠にしない。

実際の補助金受給者を事後に除く、現在の黒字企業だけを選ぶ、現在の投資額や賃上げ率を統制する、という操作では解決しない。いずれも政策によって変わる変数で選別・調整する危険がある。改正前の利益・属性による層別は感度分析に使えるが、それだけで別政策を分離できたとはしない。

## 最小データ仕様と入手の判定

| 必要項目 | 用途 | 現在の状態 |
| --- | --- | --- |
| 匿名の法人固定ID、年度開始・終了日 | 年次接続と制度適用日の割当 | 未取得 |
| 法定人数・判定日、通常の平均雇用人数 | 適格性と雇用結果を区別 | 定義の対応を要確認 |
| 株式保有関係、関係法人の人数、中小企業区分 | 2,000人以外の要件を再現 | 未取得 |
| 総給与、継続雇用者給与と比較給与 | 給与効果、適格性の点検 | 接続可能性を要確認 |
| 控除対象額・実際の控除額・税額上限等 | 同じ対象群の財政費用 | 未取得 |
| 改正前の業種・地域・資本・利益、合併分割 | 比較可能性、標本の接続 | 未取得 |
| 同時施策の事前適格性、認定・受給履歴 | 政策の重なりの点検 | 未取得。受給は群選択に使わない |

法人企業統計の給与・従業員項目があっても、税法上の継続雇用者給与や法定人数と同じとは限らない。異なる統計と税務情報を法人単位で自由に結合できるとも仮定しない。

[財務省の案内](https://www.mof.go.jp/statistics/ordermade.htm)には、条件付きの調査票情報提供と、有料のオーダーメード集計がある。後者の掲載サービスはクロス集計で、企業パネルや任意の回帰推定を依頼できると確認したものではない。受付は4月・10月、事前相談が必要。匿名データ提供は実施していない。

[国税庁の第6期共同研究公募](https://www.nta.go.jp/about/organization/ntc/kyodokenkyu/koubo/index.htm)は2026年4月30日に終了。掲載された法人税テーマの控除明細は研究開発税制であり、賃上げ税制の明細が利用可能と読むことはできない。次回公募や追加項目の提供は未確認。

したがって、現時点では公開データのみで上記推定を実行できない。疑似データや集計値で穴を埋めて因果効果を出さない。

相談前に研究主体・利用資格・費用負担を確定する必要がある。現時点で申請や連絡はしていない。

## 実行順と評価への反映

| 順序 | 完了条件 | 満たせない場合 |
| --- | --- | --- |
| 1. 制度照合 | 適格性を再現し、同時施策の差を列挙 | 税制単独の識別を保留 |
| 2. データ実現性 | 利用承認・項目定義・年次接続を確認 | 推定を開始しない |
| 3. 検出力と仕様確定 | 改正前分散・企業数から最小検出効果を計算し、帯域・除外規則・指標を固定 | データ追加または実行見送り |
| 4. 推定・反証 | 構成変化、事前推移、同時施策の検証を通過 | 記述分析または支援パッケージの結果に限定 |
| 5. 費用対効果 | 同じ対象群・期間の追加給与と控除額、信頼区間を提示 | 判定保留を維持 |

費用対効果の分母は「政策が追加的に増やした給与」であり、適用企業の給与増加額全体ではない。効果の区間がゼロをまたぐ場合、単一の費用対効果比を出さない。境界付近の推定値に全国の控除額を組み合わせない。給与移転額と社会的便益も同一視しない。

分析計画の作成では検証可能性を加点しない。賃上げ税制の現行評価（必要性2、効果1、費用対効果は判定保留、公平性2、検証可能性2）を維持する。削減可能額への追加計上は0円。これは削減余地がゼロという推定ではなく、今回の設計から金額を裏付けられていないという意味である。
