確認日：2026-09-24。

拡張済み：13社×3年＝39観測を取得し、[比較結果](./wage-company-panel-results.md)と[全観測CSV](./wage-company-panel.csv)を追加した。以下の2社は初回の取得確認。アプリの賃上げ税制の評価欄には、全標本の比較表と人数による絞り込みを実装した。

## 取得できたもの

企業データは取得できる。前の分析仕様の「必要な企業データは未取得」は、税法上の適格性と給与・控除を接続した分析用データを指す。企業別の公開情報まで入手不能という意味ではない。

## 原資料で見つかった注意点

- ダイヘンの2025年3月期は、連結4,606人に対して単体1,203人。ホーチキは連結2,383人に対して単体1,573人。連結人数で2,000人境界を判定すると単体と分類が逆になる。単体人数についても税法上の人数との対応確認が必要。
- ダイヘンの就業人員には出向受入社員を含む。給与には賞与・基準外賃金・前払いの退職金を含む。ホーチキは顧問・嘱託・臨時従業員の年間平均人数を外数で記載しているため、今回の人数に合算していない。
- 平均年間給与×期末従業員数を給与総額や継続雇用者給与と見なさない。対象者・期間・人員構成が異なり得る。平均給与の変化も同じ社員の昇給率ではない。
- ダイヘン2024年3月期には訂正報告書があるため併せて取得した。訂正事項のページを画像で確認し、連結財務諸表注記の担保資産・保証付債務に関する訂正で、今回の従業員表の訂正ではないことを確認した。
- 税額控除が注記される場合でも、研究開発等との合算や税率差異の説明の場合がある。今回のCSVでは賃上げ税制の実額を認定していない。

## 拡張する経路

| 経路 | 取れる範囲・役割 | 制約 |
| --- | --- | --- |
| 企業公式IRの有報 | 今回取得済み。複数年の給与・人数等を集め、候補企業を調査できる | PDF抽出、単位・注記・訂正の確認が必要。上場企業等に偏る |
| EDINET API | 書類を広く収集しXBRL等の構造化情報を利用する入口 | 登録・APIキー発行が必要。今回キーを取得・使用していない |
| 法人企業統計の調査票情報等 | 非上場を含む給与・経営情報の候補 | 利用条件、項目定義、年次接続、他データとの結合は要確認 |
| 企業活動基本調査 | 企業の従業者・給与・経営情報を調べる追加候補 | 公開の集計表と非公開の個票は別。今回個票は取得していない |
| 税務申告・控除明細 | 正確な税制利用・控除費用に必要 | 公開有報では網羅できない。個票への利用承認等が必要 |

EDINETの登録要件は[金融庁EDINETの案内](https://disclosure2.edinet-fsa.go.jp/WEEK0010.aspx)、統計の利用経路は[財務省の案内](https://www.mof.go.jp/statistics/ordermade.htm)を参照。企業活動基本調査の項目は[2025年調査票](https://www.meti.go.jp/statistics/tyo/kikatu/gaiyo/minkan/pdf/2025_chousahyo.pdf)で確認できるが、調査票の公開は企業の回答データ公開を意味しない。

## 次の分析に進める範囲

公開有報だけでも、企業群を広げて単体人数の分布、年次接続率、給与・人数の欠測、2,000人付近の標本数、改正前の給与推移を調べられる。税務個票を待たずに行える予備分析である。

適格性を外生的に判定できれば、制度を利用できることの効果を推定する際に実際の控除利用額は必須ではない。ただし今回の有報人数だけでは適格性を確定できず、同時施策の交絡も残る。控除額がないことと、給与への効果が一切研究できないことを混同しない。費用対効果を金額で評価する段階では同じ対象群の控除額が必要になる。

先に公開有報による予備パネルを整備し、足りない適格性・控除情報を特定してから個票利用の相談に進む。分析計画の適格性確認・同時施策分離の条件は維持する。

`python scripts/extract-wage-company-panel.py`（PyMuPDFが必要）で原表を抽出し、全観測CSV・アプリ用JSON・ダウンロード用CSVを更新する。初回2社の `wage-company-pilot.csv` は確認記録として残す。抽出対象は今回確認した表構造に限定し、項目不足や複数候補の場合は推測せず停止する。
