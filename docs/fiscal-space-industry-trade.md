# 産業投資の輸入推定（2026-09-16）

半導体の一律仮定（輸出50%、国内置換50%、輸入原価25%）を、2020年全国産業連関表の電子デバイス部門321を用いた参考条件に更新した。新設工場の因果推定ではない。研究開発など別の産業には流用しない。

## 原資料と再現

[e-Stat：生産者価格評価表・108部門](https://www.e-stat.go.jp/stat-search/files?stat_infid=000040187026)。表の単位は10億円。取得したxlsxのSHA256、原数値、計算結果は `app/lib/fiscal-space/data/industry-trade-reference.json` に保存する。

`python scripts/generate-industry-trade-reference.py` で取得・再計算できる（numpy、openpyxlが必要）。第1引数で取得済みxlsxも指定可能。アプリ実行時のダウンロードはない。

数値の正本は上記 JSON（`exportShare`・`domesticReplacementShare`・`operatingImportShare`・`directOperatingImportShare`）。UI と出典表はこの JSON から整形して表示する。

| 入力 | 算出・位置づけ |
|---|---|
| 輸出比率 | 輸出÷国内生産。部門平均を新設工場に適用する仮定 |
| 国内販売の輸入置換 | 輸入（税抜）÷国内市場。市場＝国内生産−輸出＋輸入。輸入浸透率を置換率に代用する仮定 |
| 稼働時の輸入原価 | 直接輸入と国内仕入先を通じた輸入の合計。下記の比例配分推計 |

投入係数行列をA、各商品の税を含む輸入計/国内需要をmとし、国内投入行列をB=(I-diag(m))Aとする。L=(I-B)^(-1) の321列をL[321,321]で割り、電子デバイスの総生産1円を固定した国内供給網の生産ベクトルqを得る。最終需要1円当たりの係数を売上1円にそのまま適用しない。

海外支払は、関税・輸入品商品税を除く輸入/国内需要をcとして cAq を使用する。税を含むmは国内調達の配分に使うが、国内の税収を海外支払に含めない。集計・丸め等で輸入比率が1を超える部門は国内配分が負にならないようmを0〜1に制限する。家計の所得増による輸入はこの供給網計算には含めない。

## 不確実性と表示

2020年の電子デバイスは集積回路だけでなく他のデバイスも含み、技術世代、輸出先、輸入する品種、新設工場の調達先は識別できない。比例配分は実際の輸入品需要先を直接観測した係数ではない。国内販売が既存国産品や新規需要に向かう可能性もある。国内置換率を政策効果の実証値と呼ばない。

稼働後の輸入を減らす置換率の境界は輸入原価/(1−輸出比率)（`industryImportBreakEven`）。建設や所得効果を含む総輸入の境界ではない。初期条件でも総輸入減は保証されない。

主表に産業投資の輸入内訳（稼働時輸入−国内代替＋その他）を追加。同じ価格時点で換算し、合計を本体の名目輸入差分に一致させる。既存政策への波及を含む差分である。追加投資の置換率だけを0%・100%に変え、本体を再計算した結果を併記する。信頼区間やあらゆる不確実性を含む上下限ではない。

建設調達と所得等の波及には引き続き一般政府支出の代理反応が残る。検証できる代替係数がないまま、その輸入反応をゼロにしたり国産化の便益に合わせて減らしたりしない。「その他」を直接の設備輸入と表示しない。建設費の輸入割合は2026-09-24.1から以下の全国投資平均を仮置きし、利用者が変更・空欄化できる。

モデル版は2026-09-16.3。旧共有URLの利用者設定を新しい係数で上書きしない。


## 2026-09-24.1：未設定の事業条件の仮置き

`project-import-reference.json` は同じ2020年産業連関表の公的・民間固定資本形成を合算し、負の純処分額を除いて正規化した品目構成 f を使う。直接輸入 cf と、国内調達の供給網輸入 cAL(I-diag(m))f の合計は17.6161%（直接9.3143%、供給網8.3018%）。`python scripts/generate-project-import-reference.py [xlsx]` で再現できる。半導体・研究開発・太陽光・原子力・水力に共通の代理初期値として使う。全国平均であり、設備比率や調達先が異なる事業別の測定値ではない。既存のマクロ輸入反応に足すのではなく、既存の建設輸入補正経路へ渡す。

研究開発はRIETIの収益率30%を参考にした既存の供給条件に合わせ、年間売上/投資額を0.3÷(0.5＋0.5×0.5−0.25)＝0.6で逆算する。輸出50%、国内販売の輸入置換50%、運転時輸入25%は比較用仮定。純追加性50%、減耗15%、稼働遅れ3年、寿命20年を適用する。純対外寄与を旧供給係数に合わせたシナリオであり、収益率を観測売上や因果的GDP効果と同一視しない。事業経路へ切り替わるため、旧知識蓄積のTFP経路とは実現時期・生産関数への反映が異なり、GDPの結果は一致しない。両経路は加算されない。

旧共有URLの数値・明示的なnullは維持する。新規シナリオと未保存項目のみ新しい初期値を使う。空欄化すれば従来通り未推計になり、研究開発の売上を空欄にすれば知識蓄積経路へ戻る。
