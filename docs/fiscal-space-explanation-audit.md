# 説明と実装の照合（2026-09-22）

画面の現行説明と現行仕様書を対象に修正。計算式・係数・既定値は変更していない。過去の検証結果や当時の設計案は、現行仕様と区別して残す。

| 対象 | 修正 | 照合した実装 |
| --- | --- | --- |
| 人口動態 | 「未実装・人口一定」を削除。含める／含めない設定で説明を分岐し、実際の政策なし終端値と歳出連動割合を表示 | `demographics.ts`、`simulate.ts` |
| 借換・高齢化 | 一律の「評価していない」を削除。選択期間の借換・人口連動を説明し、その先の長期シナリオと区別 | `simulate.ts`、`long-run.ts` |
| 債務満期 | 全債務10年均等という旧説明を、普通国債の公表償還年次表＋残差10年配分に修正。説明を共通化 | `debt-portfolio.ts` |
| 財政比率 | latestでも分子・分母が2024年という誤記を、IMF2026年比率×最新GDPの橋渡し推計に修正 | `japan-data.ts` |
| 基準利払い | 出典説明に常に既定データを表示していた箇所を、選択した初期状態の支払・受取利子に変更 | `fiscal-space-engine.ts`の`initial` |
| ストレス | 廃止済みのCPI上限引下げを削除。選択候補は実装の`STRESSES`から表示 | `stress-envelope.ts` |
| 貧困率・資源制約 | 所得階級別の直接効果近似と人員負荷概算の実装範囲を明記。賃金等の波及・制度間相互作用・詳細な設備制約は未評価と区別 | `poverty.ts`、`constraints.ts` |
| 評価期間・生産能力 | 冒頭に15年延長の扱いを追加。仕様書に統計からの参考校正を反映 | `fiscal-space-engine.ts`、`capacity-calibration.ts` |

残す未実装・未評価表記：貧困率と将来の賃金・物価・出生の接続、M1〜M3の政策後経路、外生金利変更による追加のGDP反応、施工能力超過時の投資延期、職種・地域・設備別の詳細制約。表示を改善しても、これらが実装されたことにはならない。
