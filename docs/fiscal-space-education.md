# 教育の追加支出：先進国の因果研究からの校正（2026-09-24.4）

日本の既存教育への追加支出を評価する。世界平均の「追加就学1年→個人賃金9%」を予算の限界効果へ置き換えず、追加支出→学力→就労世代→生産性と接続する。新規シナリオは正の中心条件を持つ。日本の因果推定ではなく、出典を持つ数値と移転仮定を組み合わせた比較モデルである。

## 研究と換算の区別

- [Jackson・Mackevicius（2024）、AEJ: Applied Economics](https://www.aeaweb.org/articles?id=10.1257/app.20220279)（[著者公開の本文](https://kirabojackson.com/pdfs/jackson-mackevicius-2024-school-spending-policy.pdf)、pp.412–414）：米国K–12の学校支出の因果研究を統合。児童生徒1人につき年1,000ドル（2018年価格）を4年間追加した場合、学力の平均効果は0.0316標準偏差。4年間の合計1,000ドルではない。研究間の真の効果の標準偏差は約0.021。所得階層などで効果は異なり、米国内で高支出ほど効果が消えるとの明確な証拠は得られていない。
- [OECD WP1781（2023）](https://www.oecd.org/en/publications/quantifying-the-effect-of-policies-to-promote-educational-performance-on-macroeconomic-productivity_b00051cc-en.html) §2.3：持続的な全国平均PISA約8点改善→長期生産性約1%を参考にする。§4.1・表7の支出の国際比較で日本が中央値への引上げ対象外であることは、日本の追加支出の因果効果ゼロを意味しない。このマクロ換算自体にもモデル上の不確実性がある。
- [文科省・2024年度学校基本調査](https://www.mext.go.jp/content/20241213-mxt_chousa01-000037551_01.pdf)：小学校約594万人・中学校約314万人。義務教育学校や特別支援学校等の該当学年も含む対象規模を約930万人と丸める。固定対象人口の近似であり、将来の少子化の予測ではない。
- 世界銀行WDI（2026-09-24取得）：[2018年日本GDP購買力平価](https://api.worldbank.org/v2/country/JPN/indicator/PA.NUS.PPP?date=2018&format=json)は104.158636円／国際ドル。[日本GDPデフレーター](https://api.worldbank.org/v2/country/JPN/indicator/NY.GDP.DEFL.ZS?date=2018:2024&format=json)は2018年98.0183258646232、2024年108.554052559848（2020=100）。2018年ドルの購買力を2024年円へ換算する代理係数は約115.35円。市場為替ではない。GDPの購買力・価格指数は教育人件費専用の指数ではなく、換算上の近似である。

## 初期中心値の導出

年1兆円を小中学校の継続的な教育サービスへ追加し、9学年へ均等配分する想定：

```
換算円／ドル = 104.158636 × 108.554052559848 / 98.0183258646232
1人年の追加ドル = 1兆円 / 930万人 / 換算円／ドル
9年間受益後のPISA相当改善 = 1人年の追加ドル / 1,000
                         × 0.0316 × 100 × 9 / 4 × 日本への移転率
```

1標準偏差をPISA尺度100点に対応させること、4年間の結果を9年間へ比例延長することは仮定。米国の各テストとPISAは同じ試験ではない。高校・大学・成人訓練や建設中心の政策をこの運営支出モデルへ直接転用しない。建設投資は建設費全額と年間サービス費の区別が必要である。

日本への移転率は、制度・対象者・支出の質の違いをまとめた未推定の比較条件。中心50%、慎重25%、米国並み100%、効果ゼロを画面で切り替える。統計的信頼区間や、全OECD国の平均効果とは呼ばない。米国の研究間分散から日本の移転率を推定したわけでもない。純追加性は初期100%とし、移転率50%に加えてさらに機械的に50%を掛けない。地方予算の置換などを想定する場合は純追加性を別途下げる。

数値は `EDUCATION_CALIBRATION` に集約し、`calibratedEducationGain` で小数2桁へ丸めて初期設定と感度ボタンを生成する。設定した全国平均改善幅・基準予算は保存・共有される。編集後の条件は手動シナリオとして扱い、基準年額・学年数を変えても学力改善幅を自動変更しない。感度ボタンは教育の各条件を初期条件へ戻して適用する。

## 世代・期間・財政への接続

支出年 s の有効実施割合：

`dose_s = min(1, 追加予算_s / 政策なし価格_s × 純追加性 / (基準年額 / 基準価格))`

同条件の政策を合算してから上限を適用する。分割で上限を回避できない。予算の実質化は既存の政策なし価格経路を使う。基準年額の初期1兆円を超える純追加支出は効果を外挿しない。これは実証的な飽和点ではなく校正範囲の制限であり、最適配分を左右する。基準額を広げるなら対応する学力改善幅の再校正も必要。

各年の支出は9学年それぞれへ継続改善幅の1/9を与える。最初の対象世代は支出5年後、残りの世代は翌年以降に就労する。就労人口を40の同規模世代と置き、就労後は年2%減耗、40年で退職する。

`生産性増分 = Σ_s Σ_g dose_s × PISA改善幅 × (0.01 / 8) × (1−減耗率)^就労後年数 / (9 × 40)`

学年数9と就労期間40は編集可能。未就労・退職済世代は合計しない。1年目の支出の最初の寄与は6年目で、5年目の学力経由の生産性効果は0。短期の需要効果・支出・財政費用・人員負荷は初年から従来どおり残る。単年支出の効果と全学齢期の継続支出を混同しない。減耗0の恒久支出では、全世代入替後にPISA改善幅×0.01/8へ収束する。

TFPへ一度だけ接続し、個人賃金の上昇を別途GDPへ足さない。潜在GDP・実現供給・15年試算・最適化は同じ経路を使う。選択した生産関数・制約によって実際のGDP変化は異なる。最適化は現在の単一条件で行うもので、感度条件全体に頑健な配分を自動保証しない。条件変更後は再探索する。

## 互換性と残る限界

旧URLの入力は上書きしない。2026-09-24.3の明示的な改善0点も保存どおり再現する。`educationModel` のないURLは旧就学年数方式を維持し、切替ボタンと旧方式の出典を表示する。

固定人口・同規模40世代は、日本の人口ピラミッド、学年別人口、進学・就業率の違いを省略する。就労時期、技能の残存、支出効果の持続、学習尺度の対応、国際移転はいずれも未校正の要素を含む。教員の確保や授業設計で成果は変わる。教育効果を現在の子どもの貧困・可処分所得へ直接加える経路は設定せず、進学、健康、非認知能力、世代間格差等の便益もこのTFP経路には含めない。
