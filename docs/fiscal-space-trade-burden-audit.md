# 為替・貿易・家計負担の検証（2026-09-15）

## 追加の観測指標

一般政府の基礎的財政収支は金額を主表示しGDP比を併記、支払利子も金額と利払いGDP比を独立表示。最新プリセットは2024年財政額 / 2026年4〜6月GDP季調年率という時点の異なる比率であることを維持する。将来年の結果にも基礎的財政収支の金額を追加。

エネルギーCPIは[2024年年報・表4-5](https://www.e-stat.go.jp/stat-search/file-download?fileKind=2&statInfId=000040263552)の年平均前年比3.8%、[2026年7月全国CPI・表5](https://www.stat.go.jp/data/cpi/sokuhou/tsuki/pdf/zenkoku.pdf)の前年同月比0.6%。補助金・税制を含む家計向け価格で、輸入価格ではなく、将来経路は未推計。

肥料は[農水省2026年4月・肥料をめぐる情勢4頁](https://www.maff.go.jp/j/seisan/sien/sizai/s_hiryo/attach/pdf/index-229.pdf)の2024肥料年度（2024年7月〜2025年6月）を両プリセットで表示。工業用を除く尿素の国産割合は公表丸め値3%（国産9千トン、輸入256千トン）。りん安と塩化加里はほぼ全量輸入。肥料全体、窒素・りん酸・加里成分全体の自給率とは区別し、天然ガス等の上流輸入は未控除。OECDの同一定義集計は未取得。

## 修正した計算

GDPギャップを初期入力・snapshot・将来経路・表示のすべてで `(実際−潜在)/潜在` に統一した。最大GDP基準も同じ符号。制約は従来どおり実際GDP/最大GDPで評価するため、符号の修正だけで任意控除後の枠は変わらない。

公表モデルの輸出反応を取り込んだ。GDP比1%の継続措置に対する、輸出自体の基準額を分母とする水準変化率（%）を以下のとおり採用する。

| EF2026・1〜5年 | −0.01, −0.01, −0.06, −0.12, −0.16 | 0, −0.01, −0.04, −0.08, −0.10 | 0, −0.01, −0.02, −0.04, −0.06 |
| ESRI2022・1〜3年 | 0, −0.01, −0.04 | 0, 0, −0.01 | 0, 0, −0.02 |

出典：[EF2026・主要乗数表](https://www5.cao.go.jp/keizai3/econome/ef2rrrrrr-summary.pdf)、[ESRI2022・表2-2〜2-4](https://www.esri.cao.go.jp/jp/esri/archive/e_rnote/e_rnote080/e_rnote072.pdf)。EFの減税は増税の符号反転。輸入と同じく年次応答を畳み込み、初期価格で輸出額へ換算する。追加輸出をGDPに再加算しない（公表GDP乗数に含まれる）。国内追加需要の分解は `GDP反応＋輸入−輸出`。財・サービス収支差＝輸出差−輸入差となり、輸入差の逆符号だけではなくなる。財/サービス別の追加輸出は未同定のため、輸入と共通の明示的な按分仮定を使う。

## 為替・輸入物価の条件付きストレス

財政額からの参照推計は `fiscal-external.ts` に分離した。EF2026の円／ドル水準反応（GDP比1%の継続措置）は政府 `[0.01, 0.11, -0.16, -0.34, -0.43]`、所得税減税 `[0, 0.04, -0.12, -0.22, -0.27]`、法人税減税 `[0, 0, -0.03, -0.10, -0.16]`（%）。ESRI2022はそれぞれ `[-0.06,-0.24,-0.47]`、`[-0.01,-0.05,-0.12]`、`[-0.02,-0.10,-0.22]`。同じ年次畳み込みを使い、期間終了後の反動も保つ。EFの変数定義は[2026年度変数リスト M_FXS](https://www5.cao.go.jp/keizai3/econome/ef2rrrrrr-var.pdf)の円／ドル。金融引締めを伴う円高反応も符号を変えず表示する。

入力中の政策と任意控除後の枠の両方について、外貨価格一定・輸入転嫁100%・輸出円換算50%の仮定で価格要因と支払総額差を表示。対ドル以外の通貨も同率で対円変化とみなす。公表モデル全体の再実装ではなく、既存の数量反応を含む輸出入額に為替換算を追加する部分診断である。公表CPI反応に含まれる為替効果は再加算せず、GDP・財政収支・探索制約も上書きしない。金利・需給ギャップ変更時の新たな為替係数や財政リスクプレミアムは未推定。

現在の数値・入力条件・基準インフレとCPI上限の感度は、再生成可能な[共通の検証結果](fiscal-space-audit-results.md)を参照。

`external-stress.ts` は財政額から為替を予測せず、任意控除後の枠でのCPI経路に追加の円安・海外価格上昇を重ねる。輸入価格＝`(1＋円/外貨上昇×転嫁割合)×(1＋外貨価格上昇)−1`。10%ずつの複合は21%。輸出数量を増やさず、既存輸出の円換算額だけを計算する。

初期の感度仮定は輸入転嫁100%、輸出円換算50%、輸入価格→CPI水準0.13、食品水準0.30。最もCPIが高い将来年に累積転嫁が1年で生じる厳しい時期を仮定し、翌年からは水準を維持する。同じ上昇率を毎年重ねない。CPIは複利で合成し、年0は外部ショックで書き換えない。

円安のストレスは条件付きの脆弱性を示し、追加支出が特定の円安を引き起こすという推定ではない。係数0.08/0.13/0.20と輸出円換算0〜100%を比較する。信頼区間ではない。

[日銀2026年1月 BOX3](https://www.boj.or.jp/mopo/outlook/gor2601b.pdf)の2022〜2024年分解（輸入物価+36.2%、CPI+8.7%、投入コスト寄与4.7%）は感度検証の参考にしたが、比4.7/36.2は将来の因果弾力性ではない。[日銀2026年4月 BOX2〜3](https://www.boj.or.jp/mopo/outlook/gor2604b.pdf)の円安・原油高・株安の複合ショックも円安単独の係数には転用しない。食品・コアコアCPIの政策込み年次予測は未推計。食品自給率を小売価格の輸入原価比率として使用しない。

本体の金利・エネルギーショックが既にある場合、表はそれに追加するストレスである。為替予約、数量調整、実質所得、賃金・期待・金融反応、供給途絶、政策固有の国内代替との同時均衡は未推計。本体のGDP・税収・任意控除後の枠をこの部分診断から自動変更しない。

## 政策別の輸出・国内代替

13政策それぞれについて輸出、輸入代替、追加輸入、便益の時間差を表示した。半導体では国内工場の輸出販売、国内向けの輸入置換、建設装置輸入、部素材輸入を分ける。政府の官民投資・売上目標・経済波及額を政策の因果的輸出増と扱わない。[経産省の支援枠](https://www.meti.go.jp/policy/mono_info_service/ai_semiconductor_frame/ai_semiconductor_frame.html)

事業計算は各年の支出をコーホートとして積み、稼働遅れ後に便益期間だけ売上が生じる。輸出＝売上×輸出比、輸入代替＝売上×国内販売比×置換比、運転輸入＝売上×輸入原価比。売上倍率・建設輸入比の未設定はnullで、ゼロと誤認させない。その他の初期割合・遅れはUIで明示した仮入力であり校正済みの政策係数ではない。補助率の民間投資上乗せは自動で付けない。

半導体・研究成果の事業化・発電の事業条件を本体・政策比較・財政枠探索へ接続した。公共投資・送電網は物流費・送電損失等のモデルが必要で、工場の売上モデルを流用しない。減税・給付を設備投資へ自動換算しない。接続は条件付きの会計的補正であり、政策別の実証校正ではない。

- 建設時の輸入比を指定した場合、公表モデルの初年度輸入反応を政策費用比に換算した `m0` を暫定基準とし、国内反応の倍率を `r=(1-m)/(1-m0)` とする。GDP・物価水準・雇用・共通輸出入等の反応を同倍率で変更し、輸入には当年の実質支出×`(m-r*m0)` を補う。建設時輸入を二重加算しない。初年度のマクロ輸入反応には間接誘発が含まれ、`m0` は直接調達の厳密な推定ではない。輸入比未設定なら共通反応を維持する。
- 稼働後は純追加の輸出 `X`、輸入代替 `S`、輸入原価 `O` を分離し、純輸出寄与 `X+S-O` を追加する。正の部分を海外取引経由の潜在供給増とするが、実際の生産・輸出・代替は国内供給上限で制限する。潜在GDP増を自律的GDP増にも足す二重計上はしない。同じ投資に従来の汎用供給係数も設定した場合はエラーとする。家計・企業の追加支出や雇用・賃金への二次波及は再推計しない。
- 各支出年の投資を政策なしの物価経路で実質化し、年ごとの稼働遅れ・便益期間を適用する。事業パネルの価格固定額と、本体の実質額・名目輸出入は区別する。
- 輸入代替は同種政策・追加1兆円の重複行を含め合算し、発電は基準年エネルギー輸入額、その他は残余輸入額で制限する。品種別の市場上限を推定したものではない。発電の燃料削減はエネルギー輸入額と財の収支に一度だけ計上する。
- 売上未設定・運転原価未設定のときは利益側だけを計上しない。設備投資・売上・燃料節約の純追加性と実現可能性、海外需要、国内の代替対象は案件別に検証が必要。事業表の国内付加価値（売上−輸入原価）全体をGDP純増とは扱わない。

全国の[2020年産業連関表（第75回日本統計年鑑3-11）](https://www.stat.go.jp/data/nenkan/75nenkan/03.html)を調査したが、部門別の輸入係数への校正は未完了。13部門表では医療・教育・保育等を十分に区別できず、細分類の調達構成も必要となる。UIではこの未完了部分を明記し、事業条件を公表実績として表示しない。

### 政策比較の期間

各候補を現在の政策に「初年度だけ1兆円」加えた差を表示する。1・3年は短期マクロ反応、10年は別途計算した供給寄与。公表期間外の総合的な物価・輸出入予測と、未推計政策の供給ゼロ表示は削除した。公共資本・研究・教育・保育・送電網の新経路、半導体の実績参照と減耗・純追加性、長期の実現条件は[長期供給モデルの検証](fiscal-space-long-run-supply.md)を参照。金額は年間のフロー・水準の差で累計ではない。比較表は6列に縮め、詳細を展開表示する。

### 消費税

輸出免税と仕入税還付を相殺して扱う。[国税庁](https://www.nta.go.jp/taxes/shiraberu/taxanswer/shohi/6551.htm)。税抜仕入価格一定なら、税率10%で100＋10−還付10＝100、税率5%で100＋5−還付5＝100。還付減少をそのまま輸出企業の利益減・輸出減へ置き換えない。税抜価格の交渉・転嫁・資金繰りは別。家計需要の代理反応と消費税率変更の直接価格効果を混同しない。

## 国民負担率と家計負担率

法人課税の賃金帰着を追加した。`burden-incidence-2024.json` は歳入可視化の `tax-burden-incidence.json.gz` の展開コピー（更新時に同期）。国・地方の法人課税31.3864兆円×帰着割合 / 全国賃金263.8977兆円を各世帯給与に配賦。割合は0/25/50/100%の感度仮定で、日本の実証値とは表示しない。初期の25%では世帯主65歳未満の勤労者世帯の年齢階級別30.1〜35.6%。暗黙の失われた賃金として分子・分母の両方へ同額を加算する。資本・価格への帰着と他の企業税等は未配賦。国民負担率との範囲差は残る。

[財務省2026-03-05](https://www.mof.go.jp/policy/budget/topics/futanritsu/sy202603a.pdf)の対GDP比を主表示に採用：2024年度実績32.9%、2025年度実績見込み32.9%、2026年度見通し32.7%。同じ表の国民所得比と国民所得・GDPから内訳を概算換算し、丸め差があっても公表総率は維持。最新四半期GDPで過去年度の負担を割らない。

参考表示には、同じ財務省資料の国民所得（NI）比を採用。2024年度実績46.7%、2025年度実績見込み46.1%、2026年度見通し45.7%。GDP比から再計算せず、公表総率を維持する。NIは要素費用表示で、固定資本減耗と生産・輸入品に課される税（補助金控除後）をGNIから差し引いた額。家計の手取りではない。GDP比を主表示、NI比を参考併記し、GNI比の表示・算出は削除。OECD平均との国全体の比較には、日本も同じOECD系列・対象年を使い、財務省の年度値をそのまま並べない。

年齢別の家計負担は歳入可視化と同じ[家計調査2024年 第3-2表](https://www.e-stat.go.jp/stat-search/files?stat_infid=000040247076)を使用。`age-burden-2024.json` は既存 `public/data/tax-burden-age-2024.json.gz` の展開コピー。更新時は `scripts/generate-tax-burden-stats.py` の生成物と同期する。

家計負担率＝（本人直接税＋本人社会保険料＋事業主推計＋消費税推計＋法人税の賃金帰着）/（実収入＋事業主推計＋法人税の賃金帰着）。事業主負担は勤め先収入×16%、14〜18%で感度比較。[OECD2024年制度](https://www.oecd.org/en/publications/2025/04/taxing-wages-2025_20d1a01d/full-report/japan_b78731c0.html)の料率を参考に丸めた仮定で、年齢・加入制度・報酬上限を再現しない。企業負担の全額が労働者に帰着する実証値でもない。消費税は税込の標準対象支出×10/110＋軽減対象×8/108、非課税を除外し、混在品目の按分・完全転嫁を仮定。

初期設定で平均33.8%、年齢階級別の最小〜最大30.1〜35.6%。法人税帰着0%なら平均32.2%、幅28.4〜34.0%。平均は第3-2表の「世帯数分布(抽出率調整)」を使い、Σ（世帯分布×負担額）÷Σ（世帯分布×所得）で計算する。7階級の重みは856/1041/1275/1486/1683/1327/1118で、丸め後の合計8786を使って正規化。生の集計世帯数や割合の単純平均は使わない。`scripts/generate-fiscal-space-age-weights.py` が原表から `age-burden-weights-2024.json` を生成し、原表のハッシュも記録する。

対象は世帯主65歳未満の二人以上勤労者世帯。単身・自営業を含む15〜64歳個人の全国平均ではない。家計分母には年金等の移転所得もありNI・GDPとは異なるため、国全体との差を世代間負担差と解釈しない。同じ範囲の生産年齢人口の負担率には企業課税の世代別帰着とGDP・NIの年齢別配分が必要で、未推計。

OECDの参考比較には、所得税＋本人・事業主保険料−現金給付を労働費用で割る公表指標を使用。消費税・法人税を含む現役世帯の平均とは異なる。2024年版プリセットは[Taxing Wages 2025](https://www.oecd.org/en/publications/taxing-wages-2025_b3a95829-en/full-report/overview_715add19.html)の2024年値（単身・子なし・平均賃金100%：日本32.6%、OECD34.9%；片働き夫婦・子2人：双方25.7%）。最新プリセットは[Taxing Wages 2026](https://www.oecd.org/en/publications/taxing-wages-2026_3a5169ef-en/full-report/overview_d93131c3.html)の2025年値（単身：日本33.1%、OECD35.1%；片働き夫婦・子2人：日本28.4%、OECD26.2%）。異なる版の値なので遡及改定を含む厳密な前年差比較には使わない。
