# 政策判断に関わる計算・表示の修正

対象：main `d97b6af`。作業開始時の電力投資・供給力に関する未コミット変更を保持。
財政モデル版は `2026-09-16.1`。公開環境への反映は未実施。

## 修正

| 指摘 | 対応 |
| --- | --- |
| 繰越を不用と誤認 | 当年度・前年度とも `歳出予算現額 − 執行額 − 翌年度繰越額`。執行率と不用率を独立に保持し、判定前に丸めない。繰越が不明なら判定不能。APIと評価一覧で共通の前年度履歴を使用。 |
| 当初予算が支出額に置換 | 事業ノードの `value` は選択した予算基準を保持。`layoutValue` で帯が収まる描画サイズを計算。府省庁基準は引き続き歳出予算現額を使用。支出が上回る場合はツールチップに両者の違いを表示。 |
| 法人税転嫁の追加控除 | 現金可処分所得には法人税の転嫁推計を控除しない。消費税も消費支出に属するため控除しない。転嫁等を含む推計純負担を別表示。 |
| 基準インフレへの依存 | 主表示の隣に1.0/1.5/1.8/2.0/2.2/2.5%と入力値の再探索結果を表示。上限表示は0.1兆円単位。全制約を再探索し、各行の拘束条件も表示。 |
| 未評価を安全扱い | `unevaluated` または `coverageComplete=false` で探索停止。金額の0を推奨額として見せず「算出不可」。旧リンクの手入力条件は保持し、その不足を明示。 |
| 観測年0で余力ゼロ | 年1以降を探索・感応度・CPIピークの対象とする。年0は初期値・グラフに保持。将来の政策なし経路が違反する場合は引き続き停止。 |
| 税収弾性値1.7 | 既定1.1、1.0/1.1/1.7と入力値の年末債務比率・収入を比較。1.1は本モデルの中期シナリオ仮定であり、一般政府収入全体の実証推定値とは主張しない。 |
| 債務持続性の誤読 | 280%は仮定、5年では長期持続性未検証、債務が境界を決めていなければ債務上限を見つけた結果ではないと主表示・メーターに明記。 |
| 仮定由来の能力 | メーター本体に能力・余力または閾値の仮定バッジを表示。 |
| 労働の稼働率との混同 | 「就業者 / 労働力人口」に改称。失業率の裏返しであることを明記。推移表の利用率順位も追加1兆円への感応度順位へ変更。 |
| 20%留保の根拠 | 主表示を控除前の探索額と感度表に変更。控除後は任意の定率控除として別表示。ストレスから導出した緊急予備費とは扱わない。 |
| 係数層の検証 | EF2026の原本PDF抜粋・原表数値行・URL・取得日・SHA256を固定。モデルの係数を原表の数値・符号反転と照合。原本の実在を疑う変更はしていない。 |
| docsの食い違い | 数値表を共通の生成文書へ集約。労働の追加感度は0/0、法人税転嫁は25%で統一。 |

不用額の定義：[財務省・用語の解説](https://www.mof.go.jp/policy/budget/reference/statistics/term.htm)。
EF2026原本：[経済財政モデル（2026年度版）資料集](https://www5.cao.go.jp/keizai3/econome/ef2rrrrrr-summary.pdf)。

## 検証と制限

- 単体テスト：push対象のみの分離環境で211件成功（既存の別作業を含む作業環境では213件成功）。原表照合、実データのPID回帰、旧共有リンク、観測年0、法人税転嫁を含む。
- `npm run typecheck`、`npm run build`：成功。
- 関連ブラウザ検証30件成功（サンキー16・財政11・税負担3）。法人税転嫁の新規テストはスライダー操作へ修正後、単独再実行で成功。
- Windowsの `npm run check-traces` は失敗。Next 15.5.25のローカル出力で `public/data` の除外が効かず、同じ `quality-scores` 関数に既存 `.next-resource-final` と今回の `.next` の両方で150件の `public/data` パスが残る。最大関数がローカルで200MB目安を超えるため、このWindows出力をデプロイ可能と判定しない。Linux CIでの同梱検査が必要。
- 本番ビルドのサンキーE2EにはCIと同じ `NEXT_PUBLIC_PLAYWRIGHT=1` が必要。
