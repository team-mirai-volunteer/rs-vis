# 歳入可視化（/tax-burden）と既存ビューのルック統一方針

## 現状の差分（トークンではなく「殻」が違う）

デザインシステム適用後、色・フォント・ボタン・角丸は全ページで揃っている。それでも `/tax-burden` だけ別物に見えるのは、ページの骨格（shell）が違うため。

| 観点 | /tax-burden（歳入） | 既存 11 ビュー（サンキー・MOF・評価 等） |
|---|---|---|
| 骨格 | スクロールする文書型（gikai / marumie 型） | 全画面キャンバス型のツール |
| ヘッダー | 白い浮島ヘッダー + Team Mirai ワードマーク + 製品名 | なし。右上に年度セレクトとハンバーガーが浮くだけ |
| 導入 | `bg-mirai-gradient` の Hero（見出し・説明・共有 CTA） | なし。いきなり図 |
| 主要ナビ | ピル型タブ 4 つ（横並び・アイコン付き） | ハンバーガーの中に 12 項目 |
| 情報 | KPI カード 3 枚 → 大カードにチャート | 図と小さなパネル、10〜12px の文字 |
| 注記 | 「試作・OECD 未照合」バッジ、「データについて」ダイアログ | ページごとにばらばら（無いページも多い） |

つまり `/tax-burden` は「みらいらしい Web ページ」の型で作られ、既存ビューは「データツール」の型で作られている。どちらもトークンは正しいので、直すのは shell の統一。

## 選択肢

### A. 共通ヘッダー（浮島）を全ビューに載せる — 推奨
- 高さ 56px 前後の白い浮島ヘッダーを共通化（ワードマーク＋製品名／右に年度セレクト・「データについて」・ナビ）。
- 既存ビューの右上コントロール群をこのヘッダーに吸収し、キャンバスはヘッダーの下から開始（`top: 56px`）。
- Sankey 系は縦の余白を 56px 失うだけで、密度・操作は据え置き。
- ナビは PC では主要 4〜5 ビューをテキストリンクで出し、残りはメニューへ（gikai の Header パターン）。
- 影響: 各 page.tsx の上部と `SidePanelChrome` / `MinimapOverlay` の `top: 0` 前提の調整。

### B. トップページを作る（`/` のリダイレクトをやめる）
- Hero（グラデ）＋各ビューへのカード一覧。入口だけ「みらいの Web」の顔になる。
- ツールビューは今のまま。工数は最小。A と組み合わせると一貫する。

### C. /tax-burden をツール型に寄せる（Hero を外す）
- 安いが、歳入ページは「説明して考えさせる」ページなので Hero と KPI カードは残す価値がある。非推奨。

### D. 既存ビューを文書型に作り直す
- marumie 風のカード・コンテナ幅に閉じ込めると Sankey の密度が死ぬ。非推奨。

## 推奨

A + B。ルールとして「全ページ共通の浮島ヘッダー」「説明が主目的のページだけ Hero を持つ」「注記（試作バッジ・データについて）はヘッダー右の共通スロットに置く」を決める。歳入ページは今の作りが正で、既存ビューをそこへ寄せる。

## 実施結果（2026-09-13、A + B を採用）

- `components/navigation/pages.ts`: 公開ページ一覧（href / label / description / primary）を 1 箇所に集約。AppHeader の主要ナビ・PageNavMenu の全件メニュー・トップページのカードが共有する
- `components/navigation/AppHeader.tsx`: 浮島ヘッダー（ワードマーク＋製品名／xl 以上で主要 6 ビューのナビ／右に年度セレクト等のスロット＋全件メニュー）。`position="static"`（縦 flex ページ）と `position="fixed"`（全画面キャンバス）の 2 モード。高さは `--app-header-h: 60px`
- 全画面キャンバス型（sankey-svg / budget-sankey / mof-hierarchy / mof-sankey / mof-kou/[id] / project-bubble）: ルートを `top: var(--app-header-h)` から開始。`SidePanelChrome` と `AiChatPanel` の固定パネルも同じ変数で下げた
- 縦 flex 型（quality / subcontracts / subcontracts/[projectId] / mof-jikou / mof-kou / mof-kou-moku / mof-budget-overview / transfer-detail）: ルートの最初の子として静的配置。各ページの右上クラスタ（年度・メニュー）は撤去し、年度セレクトはヘッダーのスロットへ
- `app/page.tsx`: リダイレクトをやめ、Hero（`bg-mirai-gradient`）＋主要ビューのカード＋MOF 補助ビューの一覧＋フッターのトップページに。`sitemap.ts` に `/` と `/budget-sankey` を追加
- 検証: tsc / lint エラー 0、全 13 ページのスクリーンショット確認、`tests/e2e/sankey-svg.spec.ts` 13 passed / 2 skipped
- 未対応: `/tax-burden` は別セッションの未コミット実装のため、自前ヘッダーのまま。`AppHeader` に差し替えるだけで揃う（`<AppHeader current="/tax-burden">` に「データについて」ボタンを children で渡す）

## 実装メモ（着手時の想定）
- `components/navigation/AppHeader.tsx` を新設（ワードマークは `.claude/skills/assets/logos/team-mirai-wordmark.svg` → `public/logos/` に既に配置済み）。
- `PageNavMenu` / `YearSelect` はヘッダー内に移す。`theme` prop は削除可。
- 全画面ページは `fixed inset-0` → `fixed inset-x-0 top-14 bottom-0` に。`SidePanelChrome` は `top` を prop 化。
- Playwright の `data-testid` はそのまま維持できる（DOM の位置が変わるだけ）。
