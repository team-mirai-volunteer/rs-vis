# チームみらいの国会質問の型と、LPの質問の合わせ方

LP（`/lp`）の国会質問16本は「参考人に数字、大臣に判断、逃げ答弁への切り返し」の型で書いた。
これをチームみらいの実際の国会質問と比べ、文体・構成・踏み込み方をどう合わせるかを整理する。

## 2. チームみらいの質問の型（会議録から）

### 2-1. 1問の構造

```
冒頭  「チームみらいの〇〇です。本日は〜について伺います」＋この質疑全体の狙いを1〜2文
       （例：「今回の補正予算だけでなく、来年度予算…を考える際にも議論の土台となるような建設的な御答弁を期待しております」）
導入  ①政府の取り組みをまず認める（「迅速な対応は大変すばらしい」「進捗がある点は評価したい」）
       ②事実・数字を1〜3個（出生数67万人・出生率1.14、原油110ドル、自治体システム費用6,620億円、AISI職員の守秘義務の罰則）
       ③論点の切り分け（「性質の異なる二つの課題がある」「足下の対応と構造的対応は対象も時間軸も打ち手も異なる」）
問い  短く、疑問形で判断を委ねる
       「〜ではないでしょうか」「〜という理解でよろしいでしょうか」「〜についてお考えを伺います」「〜という御判断でありましょうか」
答弁後 「ありがとうございます」→答弁を要約して受け止める→提案か要望
       「論理的に否定できないのではないかと受け止めております」（柔らかい言質の固定）
       「是非〜をお願いいたします」「検討いただければと思います」
       決意を取りたいとき：「もう一言御決意をいただけないでしょうか」
締め  「引き続き議論させてください」「これで私の質問を終わります」
```

### 2-2. 踏み込み方の特徴

- **対決しない**。「適正だとお考えですか」「否定できますか」のような詰問はほぼ無い。代わりに「〜ではないか」と仮説で迫り、答弁者に判断を委ねる
- **提案型が多い**。「どういう状況になったらどういう打ち手を打つかの検討（シナリオプランニング）」「使途の類型の例示」「事後の透明性の徹底」「費用対効果の指標」「クリアランスの付与」など、政府が実行できる具体策を添える
- **事前・事後の設計を求める**。「事前の判断基準」「事後に使途・金額・効果を都度示す」「成果を測定可能な指標で検証し是正につなげる」が繰り返し出る。これはLPの「翌年の検証」と同じ発想
- **自前の取り組みを根拠にする**。「まる見え政治資金」で自動連携ができることを示し、国のシステムの要件に求めた。「私どもが公開データを集計したところ」という持ち出し方は型に合う
- **参考人質疑では「なぜうまくいったか」「なぜ進まないか」を聞く**（行政監視委のeLTAX・データ公開）。原因分析を専門家に求める形
- **主意書は使っていない**。一覧・数表を文書で取る手段は未使用。LPで主意書を提案するのは新しい動きになる
- **副作用の指摘**。ガソリン補助に「省エネや燃料転換のインセンティブをそぐ副作用」と出口戦略を求めた。LPのエネルギー問と同じ論点

### 2-3. 長さと口調

- 1問の導入は400〜800字、問いの文は1〜2文。答弁後の受け止めは100〜300字
- 「です・ます」＋「〜と承知しております」「〜というふうに思います」「是非」。敬語は丁寧だが過剰ではない
- 数字は読み上げやすい丸め方（「六十七万人」「一・一四」「六千六百二十億円」）

## 3. LPの質問との差

| 観点 | LPの現状 | チームみらいの型 | 合わせ方 |
|------|---------|----------------|---------|
| 導入 | 「このサイトで分かっていること」を箇条書き | 政府の取り組みを認めてから事実を示す | `known` の前に「政府側の前向きな事実」を1つ置く |
| 問いの口調 | 「適正だとお考えですか」「競争と呼べますか」「否定できますか」 | 「〜ではないでしょうか」「〜という理解でよいか」 | 詰問を仮説型に書き換える |
| 答弁後 | 「逃げ答弁への切り返し」（反論） | 「ありがとうございます」→受け止め→提案 | `rebuttals` を「答弁を受けての受け止めと提案」に変え、言質は「論理的に否定できないと受け止める」「もう一言御決意を」で取る |
| 約束 | 「〜していただけますか」 | 「是非〜をお願いいたします」「検討を深めていただきたい」 | 約束の文言は残しつつ、要望の形に |
| 主意書・検査要請 | 多用 | 未使用 | 残す。「文書で数表を取る」のは党として新しい手段なので、LPでは「主意書で求める数表」を提案として示す |
| 数字の持ち出し | 「民間の集計で」 | 自前プロダクトを例示 | 「私どもが公開データを集計し、サイトで公開しているところ」に揃える |
| 参考人への問い | 事実確認（件数・金額） | 事実確認＋原因分析（なぜ進まないか） | `official` に「なぜ」の問いを1つ足す |

## 4. 書き直しの見本

### 4-1. Q2 1者応札（決算行政監視委員会・財務大臣＋参考人）を型に合わせる

**冒頭**
チームみらいの〇〇です。本日は、国の契約の競争性について、公開データの集計を基に建設的に伺いたいと思います。

**導入**
各府省が1者応札の改善に取り組んでおられることは承知しております。公告期間の延長や仕様の見直しなど、調達改善計画に基づく取り組みは評価したいと思います。
その上で、私どもが行政事業レビューシートの契約情報を集計し、サイトで公開しておりますが、2024年度の一般競争・指名競争のうち応札者が1者だった契約が48%、金額で9,036億円に上ります。1者応札の落札率は平均で93%、複数応札では82%で、契約方式・府省・金額帯のどれで分けても差が残ります。
これは特殊な装備や施設に限った話ではなく、環境省で68%、文部科学省で62%といった府省もございます。

**参考人への事実確認**
政府として、府省別の1者応札率と落札率を横断的に集計しておられるか。また、同じ事業で同じ事業者が3年続けて1者応札となっている契約の件数を把握しておられるか、伺います。
（想定答弁：横断では集計していない）

**答弁後の受け止めと提案**
ありがとうございます。各府省で把握されているということですが、横断の数字が無いということは、民間の集計でしか全体像が見えない状態だと受け止めております。
そこで一点、御提案です。1者応札の改善策を求めた事業について、翌年のレビューシートに応札者数の変化と講じた策を書く欄を設けていただけないでしょうか。事後に検証できる形にすることが、改善を実効的にする近道だと考えます。

**大臣への問い**
仮に1者応札の契約が複数応札並みの落札率で落ちていれば、差は約1,000億円になります。平均を機械的に当てた規模感ではございますが、この規模の差が毎年生じている可能性について、大臣はどのように受け止めておられるでしょうか。

**締め**
ありがとうございます。否定できる数字ではないと受け止めました。翌年のシートで応札者数の変化を私どもも確認してまいりますので、是非、改善策の記載をお願いいたします。

### 4-2. Q9 少子化（内閣委員会・こども政策担当大臣）を型に合わせる

**冒頭・導入**
2025年の出生数は67万人、合計特殊出生率は1.14と、少子化に歯止めがかかっていないという危機感は政府と共有しております。児童手当の拡充をはじめ、こども家庭庁の下で施策が進んでいることも承知しております。
その上で、私どもが行政事業レビューシートを集計したところ、子育て分野43事業・4.6兆円のうち、予算上位10事業でアウトカム指標の実績値が入っているのは2事業でした。児童手当2.17兆円の指標「可処分所得の増加」、出産・子育て応援交付金の「経済的理由を挙げる夫婦の割合」は、いずれも実績が空欄です。出生率や出生数を成果指標に置く事業は、5,794事業の中にひとつもありませんでした。
出生率を個別の事業の成果にすることが難しいのは理解しております。だからこそ、中間の指標が要るのではないかと考えます。

**参考人への事実確認**
児童手当・教育保育給付のアウトカム指標の実績が空欄である理由は、測定していないのか、シートに記載していないのか。出産・子育て応援交付金の「経済的理由」の調査はいつ行われ、結果はどうであったか、伺います。

**答弁後の受け止めと提案**
ありがとうございます。2023年度に庁を新設されたばかりで時系列が無いということは理解いたします。一方で、旧内閣府・厚労省の事業番号と接続すれば時系列は作れると思いますので、是非御検討いただきたいと思います。

**大臣への問い**
4.6兆円の子育て予算の効果を、政府は何で測っていかれるのか。希望出生率とのギャップや、経済的理由で子どもを諦める世帯の割合といった中間指標を、予算100億円以上の事業について次回のシートから記載していただくことはできないでしょうか。

**締め**
ありがとうございます。翌年のシートで実績の記載を確認させていただきます。少子化対策は未来への投資ですので、効果が測れる形で進めていただきますよう、お願いいたします。

## 5. 型を揃えるために LP のデータに足すもの

`DietQuestion` に次を足す（既存の項目は残す）。

| 項目 | 中身 | 既存との関係 |
|------|------|-------------|
| `opening` | 冒頭1〜2文（狙い＋建設的に伺う旨） | 新規 |
| `acknowledge` | 政府の取り組みを認める1文 | `known` の前に出す |
| `response` | 答弁後の受け止め（「〜と受け止めております」）と提案 | `rebuttals` を置き換える。想定答弁ごとの反論は `rebuttals` として残してもよいが、表示は「受け止めと提案」を主にする |
| `closing` | 締めの1文（翌年の検証の宣言＋要望） | `verify` と対にする |

`minister` と `promise` の文言は「〜ではないでしょうか」「是非〜をお願いいたします」の形に書き換える。`official` に「なぜ進まないか」を1問足す。

## 6. 判断が要る点

- **主意書と検査要請**：党の実績が無い手段。LPに残すなら「提案」と明記する（「主意書で求めることもできる数表」）。党の方針として使わないなら外す
- **詰問の度合い**：チームみらいの型は対決しないが、決算行政監視委員会のように事実を追及する場では多少強くてもよい。「否定できますか」は「否定できる数字ではないと受け止めました」（答弁後の受け止め）に移すと型に収まる
- **数字の丸め**：会議録では「六十七万人」「一・一四」のように読み上げる。LPの「8,134件（48%）」はそのままでよいが、台本では「およそ半分」「金額で九千億円」と丸めた言い方も併記すると使いやすい
