# 減税上限と財政画面の改善

## 減税の対象税収

所得税・住民税に対象税収の上限がなく、100兆円を減税として計算できた。
`policyReliefLimit` を入力・計算・探索・追加1兆円比較・共有URLの共通限度とし、同じ政策IDを分割しても合計額で検証する。旧共有URLにも限度を適用する。

- 所得税：2024年度の国の一般会計決算212,086億円。復興特別所得税を含めない。
- 個人住民税：所得割の道府県分4,452,998,483千円＋市町村分8,187,266百万円＝12,640,264,483,000円。均等割、法人分、利子割、配当割、株式等譲渡所得割、森林環境税を含めない。
- 入力は0.1兆円単位で切り下げ、それぞれ21.2兆円・12.6兆円。探索の限度は切り下げ前の対象額。
- 両データモード・全評価年で2024年度実績を固定する。税額を超える還付は減税額に入れず、既存の「現金給付」を別入力する。

原表抜粋とハッシュは `tests/fixtures/personal-tax/`。住民税の道府県分は47団体の合計と全国計を独立に照合する。

## 情報の配置

基準インフレ感度表と境界説明を冒頭から外す。下部の参考上限の「計算条件による違いを見る」に感度表を移し、理由を文で表示する。「次の1兆円」の制約表示は維持する。
政策を全14件表示し、発電設備投資の直下から電源構成・稼働時期のダイアログを開く。変更は既存フォーム・Worker・共有URLへ連動する。

## 発電投資

公開済み版の確実供給寄与率は未設定であり、発電投資の稼働後も供給増を算入しなかった。既存作業の寄与率の仮定（太陽光10%・原子力70%・水力50%）を利用する。
太陽光の待ち時間を2年から1年へ変更し、初回支出の翌年（2年目）に稼働する短期導入ケースとする。公表の平均としては扱わない。
[エネルギー白書2025](https://www.enecho.meti.go.jp/about/whitepaper/2025/html/1-2-2.html) の建設期間の例は1〜4年。0年（同年稼働）や2年以上も入力でき、旧URLの設定値は維持する。

電力メーターは需要÷供給の上限利用率であることを明示。期間の最悪年の指標なので、稼働後に改善しても建設中のピークが残る。年別表で建設需要・供給増・需給を確認できるようにする。

## 意見一覧

取得失敗を0件と表示しない。件数未取得と再読み込みを表示する。
公開の `/quality?year=2026` のPID1503詳細で、支出先・概要・意見の3APIが未対応の2026年度を要求しHTTP400になることを再現。
2026年度の評価一覧は2025年度RSを参照する予算要求モード。詳細の概要は2025年度から読み、参照元を明示する。支出先・執行実績は「未収録」と表示し、支出先と意見の取得・投稿は行わない。開発者向けのスクリプト実行案内を削除する。
