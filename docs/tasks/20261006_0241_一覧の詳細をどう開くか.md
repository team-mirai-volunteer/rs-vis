# 一覧の詳細をどう開くか（基金一覧を起点に）

基金一覧の詳細を左に開いたところ、「右の方がいいのでは」「いっそモーダルでは」という話になった。サイト全体の定石として整理する。

## 今のサイトの開き方

| 画面 | 主役 | 詳細の開き方 |
|---|---|---|
| サンキー図・バブルチャート | 図（キャンバス） | 左に浮かせたパネル。図は全画面のまま、上に重ねる |
| 評価一覧 | 表 | 「詳細」ボタンでモーダル（前後の事業へ移る操作を置ける作り） |
| 委託構造 | 表 | 事業名から別ページ（事業ごとのフロー図） |
| 基金一覧 | 表 | 左のパネル（いま） |

## 選択肢と向き不向き

| 開き方 | 向いている | 向いていない |
|---|---|---|
| **右の詳細パネル**（一覧と詳細を並べる） | 行を次々に選んで見比べる。名前の列（左端）を読みながら選べる | 列が多い表（表の幅が削られる） |
| **左の詳細パネル** | 図が主役で、図の上に重ねるとき（今のサンキー図・バブル） | 表が主役のとき。読み始めの左端（名前の列）が押し出される |
| **モーダル** | 1件をじっくり読む。本文が長い（必要性・点検結果など） | 一覧を見比べる（毎回閉じる必要がある）。前後移動の操作で補える |
| **行の展開**（アコーディオン） | 詳細が数行で済む | 基金のように詳細が長いもの |
| **別ページ** | 共有・ブックマーク・検索エンジン、長い内容 | 一覧との行き来 |

## 定石の提案

- **図が主役の画面は左パネル、表が主役の画面は右パネル**（または前後移動つきのモーダル）にそろえる。
  - 図の画面では、左上の操作（絞り込みなど）を避けて詳細を重ねるのが自然。
  - 表の画面では、左から名前を読んで行を選び、右で中身を見る流れが、読む方向と合う。
- **詳細の長さで決める**: 要点が数字中心なら右パネル、文章が長いならモーダルか別ページ。
- **どちらでも URL に選択を残す**（基金一覧は `?fund=` 済み）。

## 基金一覧へのおすすめ

**右の詳細パネル＋前後移動**を基本にする。

- 論点で絞り込んだ基金を上から順に確かめる使い方が中心なので、見比べやすさを優先する。
- パネルに「前の基金・次の基金」（↑↓キーでも可）を置き、行を選び直さずに順に見られるようにする。
- パネルの先頭は要点の数字と論点、その下に推移・造成の経緯。長い文章（必要性・保有割合の根拠・点検結果）は折りたたんでおく。
- 狭い画面（スマホ・タブレット）は、右パネルの代わりに全画面のシート（モーダル相当）にする。

モーダルにするなら、評価一覧の詳細ダイアログと同じ作り（前後移動つき）にそろえるのがよい。一覧との行き来は増えるが、長い文章を読むには向く。

## サイト全体で次にそろえる候補

- 評価一覧の詳細（今はモーダル）を、右パネル＋「全体を開く」でモーダルにする二段構えにするかは、使われ方を見て判断する。
