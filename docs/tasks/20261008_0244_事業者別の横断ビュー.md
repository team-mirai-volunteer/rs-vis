# 事業者別の横断ビュー（/vendors）

`20261008_0155_LP作成で見えたデータの不足.md` の 9-1（事業者別の横断指標の画面）と、`20261008_0230_LPを読んでの示唆と国会質問の設計.md` §6（Q-B 1者応札の裏付け）への対応。
LPの「三菱重工業 321億円」「クニエ 5件248億円」のように、これまでスクリプトでしか出せなかった事業者ごとの数字を画面で確かめられるようにした。

## 何が見られるか

事業者（法人番号。無ければ正規化した名前）ごとに、2023〜2025年度（2024〜2026年版シート。2025年度は暫定）の契約を全府省で合算して並べる。

| 列 | 中身 |
|----|------|
| 契約額 | 入札・随意契約・国庫債務負担行為の合計。補助金・交付金は含まない |
| 1者応札（金額・率） | 競争入札（一般・指名）のうち応札が1者だった契約の金額と、応札者数の記載がある競争入札に対する割合（件数ベース） |
| 落札率 1者（複数） | 1者応札の落札率の単純平均。括弧内は複数応札の平均 |
| 競争なし随契 | 随意契約（その他・不落不調）の金額。少額随契・企画競争・公募は含まない |
| 競争を経ない割合 | 契約額のうち、1者応札と競争なしの随意契約が占める割合 |
| 事業・府省 | 支出元の事業数・府省数 |
| 1者連続 | 同じ事業で2年度以上1者応札が続いている事業数 |

論点（絞り込み）: 1者応札が半数以上／同じ事業で1者応札が続く／競争なしの随意契約が主／同じ事業で随意契約が続く／1者応札の落札率95%以上／3府省以上から受注。いずれも手がかりで、判定ではない。

詳細パネル: 年度別の受注（契約額・競争入札・1者応札の件数と落札率・随契・国庫債務負担行為・補助金等）、支出元の府省、同じ事業で1者応札が続く事業（事業の評価一覧とサンキー図へのリンク）、支出先としての説明（既存の `UnifiedRecipientProfile`。外部情報・契約方式の内訳・3年度の推移・随意契約が続く事業・保有する基金）。

## 実装

| 層 | ファイル |
|----|---------|
| 型 | `types/vendors.ts` |
| 生成 | `scripts/generate-vendors.ts`（`npm run generate-vendors`）→ `public/data/vendors.json(.gz)`。契約方式データ 3年度分を法人番号でまとめる。25,061事業者・gz 2.9MB。raw は Git 管理外 |
| ドメイン | `app/lib/vendors.ts`（率の計算・論点・並べ替え・一覧の行の詰め込み・検索・法人種別の区分） |
| API | `app/api/vendors/route.ts`。既定は契約額1,000万円以上の12,958事業者を軽い行（合計だけ）で返す。`?key=` で全項目、`?q=` で全事業者から検索（上位50件） |
| 画面 | `app/vendors/page.tsx`・`view.tsx`。基金一覧と同じ構成（左に表、右に詳細または論点の概要。↑↓・Esc、URLに選択と絞り込みを残す） |
| ナビ | `components/navigation/pages.ts` に「事業者（試作）」。OG画像は `public/og/vendors.png` |
| テスト | `tests/vendors.test.ts` |

生成の規則:
- 収録はいずれかの年度に契約が1件以上ある事業者。補助金・交付金だけの相手と、「その他」「受給者」など特定の相手ではない記載（`genericRecipientNote`）は除く
- 法人番号は `isValidCorporateNumber`（チェックディジット・ダミー番号の除外）を通ったものだけ番号でまとめ、残りは `name:正規化名`。同じ会社が番号あり・なしで別に数えられることがある
- 落札率は記載のある契約の合計と件数を持ち、平均は表示時に計算（単純平均）
- 「同じ事業で1者応札が続く」は事業ID×年度で数える。2024年版シートは元データの約14%の契約に方式が無く落ちているため、連続の判定は保守的になる

## 分かったこと（2026-10-08 時点の生成結果）

- 1者応札が半数以上: 1,020事業者（1者応札 計1.59兆円）、同じ事業で1者応札が続く: 1,853事業者（2.05兆円）、競争なしの随意契約が主: 3,250事業者、同じ事業で随意契約が続く: 2,494事業者、落札率95%以上: 780事業者、3府省以上: 2,662事業者（一覧の下限以上の事業者で数えた値）
- 1者応札の金額上位（3年度合計）: 富士通 1,264億円（1者応札率85%・270/316件・落札率96.3%、同じ事業で1者応札が続く34事業：ハローワークシステム運営費 315億円など）、NEC 823億円（77%・38事業）、NTTデータ 790億円（82%・29事業）、アクセンチュア 639億円（46%・10事業）、JERA 505億円（100%・12/12件・落札率99.9%・石油備蓄）、日立製作所 419億円（74%・19事業）、三菱重工業 356億円（93%・落札率98.8%）
- 1者応札が続く事業はシステムの運用・保守（ハローワーク、防衛情報通信基盤、中央指揮システム、e-Tax、戸籍情報連携）に集中している。既存ベンダーの継続契約という性質があり、国会質問では「競争性の検証を誰がいつ行ったか」「PBL・原価監査」の形で問う

## 残る不足

- 年度またぎの同一契約の判定は事業ID単位。契約IDが無いため、同じ事業の中の別の契約を「続いている」と数える可能性がある
- 落札率の分母（予定価格）と、随意契約の理由区分は元データに無い（不足ドキュメント 1）
- 2段目以降（再委託先）の契約方式は記載要領の対象外。この一覧は国からの直接契約だけ
