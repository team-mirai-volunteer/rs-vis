## P3：中長期・データがない／範囲外

- **地方自治体を経由するお金・地方予算の可視化**：データがない。地方自治体向けの標準仕様は公開されているが、あとは各自治体に任されている（https://www.digital.go.jp/policies/local_governments ）。官民ファンド（例：NEDO の先）も同じ問題
- **国民健康保険中央会への約5,000億円**：個別に調べるテーマ
- **執行額の入力ミスの検証**：例として https://rs-vis.team-mir.ai/budget-sankey?year=2024&b=settlement&cols=rv%2Cac%2Cmi%2Cse%2Cpr%2Cps%2Cre&opr=2690&sel=project-spending-18695&ld=all 。外れ値・桁ずれの自動検出は新しい品質指標の候補
- **会計検査院との連携・予算化**：提言として扱う。2025年度予算は今まさに検査中、という理解で合っている
- **末端が任意団体の交付金**（中山間地域等直接支払、環境保全型農業直接支払、鳥獣被害防止など）：「不透明支出比が高い交付金」の上位には、不正の候補ではなく、末端が任意団体の事業が並ぶ可能性がある。スコアの読み方として説明ページに書く。提言として「市町村が活動組織を認定する時点で、地方公共団体コード＋連番の組織コードを振る」も記録しておく
- **★ 利用ペルソナごとの How to use ページ・解説動画**：作ってくれる人を募る
- **★ 議員・官僚向けの公開とレクチャー**：みらい以外の議員・官僚を想定

## 財政余力シミュレータ：「〇〇を実現するにはいくら必要か」

安野さんから「軽減税率を実現するとどうなるか分かるようにしてほしい」という要望があった。

- **現状**：消費税は1つの税率で近似している。対象品目のCPI比率・基準税率・1ポイントあたりの減収額は、詳細設定（`client/components/fiscal-space/Calibration.tsx:26-29`）で変えられる。ただし、利用者が政策と金額を自分で換算する必要がある
- **対応案：政策プリセット（実現メニュー）**：「食料品の消費税ゼロ」「消費税5%」などを選ぶと、`amounts` と `calibration.consumptionTax`（対象CPI比率・基準税率8%・減収額）をまとめて設定する。あわせて「年〇兆円必要」と根拠・出典を表示する。エンジン（`app/lib/fiscal-space/`）は変えず、プリセット定義と UI の追加で済む
- **決定（2026-10-03）**：今議論されている「食料品だけ1%」を、税率スライダーで動かせるようにする
- **実装**：消費税減税の欄に「全品目／食料品のみ（軽減税率）」の切り替えと「食料品の消費税率」スライダー（0〜8%）を追加した（`client/lib/fiscal-space-food-tax.ts`）
  - 「食料品のみ」を選ぶと、換算条件を次の値に切り替える：1ポイントあたりの減収0.6兆円、対象CPI比率22%、基準税率8%。8%→1%は年4.2兆円、税率ゼロで年4.8兆円が上限になる
  - 1ポイント0.6兆円は、財務省試算として報じられた「ゼロで年4.8兆円」を8で割った値。対象CPI比率22%は、家計調査2024で消費支出に占める軽減税率品目の割合
  - 計算エンジンは変えていない。全品目と食料品を同時に下げる設定はできない
- **歳入可視化との連動**：一方向のリンクも含めて今は入れない。混乱を避けるため、完全に連動する形まで設計が固まってから入れる（2026-10-03 決定）
- **要確認**：4.8兆円は報道で見た数字で、財務省の一次資料はまだ確認していない
