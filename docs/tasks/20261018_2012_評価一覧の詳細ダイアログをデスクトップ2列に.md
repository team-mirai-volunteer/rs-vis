# 評価一覧の詳細ダイアログをデスクトップで贅沢に使う（2 列化・推移グラフ拡大）

## 依頼

評価一覧（/quality）の事業詳細がページいっぱいに出るわりに、デスクトップでは横長に潰れて小さな文字が 1 列に流れる。サンキー図の詳細パネルとの情報の重複は構わないので、評価一覧の詳細は画面をもっと贅沢に使ってほしい。予算・執行額の推移ももっと大きくてよい。チームみらいのデザインスキルの指針も使う。

## 変更

| ファイル | 内容 |
|---|---|
| `client/components/quality/ScoreDetailDialog.tsx` | lg（1024px）以上で本文を 2 列グリッドに。左（3fr）= 事業内容・みんなの意見、右（2fr）= 政策評価・予算執行推移・概算要求・関連ページ・予算執行調査・決算検査報告。スコア計算根拠と支出先一覧はその下に全幅。文字サイズをデスクトップで引き上げ（タイトル 20px、総合点 60px、各軸 30px、本文 13〜14px）。共有部品には `scaleFont = px + 3` を渡す |
| `client/components/unified-budget/ProjectBudgetHistory.tsx` | `size="large"` を追加（高さ 260px・目盛り 5 本・線 2.25px・文字 12〜15px）。サイドパネルは従来の `default`（96px）のまま |
| `client/components/ProjectDescription.tsx` | `size="large"`（本文 14px・補足 12px）を追加 |

デスクトップ判定は CSS の `lg:` と `useMediaQuery('(min-width: 1024px)')` の両方で同じ境界を見る。共有部品（グラフ・概算要求など）は文字サイズを数値で受け取るため CSS だけでは切り替えられない。lg 未満は従来の 1 列のまま。

## デザインスキル（web-design-system）から適用した指針

- 最小文字 11px: ダイアログ内の 9px・10px を 11px に引き上げ（AI 評価バッジ、支出先ステータス、法人番号、指標ラベル）
- 余白の段階（8/12/16/24/32）: デスクトップのブロック余白を px-8（32）/ py-6（24）に揃えた
- 色は意味にだけ: 大きな数字は従来どおりスコア色（良・注意・悪）。見出し・本文は色字にしない。色トークンは変更していない
- このスキルは本来 LP 向けで「アプリ画面には使わない」とあるため、部品（ds.css）は持ち込まず、文字階層・余白・最小文字サイズの指針だけを当てた
