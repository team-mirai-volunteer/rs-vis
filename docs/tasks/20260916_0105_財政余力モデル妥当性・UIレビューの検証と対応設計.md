# 財政余力モデル：妥当性・UI レビュー（1-A〜1-H、P0〜P2）の検証と対応設計

対象コード: main 4e0db9d（モデル版 2026-09-16.4）。指摘の数値は 2026-09-16.3 で採られており、燃料輸入の接続で参考上限が 17.01→16.79兆円へ動いている以外、すべて現行でも再現した。

## 目的

`/fiscal-space` の利用者が、(1) 作動しない制約・結論を動かさない操作を「効いている」と誤読し、(2) 留保前の大きい数字や切断軸のグラフで効果を過大に受け取り、(3) 5年評価に内在する成長投資への構造的な不利を知らずに政策比較する状態を解消するため。

### 対応設計

**1-A 労働制約の再定義**
- 制約の指標を「就業者/労働力人口」から **NAIRU ギャップ** `(u* − u) / u*` に置き換える。`u*`（構造的失業率）は `ModelParameters` に既定2.5%として追加し、Calibration カードで 2.0〜3.0% を可変にする。初期失業率2.53%（2024年）が `u*` にほぼ等しいため、既定では政策なし経路は境界付近から始まる。閾値は「ギャップ0まで」を既定とし、判定は `u < u*` で違反。
- UI では「許容失業率下限 x%」を閾値の隣に併記し、旧閾値0.995 は削除する。共有URLの旧 `thresholds.labour` は `u*` へ換算して移行（`1 − labour閾値` を失業率下限とする）。
- 既存の説明「1 − 失業率に相当」「99.5%は失業率0.5%の仮定」は書き換える。`docs/fiscal-space-constraint-audit.md` に閾値の二値性の評価を追記。

**1-B multiplierScale の整合**
- 提案 (a) を採用し、`calibration.ts` で `prices`・`deflator`・`imports`・`exports`・`employment`・`longRate` にも同じ倍率を掛ける（公表反応全体の比例スケール）。表⑤の直接価格効果（税率由来の機械的部分）は倍率の対象外。
- Calibration の説明を「公表反応全体の倍率。0.5にするとGDP・物価・輸入・金利の反応が半分になる」に変更。`docs/fiscal-space-calibration.md` の「他の反応を固定」文言を更新。
- 検証: 倍率0.5でCPIピークと参考上限が変わること、倍率1で既存テスト不変。

**1-C 5年評価の構造的バイアスの明示**
- 単独政策比較（`compareNextTrillion` の表）に「公表期間内の実現供給便益」列を追加し、非資本種別は「0（設計上、公表期間後に立ち上がり）」と表示。潜在GDPには加算されている旨も注記。
- 主画面の参考上限の直下に、同じ配分の長期シナリオ（`longRun`）の30年目 債務/GDP 差と供給便益合計を1行で並置し、長期カードへリンクする。評価期間の既定は変えない。

**1-D 三時点の表示**
- Summary の「評価最終年の結果」を「拘束年（CPIピーク年）・GDP効果ピーク年・最終年」の3列表に置き換える。各列に CPI、実質GDP効果、就業/労働力、債務/GDP。
- 判定基準の選択肢を追加: 現行「単年ピーク」に加え「期間平均CPI」。`Thresholds` に判定方式を持たせず、`peakConstraints` に集約方式の引数を追加して切り替える。URL に `inflationRule: 'peak' | 'average'` を追加（既定 peak）。

**1-E 近似式を見出しへ**
- 参考上限カードの見出し直下に「この条件では CPI 上限が単独で枠を決めています。近似: (上限 − 政策なしCPI x%) ÷ 0.0xx pt/兆円 ≒ y 兆円」を表示（拘束制約が物価のとき）。他の制約が拘束する条件（CPI上限2.8%超、労働閾値変更、建設・研究への配分）を1文で示す。近似式は既存の感応度計算（`constraintSensitivity`）から導出し、新たな推定は置かない。
- `docs/fiscal-space-opus-review.md` L36 の「採用しない」判断を、「既定近傍では物価単独」と明示する方針へ更新。

**1-F 為替の関係説明**
- RiskAudit の為替ストレス表の直前に「公表CPI反応には参照モデルの為替反応（5年目 −0.43%）が含まれる。下表の +10% 円安はそれに追加する外生ストレス」と明記。モデル計算は変更しない。

**1-G 見出し**
- ページ見出しと `<title>` を「財政余力（実物制約の条件比較）」とし、リード文で「債務持続性の判定ではなく、物価・労働・電力・産業能力の実物制約が5年内でどこまで許すか」を先に述べる。

**1-H 投入指数の帰結**
- 生産モデル比較カードに「最大GDP能力 = 実質GDP × 最小投入指数（現在 1.08 → 余力 7.25%）」を表示し、労働1.03 の感度行を追加。`docs/fiscal-space-production-model.md` に帰結を追記。

## 2. UI / 可視化：検証結果と対応

## 実装順の提案

1. P0 の6件（数字の誤伝達を止める。モデル変更なし）
2. 1-B、1-A（モデル変更。モデル版を上げ、旧URL移行）
3. 1-D、1-E、1-C（表示の再設計。モデル変更なし、`peakConstraints` の集約方式追加のみ）
4. P1、1-F、1-G、1-H
5. P2

各段階で `npx tsx --test tests/fiscal-space*.test.ts` と `node tests/fiscal-space-review-browser.mjs` を実行する。1-A・1-B は既存の固定値テスト（15兆円例など）の更新を伴う。

## レイヤー整合性

- 1-A・1-B・1-D の計算変更は `app/lib/fiscal-space/`（`constraints.ts`、`calibration.ts`、`assumptions.ts`）に限定。
- 近似式・三時点表・長期並置は既存の計算結果の再表示で、`client/components/fiscal-space/` のみ。
- 閾値の範囲・URL 版情報は `client/lib/`。API 層・`scripts/` は変更なし。

## 対応しないこと

- 為替の内生化（二重計上回避の現行設計を維持）。
- 5年評価の既定期間の変更（公表期間内に限定する判断を維持）。
- NAIRU の推定。`u*` は利用者が置く仮定として扱い、推定値の幅（2.3〜2.7%）を注記に示すのみ。
