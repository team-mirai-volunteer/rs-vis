# 経済状態・評価条件のポップアップ化

## 変更

- 政策の操作パネル末尾に、経済状態・評価条件、乗数・労働反応の条件、政策別の供給力・長期条件の順で設定ボタンを配置。
- 経済状態・評価条件の展開欄をネイティブのモーダルダイアログに変更。既存の入力と計算への接続を維持。
- ポップアップの見出しと閉じるボタンを上部に固定。末尾にも「設定を閉じて結果を見る」を設置。
- Escapeで閉じ、起動ボタンにフォーカスを戻す。PC・モバイルとも操作パネルから開ける。Escapeが親パネルにも伝わって両方を閉じないようにする。

## 検証

- TypeScript型検査。
- PCで5年推移を表示したまま評価期間を変更して結果へ戻る操作。
- モバイルでボタンの順序、開閉、フォーカス復元、経済状態の変更と共有URLからの復元。
- 財政シミュレータの画面テストは15件を実行。14件成功後、モバイルのEscape伝播を修正し、操作パネルの2件を再実行して成功。全15ケースの成功を確認。
