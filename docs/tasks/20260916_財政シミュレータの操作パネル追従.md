# 財政シミュレータの操作パネル追従

操作パネルのsticky配置が冒頭の結果欄のグリッド内で終わり、下部の「5年間の状態遷移」ではパネルが画面外へ出ていた。

- PCではすべての結果・詳細条件を同じ右カラムに収め、左の操作パネルがページ下部まで追従する。画面高を超える操作項目はパネル内でスクロールでき、結果の位置は維持する。
- 1024px未満では画面下に年額合計と「政策を調整」ボタンを固定。開いたパネルは画面高の45%を上限として内部スクロールし、閉じるとその場で結果を読める。PC・スマホとも同じ入力DOMと状態を使用する。
- 「乗数・労働反応の条件」「政策別の供給力・長期条件」を下部から操作パネル起点のダイアログへ移した。発電設定と同じく変更は直ちに計算へ反映し、Escapeや閉じるボタンで開いたボタンへフォーカスを戻す。既存の共有URLと計算処理を使用する。
- スマホの計算中表示は画面上側に置き、画面下のパネル開閉ボタンを遮らない。

ブラウザ検証では、5年間の推移を表示したまま政策額・評価期間を変更できること、スマホで設定を開閉してもページ位置が変わらないこと、両ダイアログの入力と共有URLからの復元を確認する。評価期間を3年にしても公表モデルの5年推移は維持する既存仕様。

型チェックと関連ブラウザテスト15件が成功。PCとスマホの操作パネル・供給力設定ダイアログはスクリーンショットでも確認した。
