# 費用対内容への「国富増強」観点の導入検討

きっかけ: 2025年度の半導体事業の費用対内容が低い（ポスト5G基盤強化 3.67、先端半導体の国内生産拠点 6.0、省エネ半導体 5.0〜5.67）。供給力・自給率・貿易赤字削減に寄与する産業なら、国富増強の観点で評価してよいのではないか、という指摘。

## 1. なぜ低いのか（所見の実物）

| pid | 事業 | 費用対内容 | 所見 |
|---|---|---:|---|
| 3522 | ポスト5G基盤強化研究開発 | 3.67 | 基金9901.8億円÷採択31件＝約319億円/件、最終配分不明 |
| 19958 | 先端半導体の国内生産拠点の確保 | 6.0 | 4713.9億円÷認定6件＝約785.7億円/件、基金残高が大きく単価検証困難 |
| 3957 | 省エネ半導体（製造基盤強化） | 5.0 | 25.1億円÷開発件数不明で単価不能、企業開発費中心 |
| 7167 | 次世代半導体に関する調査 | 2.0 | 執行4.9億円÷調査件数不明、BCGに83%集中 |

下げている要因は「重要でない」ではなく、次の2つ。

- **分母が「件数」しかない**: 採択31件・認定6件で割ると1件あたり数百億円になり、それが見合っているかを判断する材料が無い。プロンプトは「本文から活動の規模を表す数量を拾う」と指示しているが、拾えるのが件数だけだと巨額の件数単価が出て中位以下に落ちる。
- **基金滞留**: 「資金の停留: 基金や執行管理法人で資金が止まり、最終的な配分先が追えない」を減点対象にしている。半導体は基金経由がほとんどで、この減点を必ず受ける。

## 2. 現行設計との整理

- 費用対内容は「金額が活動内容と規模に見合っているか」「その金が誰に渡っているか」の軸で、**事業の重要性は見ない**設計（「金額が大きいこと自体は減点しない」「必要性の弱さは減点しない」を明記）。重み35と最重なのは「所管庁の作文で動かせない軸」だから。
- 重要性・国益は必要性（段階4）の担当で、半導体はそこで既に高い（19958 は 7.67「国内産業が半導体供給を失う。輸入依存は割高」、3522 は 7.33）。
- したがって「重要だから費用対内容を上げる」は軸の混線になる。一方、**「何を買っているか」の分母を件数から供給力へ変える**のは費用対内容の本来の問いに沿う。

## 3. 提案: 分母を「国富の獲得量」にする

段階3に「供給力・自給率投資の単価換算」を追加する。

1. **分母の優先順位**: 産業政策・エネルギー・供給網強靱化の事業では、件数より先に次を探す。
   - 獲得する生産能力（枚/月、GW、トン/年）
   - 自給率・国産化率の変化（%ポイント）、輸入代替額・貿易赤字削減額（億円/年）
   - エネルギー自給への寄与（kWh、原油換算）
   - 創出雇用・国内投資誘発額
   これらが概要文・成果指標に**数値で**示されていれば、それを分母に単価換算し、件数単価の大きさだけで下げない。
   例: 「4713.9億円で国内先端ロジック生産能力〇万枚/月を確保＝〇億円/千枚」。
2. **数値が無い場合は現状どおり**: 「重要産業である」「経済安全保障上不可欠」だけでは分母にならず、件数単価と配分の粗さで判定する。所管庁が国富への寄与を数値で書けば上がる、という作文インセンティブを与える。
3. **基金滞留の減点を条件付きにする**: 認定件数・認定額・交付済み額が示されていれば「最終配分が追える」とみなし、滞留減点を軽くする。残高だけが大きく配分先が書けない場合は現状どおり減点。
4. **国民便益の原則に「国富増強」を明記**: 冒頭の原則の「国内産業への波及」を「国富増強（自給率向上・貿易赤字削減・エネルギー自給・供給途絶リスクの低減）」と具体化する。必要性の「国民が失うもの」の例にも供給途絶・輸入依存を加える。

## 4. 影響と注意

- 半導体・蓄電池・LNG・再エネ・食料など供給力系の事業で費用対内容が上がる可能性がある。ただし数値が示された事業だけ。
- 費用対内容アンカー（proportionalityAnchors）に供給力投資の事例が無いため、テキストアンカー（score 7 前後: 「巨額だが獲得する供給力が数値で示され単価が説明できる」）を1つ足す必要がある。
- 再採点は費用対内容だけの差分実行ができないため全件・3票（約15ドル・1時間強）になる。
- 価値判断を含む変更（「国富」を評価に入れる）なので、実装前にユーザーの確認を取る。

## 5. 実施記録（2026-09-14）

ユーザー確認のうえ、役割分担を次のとおり実装した（unified v15、キャッシュキー `U9:`）。

- **共通原則**: 国民便益の具体例に「国富増強＝自給率向上・貿易赤字削減・エネルギー自給・供給途絶リスクの低減」を明記。
- **段階3（費用対内容）**: 供給力を買う事業では件数より先に生産能力・自給率変化・輸入代替額・エネルギー自給寄与を分母に探す。数値で示されていればそれで単価換算し、件数単価の巨額さでは下げない。数値が無ければ従来どおりで、重要性は分母にしない。基金滞留は認定件数・認定額・交付済み額で配分が追えれば軽い減点にとどめる。
- **段階4（必要性）**: 「国民が失うもの」の例に供給途絶への耐性・自給率・エネルギー自給・貿易収支を追加。数値・事実で示された場合に限り、抽象的な「経済安全保障」だけでは認めない。
- **アンカー**: 費用対内容に score 7 のテキストアンカー（巨額・基金経由だが供給力が数値で示され配分を追える）を追加。`schemaVersion` 16。
- **UI**: `score-meta.tsx` の費用対内容説明を同期。
- 重要性そのものを費用対内容で加点する変更は入れていない。
