# 基金シートで確認できること

基金について懸念が出ているという話を受けて、RSシステムのデータで何が確かめられるかを調べた（2026-10-05）。

## データの所在

- RSシステムには事業のレビューシート（`sheet_type=RS`）とは別に、**基金シート（`sheet_type=KS`）** がある。2025年版で340件。
  - ほかに `SS`（272件。独立行政法人などのシートで、基金の項目は空）がある。
- これまでの取得（`scripts/fetch-rs-api.mjs`）は `sheet_type=RS` だけだったため、基金の項目はすべて空だった。
- 調査用に、2025年版の基金シートを `data/rs-api-funds/ks-2025.json` に取得した（Git管理外）。
- 基金シートの主な項目:

| 項目 | APIのフィールド |
|---|---|
| 基金保有法人 | `fund_owner` |
| 造成年度 | `composition_backgrounds_fiscal_year_of_creation` |
| 終了予定日 | `scheduled_end_end_date` |
| 新規受付の終了日 | `scheduled_end_end_date_of_new_application_receiving` |
| 年度初めの基金残高 | `beginning_of_the_fund_balance` |
| 前年度の国庫返納額 | `previous_year_amount_returned_to_the_national_treasury` |
| 前年度の管理費・管理費率 | `previous_year_administrative_expense`・`previous_year_administrative_expense_rate` |
| 前年度の収入・支出 | `previous_year_total_income`・`previous_year_total_expense` |
| 乖離率 | `previous_year_divergence_rate` |
| 保有割合 | `ownership_ratio` |
| 事業の形態（補助・補償など） | `business_forms` |
| 運営の形態（取崩し型など） | `operation_forms` |

## 2025年版での集計（府省の記載どおり。検証はしていない）

| 観点 | 件数 | 残高など |
|---|---|---|
| 基金シート全体 | 340 | 年度初めの残高 計17.6兆円 |
| 新規受付を終えたのに残高がある | 38 | 1.78兆円 |
| 終了予定日を過ぎても残高がある | 3 | 57億円 |
| 残高が前年度の支出の10年分以上 | 84 | 8.36兆円 |
| 残高はあるが前年度の支出がゼロ・不明 | 12 | 893億円 |
| 前年度に国庫返納があった | 52 | 返納 計1.15兆円 |
| 管理費率10%以上（支出1億円超） | 29 | — |
| 乖離率の絶対値が50%超 | 54（記載172件中） | — |

残高の上位はグリーンイノベーション基金（2.31兆円）、特定半導体基金（1.56兆円）、ポスト5G（1.44兆円）、燃料油価格激変緩和（1.20兆円）、蓄電池の安定供給確保（9,578億円）。

前年度の支出に対して残高が極端に大きいもの（残高100億円以上）には、重要鉱物の安定供給確保（1,060億円、前年度支出ほぼゼロ）、電子部品の安定供給確保、防衛装備移転円滑化などがある。造成直後で支出がまだ立ち上がっていない基金も含まれるため、年数は目安にとどまる。

## 読み方の注意

- 金額・率は府省の記載どおりで、このサイトでは検証していない。
- 「保有割合」「乖離率」の正確な定義は、基金シートの記載要領で確かめてから画面に出す。
- 残高が大きいこと自体は問題ではない（複数年度の事業を前払いで造成する制度のため）。新規受付の終了後や終了予定日の後に残っている残高、支出に比べて過大な残高、国庫返納の状況が論点になる。

## 次にできること（案）

1. 取得スクリプトで基金シート（KS）も取るようにし、2024〜2026年版をそろえる。年度をまたいで残高の推移を追える。
2. 「基金」一覧のビューを作る。上の観点で絞り込み・並べ替えができ、基金ごとに保有法人・残高推移・支出・国庫返納・終了予定を出す。
3. 基金を造成した事業（RSシートの補助金など）と基金シートをつなぐ。サンキー図の支出先（例: NEDO）から、その法人が保有する基金に飛べるようにする。

## 実装（2026-10-06）

- 取得: `node scripts/fetch-rs-api.mjs {年} --sheet KS`（`npm run fetch-rs-funds`）で、基金シートの一覧・詳細・支払先を `data/rs-api-ks/{年}/` に取得。2024年版322件・2025年版340件・2026年版328件。
- 生成: `scripts/generate-funds.ts`（`npm run generate-funds`）で、基金（lineage_id）ごとに3年度をまとめた `public/data/funds.json` を作る。354基金。
- 基金一覧 `/funds`: 論点（新規受付の終了後も残高・終了予定日の後も残高・残高が支出の10年分以上・支出ゼロ・国庫返納・保有割合1超・低執行の点検に該当）で絞り込み、残高・支出・残高÷支出・国庫返納・管理費率・保有割合・終了予定で並べ替え。詳細に3年度の推移・造成の経緯・造成元の事業・必要性・保有割合の根拠・点検結果。
- つなぎ込み: 支出先の説明に「この法人が保有する基金」（保有法人名で一致。例: NEDO は19基金）、事業の詳細パネルに「関連する基金」（基金シートの関連レビューシート・造成の経緯で引き当て。118基金）。
