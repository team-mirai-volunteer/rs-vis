# 税収弾性値と反応条件の検証

## 変更

- 税収弾性値の初期値を1.1から1.3に変更。GDP乗数の感度倍率は1のまま。
- 共有URLに明示された旧値1.1は保持する。新規設定とリセットには1.3を適用。
- 政府の従来値1.1、現在の後年度試算1.2、2015〜2024年度実績から計算した1.7を区別して説明。
- 消費税完全転嫁の意味、海外の部分転嫁の実証例、設定の影響範囲を説明。日本の減税の推定値が得られていないため、海外の70%を日本の初期値として採用しない。

## 出典と解釈

### 税収弾性値

[2026年4月10日財務金融委員会](https://www.shugiin.go.jp/Internet/itdb_kaigiroku.nsf/html/kaigiroku/009522120260410006.htm)で財務省は、2015〜2024年度の10年間の実績から幾何平均を用いた計算値を1.7としている。期間の選び方や名目成長率の小ささで値が変わり、政策による追加GDPに対する因果効果を同定した係数ではない。

[2026年度予算の後年度影響試算](https://www.mof.go.jp/policy/budget/topics/outlook/sy2026a.htm)は1.2を使用。[2025年2月14日予算委員会](https://www.shugiin.go.jp/internet/itdb_kaigiroku.nsf/html/kaigiroku/000121720250214005.htm)で従来の1.1から1.2への見直しを説明している。

このアプリの税収は一般政府の税・社会保険料であり、国の一般会計税収と範囲が違う。初期値1.3はユーザー指定の比較仮定。国税の実績値を社会保険料まで実証済みとして扱わない。

### 消費税価格転嫁率

[日銀2018年7月展望](https://www.boj.or.jp/mopo/outlook/gor1807a.htm)は増税の直接CPI効果の計算で完全転嫁を仮定する。100%は機械的な比較基準として成立するが、減税の観測値ではない。

[Fuest・Neumeier・Stöhlker（2021）](https://www.ifo.de/cesifo/publikationen/2021/working-paper/pass-through-temporary-vat-rate-cuts-evidence-german-supermarket)はドイツ2020年の一時的VAT減税について、スーパーの価格低下約1.3%、転嫁率約70%を報告。復税との非対称性もある。日本・全品目・恒久減税へそのまま外挿できない。

基準税率10%、対象CPI比率85%で1ポイント減税すると、直接CPI水準効果は `−0.01 / 1.10 × 0.85 × 転嫁率`。100%で約−0.773%、70%で−0.541%、50%で−0.386%。これは間接効果を加える前の固定価格換算であり、画面の年間インフレ率そのものではない。

## ポップアップの全数値設定の点検

21項目についてUIの範囲・単位変換と計算側を確認。下表の初期値は、断りがない限り推定済みの日本固有係数ではなく感度仮定。

| 項目（初期値） | 接続・検証結果と限界 |
| --- | --- |
| 税収弾性値（1.3）、反映ラグ（0年） | 税収は初期税収×名目GDP比の弾性値乗−有効な減税額。ラグ期間中は初期GDPを使う。5年間の式と一致。税目別・保険料別の分離なし。 |
| ギャップ需要感度（3）、物価感度（5） | 初期ギャップに対する指数補正。指数を−1〜1に制限。未推定の景気依存性。 |
| 基準インフレのギャップ係数（0.05） | 政策なし経路のインフレ補正。公表モデルと別の仮定。 |
| 基準借換金利（2%） | 既存債すべてに即時適用せず、借換・新発へ適用。GDPへの追加金利波及は未推計。 |
| 消費税1ポイント減収（3.5兆円） | 年額と税率ポイントの換算。軽減税率等の対象を変えるときは他の税設定も変更が必要。全対象に共通する観測値ではない。 |
| 消費税対象CPI比率（85%） | 価格効果の重み。CPIの非課税・帰属家賃等を含む品目構成から再推定した値ではなく、精密な日本の物価予測には再較正が必要。 |
| 対象税率（10%、8%へ切替可能） | 税込価格を分母に使用。複数税率同時の変更は単一税率近似。税率ゼロを超える減税は拒否。 |
| 価格転嫁率（100%） | 直接CPI・デフレーターに作用。0/50/70/100%の算術検証を実施。実質GDP・輸出入・雇用の公表反応は再推計しない。未転嫁分の企業利益への帰着と二次波及は未実装。 |
| 表⑤から分離する直接CPI効果（0.78%/pt） | 公表表⑤から直接効果を分離するための仮定。表自体が直接・間接を識別した値ではない。変更すると残余の間接価格効果も変わる。固定の直接デフレーター0.50%/ptも同様。 |
| 輸入エネルギー費のCPI転嫁係数（0.25） | 輸入費増分/GDPから物価への係数。消費税転嫁率とは分母が異なる。 |
| 輸入価格の国内転嫁（50%） | 回収できない輸入費上昇を名目付加価値から差し引く。実質所得減から実質GDPへの二次波及なし。 |
| 既存歳出のCPI連動（100%） | 当年の累積CPIで既存歳出の実質額を維持する強い仮定。制度別の改定時期・ラグ・固定契約は未反映。0%は基準名目歳出経路。 |
| GDP乗数感度（1倍） | 実質GDP反応のみ変更。他の公表系列を再推計する全体モデルの設定ではない。説明を追加。 |
| 社会保険料本人配分（50%） | 本人・事業主に一度だけ配分し、所得税・法人税の公表反応を代用。折半は比較仮定。 |
| 時間・参加・事業主労働需要の弾力性（すべて0） | 追加反応を未算入。供給増をそのまま短期GDPへ加算しない。参加率は100%以内。 |
| 手取り労働所得/GDP（40%）、雇用コスト/GDP（55%） | 本人の賃金増・事業主のコスト減への換算分母。人口全体の所得・雇用データから再推定した値ではない。 |

[Chettyほか](https://www.nber.org/papers/w16729)の時間0.3・参加0.25は補償弾力性の整理であり、日本全体の減税反応として直接推定したものではない。現在の説明はその区別を維持している。

## 検証範囲

- 新規テスト：税収弾性値6通り×ラグ3通りの5年経路を税収の式と照合。
- 新規テスト：税率2通り×CPI比率3通り×転嫁率4通り。直接価格の算術、終了時の直接価格効果消滅、実質GDP反応が転嫁率で変わらない制限を確認。
- 新規テスト：21数値設定の上下限を一つずつ変え、2参照モデルで計84経路・各5年を検証。公共投資・所得税・保険料・消費税の混合政策に輸入価格30%上昇・金利1ポイント上昇を加え、状態の有限性・正の名目GDP・参加率・財政恒等式を確認。
- 財政関連ユニットテスト148件成功、TypeScript型検査成功。
- PC・モバイルのパネル、ポップアップ、共有URL、新規弾性値と参照説明を含む画面テスト15件成功。
- UIの例示配分は弾性値変更により5年目税収245.00→252.92兆円、国民負担/GDP30.41→31.39%。公表反応の実質GDP経路や、CPI・供給制約で決まる探索上限は変わらない。

境界値テストはすべての係数の同時極端設定や実証妥当性を保証しない。今回、検証した範囲では計算の破綻・単位誤りは見つからなかった。一方で転嫁率や歳出連動率100%などは強いシナリオ仮定であり、現実を予測する既定値として裏づけられたものではない。
