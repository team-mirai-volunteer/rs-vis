# LP ブラッシュアップ（lp-production スキルの作法で）

対象: `/lp`（app/lp/page.tsx、components/lp/PolicyCases.tsx）。チームみらいのプラグイン 1.2.0 の `lp-production` スキルで監査し、ブリーフを書いてから直した。

## ブリーフ

```
■ 読み終えたときに思ってほしいこと：「国の予算は公開データでここまで追えるのか」と思って、サンキー図を開く
■ いちばん押してほしいボタン：予算の流れを見てみる（/budget-sankey の 2024 年度決算）。冒頭・最後の CTA・スマホの下部固定
■ 主に読んでほしい人：議員・政策秘書／中身を確かめに来る人：記者・研究者、市民
■ ページの型：サービス紹介（product-launch）に近い。違う点：製品画面の代わりに「分かったこと」（公開データの集計）が主役
■ 書き直しの範囲：自由に書き直し。ただし数字・事例・出典は insights.ts にあるものだけ
■ 見出しだけの流れ
  冒頭：国の予算は、ここまで見える。
  分かったこと：公開データをつなぐと、見えてきたこと
  使い方：3ステップで、根拠つきの問いにする
  政策の選択肢：数字の先に、政策の選択肢をつくる
  国会質問の試案：国会質問の設計（台本つき12本＋3本）
  ビュー一覧：ひとつのデータを、9つの見方で
  データについて：数字は公開元の記載どおり。出典と前提をここに書いています
  次の一歩：公開データから、根拠つきの問いへ
■ 載せないもの：「こんな人に」のセクション（冒頭のリードで読み手を名指ししているので重複）、示唆カードの装飾番号 01〜15
■ まだ決まっていないもの：なし（未確定の値は無い）
■ 参考にするもの：なし
■ 推定・仮置きしたもの：最後の CTA の安心材料「登録不要・無料。公開データだけで動いています」
```

## 監査で見つかった点と対応

| 観点（checklists.md） | 見つかったこと | 対応 |
|---|---|---|
| 英字のラベル | Insights / How to / For the Diet / Who / Views / From data to policy | 日本語の正式名（分かったこと・使い方・政策の選択肢・国会質問の試案・ビュー一覧・データについて）。フッターの「このページの構成」と同じ文言 |
| 文字リンクの見た目 | 8 種類（下線あり/なし、offset 2/4、hover:underline、opacity） | 1 種類 `TEXT_LINK`（ブランド文字色・太字・ホバーで下線）。外部は ↗、ページ内は ↓/↑、ビューへは → |
| 開閉の部品 | 4 種類 | カード内の開閉は 1 種類 `SUMMARY_LINK`（文字リンクと同じ見た目＋矢印）。「残りの 12 件を見る」は副ボタン（Button outline と同じ見た目） |
| タップ領域 | 24〜31 の文字リンクが 24px 未満 | 文字リンクに上下 8px の当たり判定を足す（見た目は変えない） |
| 装飾の番号 | 示唆カードの 01〜15 | 削除（参照に使っていない） |
| 主 CTA | 冒頭に 3 ボタン。最後の CTA が「データについて」のカード内 | 最後の CTA を背景色のセクションに独立。スマホでは下部固定 CTA（冒頭と最後の CTA が見えている間は隠す） |
| スマホの縦の長さ | 375px で 17,212px（PC 1280px の 2.0 倍） | 「こんな人に」を削除、ビュー一覧を 2 列・名前だけ、国会質問の一覧でタグと委員会名を隠す |
| フッター | 構成の一覧が無い | 「このページの構成」（6 セクション）を追加 |
| 見出しの階層・小さい文字・未確定の値・リンク切れ | 問題なし | — |

変えていないもの: h1 の句点（タイトルロゴ扱い）、冒頭の副ボタン 2 つ（事業／企業・事業者の検索導線は #21 で分けた決定）、色（アプリ共通のトークン。LP だけ別の色にはしない）。
