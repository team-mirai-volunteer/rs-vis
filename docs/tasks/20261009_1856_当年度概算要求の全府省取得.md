# 当年度概算要求の全府省取得（2026-10-09）

## 対象と結果

2026年に公表された2027年度（令和9年度）向け概算要求を、[財務省の当年度索引](https://www.mof.go.jp/policy/budget/budger_workflow/budget/fy2027/index.html)から収集した。過年度の要求は対象外。

- 34府省・機関等、846資料・掲載ページ。原本取得836件、取得待ち0件、HTTP取得失敗10件
- 28機関・100資料から39,352行。46資料は抽出警告なし、54資料は一部抽出
- 数値未対応・抽出対象外660資料（歳入41資料を含む）、掲載ページ76件
- 旧カタログ1,432件から過年度・無関係なナビ等834件を除外し、当年度の248件を追加。除外した資料に抽出行はなかった
- 新たに原本の取得成功が確認できた資料・ページは679件。保存済みの同一原本は取得日時・ハッシュを維持して再利用
- 既存22,382行のID消失0、同一原本に対する既存要求額の変更0。追加16,970行は国土交通省10,645行、内閣府3,202行、農林水産省3,123行

資料数は事業数や政府全体の網羅率ではない。階層行・親子・概要版・分割版・一括版には重複があり、資料横断の金額合計は作らない。HTTPで読めない掲載先の全資料数は把握できていない。

## カタログの年度・範囲修正

- 年度を含む親見出しを下位見出しに継承。農村振興局の417件には過年度394件と年度不明の配分ページ1件が含まれ、当年度の22件に限定した
- 段落・リスト項目の年度区切りにも対応。復興庁の過年度政策一覧への逸脱を除いた
- 公開年度の見出しの下に翌年度要求を掲載する消費者庁等では、リンク自身の明示年度を優先
- MEXT/環境省のCMSディレクトリ名やデジタル庁の公開年度を、要求年度とは取り違えない
- HTMLコメント内の外務省CMSプレースホルダー、サイドバー、フッター、複数リンク間の文脈混入を除外
- 保存済みHTMLで明確に範囲外と確認できた旧項目も整理。見つからないリンクだけを理由に消失扱いにしない。原本は削除しない
- 年度のない部局別予算入口はたどり、その中の年度区切りで限定。農水の消費・安全局、林野庁、環境省のエネルギー特会まで届くよう既定の探索深度と続行判定を3階層にそろえた
- ページ取得失敗時もハッシュ検証済みHTMLがあれば当年度リンクの取得を続行し、ページ自体の失敗表示を残す

## 原本・金額の検証

全836件の保存ハッシュを照合。重複を除く原本は822ハッシュ・1,613,894,476バイトで、ハッシュ不一致0、PDFリンクにPDF以外が返ったもの0。

40MBの通常取得上限を超えた5本は、公表サイズを確認したうえで今回のみ400MiB/本を上限に別途保存した。合計664,844,905バイト。通常の自動更新上限は40MBのままなので、大容量資料の将来の再取得にはこの制約が残る。歳入41本も原本は保存し、再抽出時にも歳出額に混ぜないガードを追加した。

原本の別系統のPDF座標抽出による照合で、国土交通省・内閣府の14,392行（既存行を含む）について要求額・単位換算・空欄状態の不一致0を確認した。組織ごとの重複しない内訳を使った照合例は以下の通り。

厚労省の`05-1b-01.pdf`（1,732ページ）と`05-2b-01.pdf`（761ページ）は、表紙で令和9年度を確認。文字が輪郭線に変換されて文字層がなく、視覚読取/OCRが必要なため数値未対応。画像だけのPDFと断定せず、原本取得済み・文字抽出未対応として扱う。

[農水の全体概要](https://www.maff.go.jp/j/budget/pdf/r9yokyu_gaiyo.pdf)や[フードテックの事業概要](https://www.maff.go.jp/j/budget/pdf/r9yokyu_pr002.pdf)には読める値があるが、自由レイアウトなので構造化行には追加していない。例えば後者の1ページには50,214百万円がある。概要の未対応を金額不在や0円と扱わない。[日本型直接支払](https://www.maff.go.jp/j/budget/pdf/r9yokyu_pr011.pdf)の事項要求も0円に置換しない。
