# AIレビュー（docs/ai-review）をLP水準に引き上げる：示唆と国会質問

`docs/ai-review/` の4本（仕分け最終レポート 12.51億円、ストレッチ版 411.77億円、租特の試行評価、賃上げ税制の分析仕様）を読み直し、
`/lp` の示唆カード（横断集計の数字 → 内訳 → 読み方の注意 → 確認リンク）と国会質問（参考人／大臣／主意書を分けた台本）と同じ水準に組み替えた。
質問の設計原則は `20261008_0230_LPを読んでの示唆と国会質問の設計.md` に従う。

集計は 2026-10-08 に `public/data` の生成物（2025年版レビューシート＝2024年度実績、2024年度租特適用実態）から行った。定義は末尾。

## 1. 旧レビューの何をLP水準に変えるか

| 旧レビュー | 弱点 | LP水準にするには |
|-----------|------|----------------|
| 4事業・31明細に削減率を掛けて12.51億円 | 削減率が仮定で、4事業は全体の縮図ではない。画面で再現できない | 「削減額」を捨て、同じ現象（広報・事務局・企画競争）を**5,794事業の横断集計**にして、政府に出させる数字に変える |
| ストレッチ版411.77億円（住宅348億円が85%） | 外部の予算額に政策的な率を掛けたもの。レビューシートの裏付けがない | 住宅補助は「事務局が誰で、事務費がいくらか」というシートで裏付けられる論点に戻す |
| 租特の試行評価（7区分・5軸） | 評価点は編集的判断で、国会で使えるのは「因果推計がない」という事実だけ | 適用額の規模と伸びを数字で示し、期限前の検証を約束させる質問にする |
| 賃上げ税制の13社パネル | 標本が薄く、因果は出せない | 「政府は個票を持っているのに推計を公表していない」という問いの根拠に使う |

旧レビューの最大の収穫は、仕分けの過程で**広告代理店が補助金事務局になっている構造**（子育てエコホーム→博報堂）と**企画競争の1者応募・落札率100%**（国際広報→電通PRコンサルティング）を見つけたこと。横断集計すると、どちらもLPの代表カードになる規模だった。

- **body**: 一般競争・指名競争の1者応札48%（LP既出）とは別に、「企画競争」と「公募」という随意契約の形式がある。企画競争4,192件・3,509億円のうち1,522件（36%）が応募1者で、公募3,880件・1.12兆円のうち3,016件（78%）が応募1者。応募1者の平均落札率は企画競争99.6%、公募98.6%。

### I-3. 広報・広告の外注は年781億円。成果指標は「放送回数」止まり

- **figure**: 781億円 ／ 民間への広報・広告・周知の委託（1,617件・402事業）
- **body**: 契約概要に広告・広報・PR・周知を含む民間への直接支出は1,617件・781億円。政府広報の中核3事業（国内広報経費45億円、国際広報経費31億円、ジャパン・ハウス運営44億円）は計120億円が4年間ほぼ横ばいで、成果指標は放送回数・掲載回数・来館者数。認知度や行動変化のアウトカム指標がないか、実績が空欄。
- **points**:
  - 国内広報経費の指標は「テレビ定時番組の放送回数52回」「新聞突出し広告30回」などアウトプットのみ。国際広報経費のアウトカム「対日好感度の変化」は実績が空欄。ジャパン・ハウスは来館者数（サンパウロ 55.8万人、目標60万人）のみ
  - 同じ内閣府の戦略的広報経費（事業ID 96）には「テレビCMの認知度21.1%」「理解度48.6%」の実績がある。測れないのではなく、測っていない
  - 広報系の競争入札498件のうち応札1者は150件（30%）。1者応札の落札率91.1%に対し複数応札は78.7%で、差は12ポイント
  - 広報系の最大契約はアクセンチュアの出産費用情報サイト「出産なび」304億円（開設・保守運用・広報を一式）
- **caveat**: 「広報」の判定は契約概要の文字列で、システム開発や相談窓口を含む契約も混じる（出産なびが典型）。旧レビューの12.51億円削減案は媒体費の率を仮定したもので、この集計の根拠にはしていない。
- **href**: `/quality?pid=5508`（国内広報経費の支出先と成果指標を見る）
- **source**: 2024年度実績（2025年版レビューシート）の支出先・成果指標

### I-4. 賃上げ税制の減収は2年で1.9倍、9,560億円。追加性の推計は公表されていない

- **figure**: 9,560億円 ／ 賃上げ促進税制の適用額（2024年度・29.4万件）
- **body**: 法人税の租税特別措置のうち賃上げ促進税制の適用額は2022年度5,040億円から2024年度9,560億円へ1.9倍。研究開発税制1兆69億円に次ぐ規模で、中小企業の軽減税率4,713億円の2倍。政府の検証資料にはパネル分析とマクロ分析があるが、税制がなくても起きた賃上げと税制が生んだ賃上げを分けた因果推計はない。適用期限は2027年3月31日。
- **points**:
  - 規模別の内訳（2024年度）：大企業向け 4,507億円、中堅企業向け（2024年新設）1,723億円、中小企業向け 3,330億円
  - 財務省の検証ではパネル分析に「逆因果の課題」、マクロ分析は「有意差なし」と記載。効果ゼロの証明ではないが、追加性を支持する根拠は弱い
  - 公開有報から13社×3年を取得した予備調査では、2,000人境界±100人に企業がなく、民間側で因果推計をするには税務個票が要る。政府だけが持っている
  - 政府が2026年9月に示した補助金・基金の見直し約20件・170億円に対し、賃上げ税制1本の減収は56倍
- **caveat**: 適用額は税額控除の額で、廃止すれば同額の増収になるわけではない（行動変化と課税繰延べがある）。減収の大きさ自体は政策の失敗を意味しない。
- **href**: `/tax-expenditures`（租税特別措置の適用額と試行評価を見る）
- **source**: 財務省「租税特別措置の適用実態調査の結果に関する報告書」（2026年2月国会提出）総括表、財務省 賃上げ促進税制の検証（事務局資料）

- **figure**: 44億円 ／ ジャパン・ハウス3拠点の運営委託（2024年度）

### 代表3件の選び方

LPに足すなら **I-1（事務局）・I-2（企画競争）・I-4（賃上げ税制）** を代表にする。
I-1 と I-2 は既存の「1者応札」「再委託」カードの延長で、横断集計の数字が大きく、記載要領（事務費の内訳・企画競争の応募者数）という約束の取りどころがある。I-4 は歳出レビューが租税特別措置を扱っていないこと自体を示せる唯一のカード。
I-3 と I-5 は個別事業の深掘りなので、質問の裏付けとして残す。

## 3. 国会質問の台本（目的・答弁者つき）

### Q-1. 補助金事務局の事務費（約束型／経産大臣・国交大臣＋参考人／予算委員会・決算行政監視委員会）

- **通告**: 子育てエコホーム支援事業（2,095億円）、省力化投資補助（576億円）、観光地再生・高付加価値化（479億円）の事務局契約について、事務局の選定方法、応募者数、事務費の額、再委託先。
- **参考人への事実確認**
  1. 博報堂が事務局を務める補助金の2024年度の合計額を政府として把握しているか（想定答弁：府省横断では把握していない）。
  2. 子育てエコホーム支援事業で、2,095億円のうち事務局の事務費はいくらか。事務局の選定は企画競争か、応募者数は何者か。
  3. 事務局からの再委託先（審査・コールセンター・システム）とその金額を把握しているか。
- **大臣への評価**: 「民間の集計で、1社が9事業・3,000億円超の補助金事務局を務めています。事務費がいくらか、シートからは読めません。補助金の2割が事務に消えていても分からない状態で、適正だとお考えですか。」
- **大臣への約束**: 「事務局契約について、(1)事務費と補助金本体を分けた記載、(2)事務局の選定方法と応募者数、(3)事務局からの再委託先、の3点を次回の記載要領で必須にしていただけますか。」
- **逃げ答弁への切り返し**
  - 「事務局は公募で適正に選定」→「応募者数を答えてください。1者なら公募の意味を説明してください。」
  - 「事務費は契約書に定めている」→「それなら公表できる。シートに転記するだけです。」
  - 「個別契約は所管省が答える」→「だから横断で把握する仕組みを行革担当に求めている。」
- **翌年の検証**: 次年度シートで事務局契約の事務費欄の記入率を集計する。博報堂への直接支出の推移を `/subcontracts` で追う。
- **旧レビューとの対応**: S01（住宅補助348億円）・S02〜S04（観光）の論点を、率の仮定ではなく事務局の構造で問う形に変えた。

### Q-2. 企画競争・公募の1者応募（事実確定→制度／財務大臣・行革担当大臣＋参考人／決算行政監視委員会）

- **質問主意書（先行）**: 府省別・年度別の企画競争・公募の件数、応募1者の件数と金額、平均落札率（2022〜2024年度）。
- **参考人への事実確認**
  1. 企画競争・公募で応募が1者だった契約の件数と金額を政府として集計しているか。
  2. 応募1者の場合に再公告や仕様見直しを求めるルールがあるか（想定答弁：各府省の判断）。
  3. 国際広報経費の戦略的メッセージ業務（7.8億円）は企画競争で応募1者・落札率100%。公告期間と仕様書の作成者を答えてください。
- **大臣への評価**: 「企画競争と公募で応募1者の契約が1.18兆円、落札率は99%です。これは競争と呼べますか。」
- **大臣への約束**: 「応募1者となった企画競争・公募について、理由の記載と公表を義務づけていただけますか。1者応札の改善策（公告期間の延長・仕様の見直し）を企画競争・公募にも適用する考えはありますか。」
- **委員会への提案**: 応募1者・落札率99%以上の企画競争・公募について、会計検査院に検査を要請する（国会法105条）。
- **翌年の検証**: 翌年度シートの契約方式データで企画競争・公募の応募1者率を再集計。
- **旧レビューとの対応**: A07〜A10（国際広報の共通化）を、削減率ではなく契約方式の問題として問う。

### Q-3. 政府広報の成果測定（評価型／内閣官房長官または内閣府担当大臣＋参考人／内閣委員会）

- **参考人への事実確認**
  1. 国内広報経費45億円の成果指標が放送回数・掲載回数のみである理由。認知度・理解度の調査を実施しているか（戦略的広報経費では実施している）。
  2. 国際広報経費のアウトカム指標「対日好感度の変化」の実績が空欄である理由。測定したが書いていないのか、測定していないのか。
  3. 媒体別（テレビ・新聞・ネット）の到達と費用を把握しているか。
- **大臣への評価**: 「年120億円の政府広報に、認知度や行動変化の指標がありません。同じ内閣府の別事業では測っています。測れないのではなく、測っていないのではないですか。」
- **大臣への約束**: 「国内広報経費・国際広報経費・ジャパン・ハウスの3事業について、次回のレビューシートからアウトカム指標と実績を記載していただけますか。媒体別の到達・費用のデータを委員会に提出していただけますか。」
- **翌年の検証**: 次年度シートの成果指標でアウトカム実績の有無を確認。
- **旧レビューとの対応**: A01〜A06（国内広報の媒体整理 6.42億円）は、削減額を言う前に「媒体別の到達・転換データの提出」を取る段階に戻す。旧レポート自身が「まず提出対象にする」と書いていた部分を質問の本体にした。

### Q-4. ジャパン・ハウスの契約と成果（事実確定型／外務大臣＋参考人／外務委員会・決算行政監視委員会）

- **参考人への事実確認**: 3拠点の国庫債務負担行為の期間と総額、各拠点の賃料・人件費・企画展費の内訳、来館者1人あたりコスト、運営者（吉本興業・JTB・ジャパン・エイチ・エル）の選定方法と応募者数、次回更新の時期。
- **大臣への評価**: 「来館者数だけが指標ですが、目的は親日派・知日派の拡大です。それをどう測っていますか。」
- **大臣への約束**: 「次回の契約更新時に、拠点ごとのコストと成果を公表したうえで競争で選定すると約束できますか。」

### Q-5. 賃上げ税制の検証（約束型／財務大臣＋参考人／財務金融委員会）

- **質問主意書（先行）**: 賃上げ促進税制の規模別（大企業・中堅・中小）の適用件数・適用額・継続雇用者給与の増加率の分布（2022〜2024年度）。
- **参考人への事実確認**
  1. 2024年度の適用額9,560億円は2022年度の1.9倍。この増加のうち、税制がなくても起きた賃上げの分をいくらと推計しているか（想定答弁：推計していない）。
  2. 財務省の検証資料でパネル分析に「逆因果の課題」、マクロ分析に「有意差なし」とある。その後、個票を使った因果推計を行ったか。
  3. 2,000人の境界で中堅企業枠が新設された。境界前後の企業の給与変化を比較したか。
- **大臣への評価**: 「補助金・基金の見直しで170億円を積み上げた一方、賃上げ税制1本で9,560億円の減収です。56倍の規模の税制に、効いたかどうかの推計がない。これで2027年の期限延長を判断できますか。」
- **大臣への約束**: 「2027年3月の期限までに、税務個票を使った追加性の推計を公表し、効果の乏しい区分は縮減する。この順序を約束していただけますか。」
- **逃げ答弁への切り返し**
  - 「賃上げの機運醸成に効果」→「機運は数字で測れない。適用企業と非適用企業の賃上げ率の差を答えてください。」
  - 「個票は守秘義務」→「集計結果の公表を求めている。国税庁の共同研究では研究開発税制の明細を提供している。」
- **翌年の検証**: 2027年2月提出の適用実態報告書で適用額を更新。検証資料の公表の有無を確認。
- **旧レビューとの対応**: 租特の試行評価（追加性1点・費用対効果保留）と13社パネルの「個票がないと出せない」結論を、「政府は持っているのに出していない」という問いに転換。

### Q-6. 住宅取得補助の設計（評価型／国交大臣＋参考人／国土交通委員会）

- **参考人への事実確認**: 子育てエコホーム支援事業（2,095億円）の交付先を所得階層別・住宅価格帯別に集計しているか。補助がなくても購入した世帯の割合を調査したか。後継のみらいエコ住宅（長期優良・ZEH水準枠1,450億円）で制度設計を変えた点。
- **大臣への評価**: 「2,095億円の交付先の所得分布が分からないまま、後継で1,450億円を積んでいます。誰に届いたかを確認せずに続ける理由は何ですか。」
- **大臣への約束**: 「所得・価格帯別の交付実績と、補助の追加性に関する調査結果を次回の予算要求前に公表していただけますか。」
- **旧レビューとの対応**: S01の「30%縮小・348億円」は政策判断の数字で、質問には使わない。縮小の是非ではなく「誰に届いたか」を出させる。

## 6. 集計の定義

- 直接支出：`project-quality-recipients-2025.json` の `r=true` かつ `d=0` かつ金額>0
- 広報・広告（民間）：契約概要または役割に「広告|広報|プロモーション|PR|SNS|CM|キャンペーン|周知」を含み、「事務局|補助|交付|給付|示達|助成」を含まず、支出先が独法・公益法人・自治体・健保でない
- 民間事務局：契約概要または役割に「事務局|補助事業に関する事務|執行事務|事務費」を含み、支出先が独法・自治体・「その他」でない
- 契約方式：`contract-methods-2025.json` の `m`。企画競争＝`negotiated-contract-competitive-bidding`、公募＝`negotiated-contract-public-offering`。応募1者＝`ap=1`、落札率＝`br` の単純平均
- 租特：`app/lib/tax-expenditures/data.json` の単体法人行の2024年度適用額（千円）。通算法人の内数は除外
- 予算・執行推移：`rs2025-project-budget-history.json`
- 成果指標：`rs2025-project-outcomes.json`
