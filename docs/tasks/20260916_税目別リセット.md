# 歳入可視化の税目別リセット

- 「税・給付」パネルに住民税、年金・医療・介護・雇用保険料、所得税の基礎控除、児童手当の個別リセットを追加。
- 消費税は標準・軽減税率の2項目、給付付き控除は年額・逓減開始年収・逓減率の3項目をまとめて戻す。
- 対象の改革パラメータだけをBASE_REFORMへ戻し、他の改革や世帯・表示条件を保持。既に基準値ならリセットを無効化する。全体リセットも維持。
- 所得税は基礎控除の上乗せ額をゼロに戻すため、年収に応じた基準控除額に戻る。
- 画面テストで全9組のリセット、別税目の保持、年収の保持、URL・再読み込み後の状態を確認。TypeScript型検査を実施。
