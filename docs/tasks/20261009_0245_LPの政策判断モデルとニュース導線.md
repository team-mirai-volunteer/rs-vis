# LPに政策判断のモデルとニュースからの入口を追加

公開データから「どこを増やすと支援が届くか」と「発見をどう検証し、次の政策判断につなげるか」が分かるようにする。既存の議員・政策秘書向け説明、国会質問14本・台本11本、タイトルとデザインは維持する。

## 追加内容

### 支援を届けるモデル

公立学校施設整備費（PID 1527）の実在する事業詳細を入口にする。2025年版シートの2024年度実績を開き、予算・執行推移と記載された成果指標を見る。

低執行だけから増額・削減を判断しない。未充足需要や不採択件数は算出しておらず、次を追加で求める資料として示す。

1. 適格な申請のうち、予算不足で支援できない件数・金額とその他の不採択理由
2. 条件による対象外、申請の負担による未申請・取下げ
3. 審査待ち、職員配置、設計・施工体制、交付決定済み額

原因に応じた増額・配分時期、制度・手続き変更、実施体制の補強を候補として示す。国会での問いの試案と、翌年度の未充足件数・審査日数・改修完了件数の確認を折りたたみ内に置く。既存の14問を書き換えたり追加扱いにはしない。

### 1件を最後まで調べるモデル

- `vendors.json.gz` の富士通株式会社（法人番号 `1020001071491`）の `repeatSingle` に、ハローワークシステム運営費（PID 2519）がある。
- `sheetYears: [2024, 2026]` は **2023・2025年度実績**。2025年度は暫定。連続年度でも同一契約でもあるとは断定しない。
- `contract-methods-2024.json.gz` と `contract-methods-2026.json.gz` に、同PID・法人番号の競争入札で応札者数1の行があることを検証。
- 企業詳細URLから、この実データの年度別記載を確認できる。事業詳細は2024年度実績の既存データを別リンクで開く。

発見 → 継続性・専門性を含む別の説明 → 公告・仕様・参加要件・契約結果の確認 → 分割発注・標準化・契約期間の比較 → 応札者数に加え価格・品質・事務負担の測定、の5段階を掲載。

これは調査のモデルであり、公告原本の照合、問題の認定、改善策の実施、改善効果の実証が済んだ事例ではない。後半は追加調査と検討の手順として記載する。

### 72.3億円のニュースから調べる入口

確認日: 2026-10-08。

- [FNN 2026-09-11 15:34](https://www.fnn.jp/articles/-/1112462) の本文を確認。内閣官房・内閣広報室の2027年度概算要求72億3千万円、比較対象の2026年度予算7億円という報道。
- 原資料の概算要求PDFそのものと詳細な費目対応は確認できていないため、**報道ベース**と明示する。細かい内訳は掲載しない。
- 見出しは「広報費の要求が約10倍。何を増やすのか？」。要求と成立予算・契約・支出は区別する。
- 内閣府の政府広報・国際広報経費とは別。別所管のPID 98を72.3億円の追跡先としてリンクしない。
- 当サイトで2027年度概算要求全体は未収録で、72.3億円を直接追えないことを**常時表示**する。過年度の広報事業の探索とは対応関係が未確認であると明示する。
- 前年との比較範囲、動画制作・発信体制などの内訳、届く相手や政策理解の成果指標、委託先の選定を次の確認事項にする。支出の不適切さを断定しない。

## 現在の概算要求表示の限界

`app/lib/api/quality-year.ts` の対応年度は2024・2025・2026。最後は2025年版シートの翌年度要求額を表示する仮想年度である。`quality-scores-loader.ts` は予算額のみ置き換え、執行額をnullにし、過去の採点結果・事業概要を参照する。

2027年度の要求データ取得・整形・収録は、このLP変更では実装しない。
