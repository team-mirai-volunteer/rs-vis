# サンキー図の太さの基準と操作

- 従来のレイアウト倍率0.5を画面上の1倍とし、新規表示・リセットの初期値にした。
- 文字サイズの共通コントロールに刻み・ラベル・単位を追加し、太さでも利用。スライダー・数値入力・長押し対応の上下ボタン・リセットを揃えた。
- 太さは0.1〜16倍、0.1倍刻み。描画時は画面倍率×0.5を使う。金額比を維持。
- URLのthは従来の描画単位を維持。明示された旧値は新表示倍率へ換算し、初期読み込みと履歴操作に同じ処理を使う。th未指定は新しい初期値となる。
- 歳入は既存の統合プリセットに含まれており、通常の入口で表示されることをE2Eで確認。続く依頼で補正・決算の公式歳入CSVも接続した（20260916_補正決算の歳入接続.md）。

## 検証

- TypeScript型検査成功。
- レイアウト・旧URL換算のユニットテスト3件成功。
- サンキー画面テスト4件成功。歳入の初期表示、0.1刻み、上下ボタン、数値入力、太さの比例、共有・リセット、文字サイズとの独立、PCズーム・モバイルピンチを確認。
