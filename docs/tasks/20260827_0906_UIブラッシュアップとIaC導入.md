# UI/UXブラッシュアップ（ナビ位置統一・小画面フォント）と IaC 導入

日付: 2026-08-27

## 背景

ユーザー報告:
1. 画面サイズによって文字が極端に小さく見える（特にサンキー図のラベル）
2. ハンバーガーメニューの位置がページによって「右に張り付く / 中央寄せ」に変わる

## 調査結果

全5公開ページを 390 / 768 / 1024 / 1600px 幅で実機スクリーンショット検証した。

### ハンバーガー位置の不統一（原因特定）

| ページ | 実装 | 症状 |
|--------|------|------|
| /project-bubble, /mof | `absolute/fixed top-3 right-3` | 問題なし（右上固定） |
| /quality | ヘッダー行内 `flex items-center` + `ml-auto` | タイトルが折り返すと**上下中央に浮く**（「中央寄せに見える」の正体） |
| /subcontracts | `flexWrap: wrap` のツールバー行内 | 狭幅で**2行目に落ちる** |
| /sankey-svg | ツールバー右端 | 問題なし |

### フォントサイズ（計測結果）

Playwright で SVG ラベルの実効フォントサイズ（font-size × getScreenCTM の scale）を
390〜1600px の5サイズ+リサイズシーケンスで計測 → **全条件で11px一定**（縮小はしない）。
`/zoom` の逆スケール補正が機能しているため「画面が小さいほど縮む」わけではなく、
**スマホでも11pxのままで体感的に極端に小さい**ことが実態。

## 実施した修正

1. **`/quality`**: ヘッダー行を `items-start` 化し、年度セレクト+メニューを `ml-auto shrink-0` の
   クラスタにまとめて右上端に固定（タイトル折返し時も浮かない）。
2. **`/subcontracts`**: 年度+メニューを折返し対象の flex から外し、常に1行目右端に固定。
   検索の minWidth を 240→180 に緩和。
3. **小画面の既定フォント引き上げ**: `useBaseFontPx` に `compactOptions` を追加。
   幅 ≤767px かつ localStorage 未設定時のみ既定 12px→14px（/sankey-svg と /subcontracts/[projectId]）。
   自動適用値は localStorage に恒久化せず、ユーザー操作起点の変更のみ永続化するよう変更。

## IaC 導入（Terraform: Vercel + Supabase）

`infra/terraform/` を新設。方針:

- **役割分担**: ビルド設定・ヘッダ・regions は既存 `vercel.json`（アプリ設定として同居）、
  プロジェクトの存在・GitHub連携・環境変数は Terraform。
- **Supabase は先行整備**: アプリ未使用のため `supabase_enabled = false` 既定の count 切替。
  DB導入時に有効化すると東京リージョンにプロジェクト作成 + `NEXT_PUBLIC_SUPABASE_URL` を
  Vercel 環境変数へ自動配布。
- **秘匿値**: トークン/APIキー/DBパスワードは環境変数（`VERCEL_API_TOKEN` / `SUPABASE_ACCESS_TOKEN` /
  `TF_VAR_...`）でのみ渡す。tfvars は gitignore。
- **既存プロジェクトの取り込み**: apply 前に `terraform import vercel_project.app prj_...` 必須
  （手順は infra/terraform/README.md）。
- **state**: 当面ローカル。チーム運用時にリモートバックエンドへ移行。
