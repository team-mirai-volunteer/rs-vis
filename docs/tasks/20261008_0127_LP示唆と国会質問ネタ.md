# LPの示唆と国会質問ネタ

このサイトのデータから引き出せる示唆を整理し、LP（`/lp`）に載せる数字と、国会質問の候補をまとめた。
数値は 2026-10-08 に `public/data` の生成物を集計したもの。集計スクリプトは本文末尾に残す。

年度の書き方は `docs/年度表記ルール.md` に従う。
- 2025年版レビューシート → 2024年度実績（予算現額・執行額・支出先・契約方式）
- 2026年版基金シート → 2025年度末の残高、2025年度の支出・返納
- 予算・執行推移 → 2025年版レビューシートに載る 2021〜2025年度

## 3. 国会質問ネタ

設計は `20261008_0230_LPを読んでの示唆と国会質問の設計.md`、文体は `20261008_0340_チームみらいの国会質問の型とLPの質問の合わせ方.md`。LP（`app/lp/insights.ts` の `DIET_QUESTIONS`）と同じ内容で、更新時はそちらを正とし、このセクションはスクリプトで再生成する。

原則:
- **参考人には数字を、大臣には判断を**: 大臣に数字を聞くと「精査する」で終わり、参考人に判断を聞くと「大臣の指示に従う」で終わる。事実は事前レクと通告で固め、本番では大臣に「その事実を前提にどうするか」だけを聞く。
- **一覧は口頭で取れない。主意書に回す**: 府省別・基金別・事業別の数表は質問主意書で求める。答弁書は閣議決定なので、翌年の検証で「政府の数字」として引用できる。質疑の時間は約束に使う。
- **約束は翌年このサイトで確かめられる形で**: 「検討する」は不成立。金額・件数・期限・公表の形式を取る。翌年のレビューシートや基金シートで、約束どおりになったかを同じ画面で見られる。

### Q1. 記載の穴（台本つき）

- 委員会・答弁者: 内閣委員会・決算行政監視委員会／行政改革担当大臣
- 目的: 事実確認・約束・制度変更／答弁者: 参考人・大臣
- 要約: 支出先「その他」22.3兆円・法人番号未記入9%・アウトカム指標なし954事業。次の記載要領改定で件数・区分・法人番号を必須にするか
- 冒頭: 本日は、行政事業レビューシートの記載のあり方について、公開データの集計を基に建設的に伺います。予算を動かさずに改善できる論点です。
- 認める: レビューシートが5,000を超える事業について支出先まで公開され、公開APIで機械的に読める形になっていることは、各府省と行革推進本部の積み重ねとして評価したいと思います。
- このサイトで分かっていること（通告・事前レクで固める数字）:
  - 支出先が「その他」として1行にまとめられた支出は1,526事業・259万件・22.3兆円。金額加重で支出全体の19%
  - 支出先の法人番号の記入率は91%。残り9%は名称だけ
  - アウトカム指標が1つもない事業が954件（16%・予算10.1兆円）。終了予定のない事業が4,375件
  - これらはすべて行政事業レビューの記載要領で決まる。予算を動かす必要がなく、所管は行政改革推進本部
- 参考人への事実確認（数字と、なぜそうなっているか）:
  - 支出先が「その他」として1行にまとめられた金額の合計を、政府として集計しているか（想定答弁：集計していない。この答弁を記録に残すこと自体が目的）
  - 法人番号の記入を記載要領で義務づけているか。任意ならその理由
  - アウトカム指標の記載を必須にしていない理由
  - 法人番号の記入が9%で欠けている主な理由は何か。任意団体・個人など番号を持たない相手が多いのか、記載漏れが多いのか、政府として分析しておられるか
- 答弁を受けての受け止めと提案: ありがとうございます。府省の事務負担という点は理解いたします。ただ、法人番号は契約時に必ず取得しておられるはずで、転記するだけで済む情報だと受け止めております。個人情報についても、名前ではなく件数と区分であれば支障はないと考えます。「検討する」とのことでしたので、検討の結論を出す時期を、次の年版のシートに間に合う形で示していただければと思います。
- 大臣への問い: 「民間の集計で、支出の2割にあたる22兆円が「その他」として1行にまとめられています。名前は求めておりません。件数と、個人・法人・自治体の区分と、法人番号があれば、国民が自分で確かめられるようになります。記載要領の次回改定で、この3点を必須にしていただくことはできないでしょうか。」
- 大臣へのお願い: 「次回の記載要領改定で、(1)「その他」の件数、(2)個人・法人・自治体の区分、(3)法人の法人番号、の3点を必須にしていただきたいと思います。改定の時期についても、お考えをお聞かせください。」
- 締め: 翌年のシートで件数欄と法人番号の記入率を私どもも集計してまいります。記載要領の改定、是非お願いいたします。
- 翌年の検証: 次年度のレビューシートで「その他」の件数欄の記入率と法人番号の記入率を再集計する。評価一覧の支出先表のステータス（OK・未登録）で事業ごとに見られる

- 大臣への問い: 「ロジックモデルは登録されている一方で、アウトカム指標が1つもない事業が954件、予算で10兆円あります。達成率の中央値が100%で、半数以上が100%以上という点も、目標の水準が適切かという疑問を生みます。指標を設けない理由を事業ごとに書いていただくことはできないでしょうか。」
- 大臣へのお願い: 「予算100億円以上の事業について、アウトカム指標の設定か、設けない理由の記載を必須にしていただきたいと思います。達成率100%以上が続く指標については、目標の水準を第三者が検証する仕組みも御検討いただけないでしょうか。」
- 質問主意書で求める数表（提案）: アウトカム指標のない954事業の一覧と、指標を設けていない理由。達成率100%以上の指標について目標値の設定根拠
- 締め: 翌年のシートでアウトカム指標の有無を私どもも再集計いたします。指標の設定、是非お願いいたします。
- 翌年の検証: 翌年のレビューシートでアウトカム指標の有無を再集計する。評価一覧の事業詳細で成果指標の目標・実績を見る
- 問う価値: 「指標がない事業が16%ある」と数字で示すこと自体に意味がある。記載要領の改定は行革推進本部が握っていて、予算を動かさずに約束が取れる。
- 画面: `/project-bubble`（バブルチャートで事業を内容と規模で眺める）
- 注意: アウトカム欄に記載があれば内容を問わず「ある」と数えている。給付や義務的経費は終了予定を持たないのが自然。

### Q16. 基金の造成

- 委員会・答弁者: 予算委員会／経済産業大臣・文部科学大臣
- 目的: 事実確認・評価／答弁者: 参考人・大臣
- 要約: 造成直後で支出ゼロの基金（2,000億円・1,500億円など）。補正で前払いする必要があった理由と年度別の支出見込み
- 冒頭: 本日は、新しく造成された基金の支出見込みについて伺います。
- 認める: 複数年度にわたる事業を基金で前払いする方式には、年度をまたいだ機動的な執行という利点があることは理解しております。
- このサイトで分かっていること（通告・事前レクで固める数字）:
  - 2025年度に造成され年度末時点で支出ゼロの基金：大規模成長投資補助 2,000億円、低軌道衛星インフラ 1,500億円、造船業再生 1,200億円、後発医薬品製造基盤 844億円
  - 基金の造成元の事業と、基金から誰にいくら支払われたかは、このサイトで年度別に追える
- 参考人への事実確認（数字と、なぜそうなっているか）:
  - 上記の基金の造成時点での年度別支出見込みと、造成後1年の執行額
  - 2025年度に造成した基金のうち年度末時点で支出がゼロのものについて、造成時点で想定していた初年度の支出額はいくらであったか
- 答弁を受けての受け止めと提案: ありがとうございます。複数年度の事業なので基金が適しているという点は理解いたします。であれば年度別の支出見込みは当然お持ちのはずで、それを公表していただくことに支障はないのではないかと受け止めております。
- 大臣への問い: 「大規模成長投資補助の2,000億円、低軌道衛星インフラの1,500億円は、造成した年度の支出がゼロです。補正予算で基金として前払いする必要があった理由と、単年度の補助金として当初予算で要求した場合との違いを、どのようにお考えでしょうか。」
- 大臣へのお願い: 「これらの基金について、年度別の支出見込みを公表していただけないでしょうか。翌年の残高と突き合わせて、私どもも確認してまいります。」
- 締め: 翌年の基金シートで残高と支出を確認させていただきます。見込みの公表、是非お願いいたします。
- 翌年の検証: 翌年の基金シートで残高と支出を見る。基金一覧の詳細で造成元の事業と支払先を年度別に出せる
- 問う価値: 造成直後に支出ゼロなのは当然だが、「いつ使うのか」を数字で答えさせれば、翌年以降このサイトで実績と突き合わせられる。
- 画面: `/funds?signal=noSpending`（基金一覧を「残高はあるが支出ゼロ」で絞り込んで開く）
- 注意: 造成直後の基金は支出が立ち上がる前で、ゼロであること自体は異常ではない。
### 使い方の順序（提案）

1. Q1 記載の穴（約束型）。既存データだけで今すぐ質問にでき、翌年のシートで検証が完結する
2. Q2 1者応札・Q3 基金は主意書を先行させ、答弁書（7日）が出てから質疑に立つ。Q2 は委員会の検査要請（国会法105条）を併用する
3. Q4 補正予算・Q5 防衛費は所管委員会で参考人に事実確認してから大臣に評価を問う
4. 残りの5本は同じ型で、所管委員会の日程に合わせて使う
5. いずれも「このサイトで誰でも再現できる」ことを添え、答弁後に画面を更新して追跡する
