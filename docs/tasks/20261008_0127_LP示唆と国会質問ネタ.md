# LPの示唆と国会質問ネタ

このサイトのデータから引き出せる示唆を整理し、LP（`/lp`）に載せる数字と、国会質問の候補をまとめた。
数値は 2026-10-08 に `public/data` の生成物を集計したもの。集計スクリプトは本文末尾に残す。

年度の書き方は `docs/年度表記ルール.md` に従う。
- 2025年版レビューシート → 2024年度実績（予算現額・執行額・支出先・契約方式）
- 2026年版基金シート → 2025年度末の残高、2025年度の支出・返納
- 予算・執行推移 → 2025年版レビューシートに載る 2021〜2025年度

## 1. LP

- 置き場所: `app/lp/page.tsx`（本体）と `app/lp/insights.ts`（数字と文言）。URL は `/lp`
- ナビには出さない（`components/navigation/pages.ts` に加えていない）。メタデータは page 内で直接定義し、OG画像は `/og/home.png` を流用

- 示唆カードごとに「読み方の注意」「出典」「確かめに行くリンク」を必ず付け、断定を避ける

## 3. 国会質問ネタ

各項目は「数字（根拠）→ 質問文 → 想定答弁と再質問 → 確認する画面 → 注意」の順。質問は政府参考人・大臣のどちらにも振れるよう、事実確認と方針の2段で書く。

### Q1. 1者応札と落札率（財務省・各府省、決算行政監視委員会・予算委員会）

- 根拠: 競争入札の48%が1者応札。1者応札の平均落札率 93.0% は複数応札の 82.2% より約11ポイント高い。1者応札で落札率99%以上が2,038件・2,352億円
- 質問文: 「行政事業レビューシートの契約情報を集計すると、2024年度の一般競争・指名競争のうち応札者が1者のみだった契約が48%、金額で9,036億円に上る。1者応札の平均落札率は複数応札より約11ポイント高い。政府として府省ごとの1者応札率をどう把握し、仕様書の見直し・公告期間の延長など改善の目標と期限をどう定めているか」
- 想定答弁: 「各府省で1者応札の要因分析と改善に取り組んでいる」「特殊な装備・施設はやむを得ない」
- 再質問: 「では府省別の数値を示されたい。原子力規制委員会73%、環境省68%、文部科学省62%、防衛省53%で、防衛省は金額で2,482億円。同じ事業で同じ事業者が毎年1者応札となっている契約について、競争性の検証をいつ、誰が行っているか」
- 画面: `/quality` の事業詳細「支出先」表の契約方式列（応札者数つき）。`/budget-sankey` の支出先ホバーで方式別件数・1者応札件数
- 注意: 2024年度以前（2024年版・2025年版シート）の契約方式は突き合わせ率 98.8%（行）。年度をまたぐ連続受注の追跡は 2023〜2024年度実績で可能

- 根拠: 航空機修理費（空自）218億→5,784億円など当初予算3倍以上が34事業。防衛省の競争入札の1者応札率53%・2,482億円。三菱重工業は競争入札の1者応札で321億円（25件・12事業）
- 質問文: 「防衛力整備計画に伴い航空機修理費（空自）は4年で26倍に増えた。防衛省の競争入札の1者応札率は53%で、金額で2,482億円に上る。急増する維持整備費について、PBL（成果保証契約）の採用状況と、1者応札の契約に対する原価監査の実施件数を示されたい」
- 画面: `/budget-sankey`（防衛省で絞り込み）、`/quality?pid=5268`
- 注意: 令和8年度予算執行調査の対象に「装備品等の維持整備（PBL）」「研究器材の使用実態等」がある。調査結果と重ねて問う

### Q8. 再委託の多段構造と中間マージン（経済産業省・国土交通省）

- 根拠: 中小企業生産性革命推進事業は5段階、子育てエコホーム支援事業は4段階。深さ3以上が445事業・17.1兆円
- 質問文: 「中小企業生産性革命推進事業では、国→中小機構→事務局→支援機関→事業者と5段階で資金が流れる。各段階の事務費・管理費の合計額と、最終的に事業者に届いた割合を示されたい」
- 画面: `/subcontracts?q=生産性革命`、`/funds`（中小機構の基金）
- 注意: 段階数はシートのブロック構造から機械的に数えたもので、事務費は各ブロックの「費目・使途」から拾う必要がある

### Q9. 奨学金事業の支出先の公開（文部科学省）

- 根拠: 日本学生支援機構の貸与型奨学金事業 9,313億円の88%が「その他」
- 質問文: 「貸与型奨学金事業は9,313億円の88%が『その他』で、学校種別・大学別の貸与実績が行政事業レビューシートからは読めない。給付型との組み合わせを含めて、学校別の貸与・返還状況を公表する考えはあるか」
- 画面: `/quality?pid=1592`
- 注意: 個人への貸与なので支出先名は出せない。求めるのは学校別・区分別の集計

### Q10. 終了予定のない長期継続事業の見直し基準（行政改革担当大臣）

- 根拠: 終了予定なし 4,375事業・133兆円。1989年より前の開始が819事業・89.8兆円
- 根拠（成果指標・ロジックモデル、2026-10-08 追加集計 `rs2025-project-outcomes.json`）:
  - ロジックモデル（アクティビティ→アウトプット→アウトカムのつながり）が null の事業は 36件（0.6%・予算0.11兆円）。「未登録」はほぼ無い
  - アウトカム指標が1つもない事業: 954件（16.5%・予算10.06兆円）。予算100億円以上で102件。防災・安全交付金 1.74兆、河川等災害復旧 7,839億、社会資本整備総合交付金 7,385億、河川改修 5,399億、蓄電池サプライチェーン 4,078億、私立大学等経常費補助 2,987億、無償資金協力 2,874億、科学研究費助成事業 2,530億
  - 府省別のアウトカム指標なし率: 外務省 49%、経済産業省 47%、文化庁 43%、環境省 41%、内閣府 39%、国土交通省 18%、文部科学省 11%、厚生労働省・防衛省・農林水産省・総務省 0%
  - アウトカム指標はあるが数値目標がない: 501件。実績値がない: 1,224件
  - 「多段階のロジックモデルにしない理由」を記載した事業: 1,989件
  - アウトカム指標の最新達成率（7,983指標）: 中央値100%、50%未満 381、100%以上 4,936
  - 「アウトカム指標なし／ロジックモデルなし／数値目標なし」のいずれか: 1,456件（25.1%・予算74.5兆円。給付の大型事業を含むため金額は大きい）
- 質問文: 「行政事業レビューの対象事業の77%に終了予定がなく、予算の9割を占める。昭和期に始まった事業も819件ある。終了予定のない事業について、定期的な見直し時期を設定する考えはあるか。レビューシートにロジックモデルは登録されているが、アウトカム指標が1つもない事業が954件・予算10.1兆円ある。アウトカム指標の設定を必須とする考えはあるか」
- 再質問: 「アウトカム指標がない事業は外務省49%、経済産業省47%と府省で偏る。防災・安全交付金、社会資本整備総合交付金、私立大学等経常費補助、科学研究費助成事業にアウトカム指標がない理由を示されたい」
- 画面: `/project-bubble`（AI評価と予算規模の切り替え）、`/quality`（継続年数で並べ替え）
- 注意: 給付や義務的経費は終了予定を持たないのが自然。問うのは「見直しの仕組みがあるか」

### 使い方の順序（提案）

1. まず Q1（1者応札）と Q3（基金）。府省横断の数字で、政府全体の方針を問える。データの裏付けが最も固い
2. Q4（執行率）と Q6（検査結果の反映）は個別事業名を挙げられるので、所管委員会で政府参考人に事実確認を求めやすい
3. Q5・Q10 は制度提案型。質問主意書に向く
4. いずれも「このサイトで誰でも再現できる」ことを添え、答弁後に画面を更新して追跡する

## 4. 再集計の手順

数値は次のファイルを Node で読んで集計した（スクリプトは scratchpad で実行、恒久化していない）。

| 示唆 | ファイル | 集計 |
|------|----------|------|
| 1者応札 | `contract-methods-2025.json` | `m` が `open-tendering-*`/`selective-*` で `ap` あり → `ap===1` の件数・金額。`br` の平均。府省は `project-quality-scores-2025.json` の `ministry` |
| 基金 | `funds.json` | `years` 末尾の `sheetYear===2026` のみ。`balance/expense>=10`、`newApplicationEndDate<'2025-04-01'`、`returned>0`、`adminRate>=10 && expense>1e8` |
| 執行率 | `project-quality-scores-2025.json`、`rs2025-project-budget-history.json` | `budgetAmount>=1e9 && execAmount/budgetAmount<0.5`。推移は `executedAmount/totalBudget<0.5` が3年以上 |
| その他 | `others-counts-2025.json`、`project-quality-scores-2025.json` | `n`・`a` の合計、`opaqueRatio` の `spendTotal` 加重平均、`cnFillRatio` の `recipientCount` 加重平均 |
| 再委託 | `subcontracts-2025.json` | `maxDepth` の分布、`hasSeparateOrigin` |
| 検査 | `audit-report.json`、`budget-execution-audit.json` | `byPid` の交差、`reflectionAmount` の合計 |
| 予算増 | `rs2025-project-budget-history.json` | 2021年度 `initialBudget>=1e9` かつ 2025年度が3倍以上 |
| 長期継続 | `rs2025-project-details.json` | `startYear`・`noEndDate` |

LP の数字を更新するときは `app/lp/insights.ts` だけを直し、このドキュメントの日付を更新する。
