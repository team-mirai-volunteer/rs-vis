# LPの示唆と国会質問ネタ

このサイトのデータから引き出せる示唆を整理し、LP（`/lp`）に載せる数字と、国会質問の候補をまとめた。
数値は 2026-10-08 に `public/data` の生成物を集計したもの。集計スクリプトは本文末尾に残す。

年度の書き方は `docs/年度表記ルール.md` に従う。
- 2025年版レビューシート → 2024年度実績（予算現額・執行額・支出先・契約方式）
- 2026年版基金シート → 2025年度末の残高、2025年度の支出・返納
- 予算・執行推移 → 2025年版レビューシートに載る 2021〜2025年度

## 3. 国会質問ネタ

設計は `20261008_0230_LPを読んでの示唆と国会質問の設計.md`。LP（`app/lp/insights.ts` の `DIET_QUESTIONS`）と同じ内容で、更新時はそちらを正とし、このセクションはスクリプトで再生成する。

原則:
- **参考人には数字を、大臣には判断を**: 大臣に数字を聞くと「精査する」で終わり、参考人に判断を聞くと「大臣の指示に従う」で終わる。事実は事前レクと通告で固め、本番では大臣に「その事実を前提にどうするか」だけを聞く。
- **一覧は口頭で取れない。主意書に回す**: 府省別・基金別・事業別の数表は質問主意書で求める。答弁書は閣議決定なので、翌年の検証で「政府の数字」として引用できる。質疑の時間は約束に使う。
- **約束は翌年このサイトで確かめられる形で**: 「検討する」は不成立。金額・件数・期限・公表の形式を取る。翌年のレビューシートや基金シートで、約束どおりになったかを同じ画面で見られる。

### Q1. 記載の穴（台本つき）

- 委員会・答弁者: 内閣委員会・決算行政監視委員会／行政改革担当大臣
- 目的: 事実確認・約束・制度変更／答弁者: 参考人・大臣
- 要約: 支出先「その他」22.3兆円・法人番号未記入9%・アウトカム指標なし954事業。次の記載要領改定で件数・区分・法人番号を必須にするか
- このサイトで分かっていること（通告・事前レクで固める数字）:
  - 支出先が「その他」として1行にまとめられた支出は1,526事業・259万件・22.3兆円。金額加重で支出全体の19%
  - 支出先の法人番号の記入率は91%。残り9%は名称だけ
  - アウトカム指標が1つもない事業が954件（16%・予算10.1兆円）。終了予定のない事業が4,375件
  - これらはすべて行政事業レビューの記載要領で決まる。予算を動かす必要がなく、所管は行政改革推進本部
- 参考人への事実確認:
  - 支出先が「その他」として1行にまとめられた金額の合計を、政府として集計しているか（想定答弁：集計していない。この答弁を記録に残すこと自体が目的）
  - 法人番号の記入を記載要領で義務づけているか。任意ならその理由
  - アウトカム指標の記載を必須にしていない理由
- 大臣への問い: 「民間の集計で22兆円、支出の2割が「その他」です。行政事業レビューの目的に照らして、この状態で足りているとお考えですか。」
- 大臣に取る約束: 「次回の記載要領改定で、(1)「その他」の件数、(2)個人・法人・自治体の区分、(3)法人の法人番号、の3点を必須にしていただけますか。改定の時期も併せて。」
- 逃げ答弁への切り返し:
  - 「個人情報があるので出せない」→ 名前は求めていない。件数と区分です。
  - 「府省の事務負担が大きい」→ 法人番号は契約時に必ず取得している。転記するだけです。
  - 「検討する」→ 検討の結論を出す時期を答えてください。次の年版のシートに間に合いますか。
- 翌年の検証: 次年度のレビューシートで「その他」の件数欄の記入率と法人番号の記入率を再集計する。評価一覧の支出先表のステータス（OK・未登録）で事業ごとに見られる
- 問う価値: 翌年のシートで記入率を測れるので、約束の検証がこのサイトで完結する唯一の論点。既存データだけで今すぐ質問にできる。
- 画面: `/budget-sankey?year=2024&b=settlement&frq=%E3%81%9D%E3%81%AE%E4%BB%96`（サンキー図を支出先「その他」で絞り込んで開く）
- 注意: 給付の受給者など個人の名前は出せない。求めるのは件数・区分・法人番号に限定する。

  - 一般競争・指名競争で応札者数が分かる16,948件のうち8,134件（48%）が1者応札。金額9,036億円
  - 落札率の単純平均は1者応札93.0%、複数応札82.2%。契約方式・府省・金額帯で分けても6〜13ポイントの差が残る（同種契約どうしの比較ではない）
  - 仮に1者応札の9,036億円が複数応札並みの落札率で落ちていれば約8,000億円で、差は約1,000億円（平均を機械的に当てた規模感で、因果ではない）
  - 事業者別：三菱重工業321億円（25件）、アクセンチュア257億円（14件）、クニエ248億円（5件・1件平均50億円）、富士通248億円（77件）

  - アウトカム指標のない事業の数を政府として把握しているか
  - 終了予定のない事業について、直近に評価・見直しを行った時期を把握しているか
- 大臣への問い: 「EBPMを掲げながら、指標のない事業が16%、予算で10兆円あります。指標を設けない理由を事業ごとに書かせる考えはありますか。達成率の中央値が100%なのは、目標が適切だからですか。」
- 質問主意書で求める数表: アウトカム指標のない954事業の一覧と、指標を設けていない理由。達成率100%以上の指標について目標値の設定根拠
- 逃げ答弁への切り返し:

- 翌年の検証: 翌年のレビューシートでアウトカム指標の有無を再集計する。評価一覧の事業詳細で成果指標の目標・実績を見る
- 問う価値: 「指標がない事業が16%ある」と数字で示すこと自体に意味がある。記載要領の改定は行革推進本部が握っていて、予算を動かさずに約束が取れる。
- 画面: `/project-bubble`（バブルチャートで事業を内容と規模で眺める）
- 注意: アウトカム欄に記載があれば内容を問わず「ある」と数えている。給付や義務的経費は終了予定を持たないのが自然。

  - 事務局契約の契約方式は「補助金」「その他」で記載され、応札者数・落札率が空欄。事務費と補助金本体の比率はシートから読めない
- 参考人への事実確認:
  - 博報堂が事務局を務める補助金の2024年度の合計額を、政府として把握しているか（想定答弁：府省横断では把握していない）
  - 子育てエコホーム支援事業で、2,095億円のうち事務局の事務費はいくらか。事務局の選定は企画競争か公募か、応募者数は何者か
  - 事務局からの再委託先（審査・コールセンター・システム）とその金額を把握しているか
- 大臣への問い: 「民間の集計で、1社が9事業・3,000億円超の補助金事務局を務めています。事務費がいくらかはシートから読めません。補助金の2割が事務に消えていても分からない状態で、適正だとお考えですか。」

  - 「事務費は契約書で定めている」→ それなら公表できます。シートに転記するだけです。
  - 「個別の契約は所管省が答える」→ だから横断で把握する仕組みを行政改革担当に求めています。

- 画面: `/subcontracts?q=%E5%8D%9A%E5%A0%B1%E5%A0%82`（委託構造で博報堂を含む事業の段階を見る）

### Q12. 企画競争・公募（台本つき）

- 委員会・答弁者: 決算行政監視委員会／財務大臣・行政改革担当大臣・各府省参考人
- 目的: 事実確認・一覧要求・約束・検査要請／答弁者: 参考人・大臣・主意書・委員会
- 要約: 企画競争・公募で応募1者の契約が1.18兆円・落札率99%。これを競争と呼ぶか、応募1者の理由公表を義務づけるか
- このサイトで分かっていること（通告・事前レクで固める数字）:
  - 企画競争4,192件・3,509億円のうち1,522件（36%）が応募1者。公募3,880件・1.12兆円のうち3,016件（78%）が応募1者
  - 応募1者の平均落札率は企画競争99.6%、公募98.6%
  - 国際広報経費の戦略的メッセージ業務（電通PRコンサルティング 7.8億円）は企画競争・応募1者・落札率100%。同じ内閣府の国内広報経費は一般競争で応札4〜6者・落札率60〜72%
- 参考人への事実確認:
  - 企画競争・公募で応募が1者だった契約の件数と金額を、政府として集計しているか
  - 応募1者の場合に再公告や仕様の見直しを求めるルールがあるか（想定答弁：各府省の判断）
  - 国際広報経費の戦略的メッセージ業務について、公告期間と仕様書の作成者を答えてください
- 大臣への問い: 「企画競争と公募で応募1者の契約が1.18兆円、落札率は99%です。これは競争と呼べますか。」
- 大臣に取る約束: 「応募1者となった企画競争・公募について、理由の記載と公表を義務づけていただけますか。1者応札の改善策（公告期間の延長・仕様の見直し）を企画競争・公募にも適用する考えはありますか。」

- 委員会として: 応募1者・落札率99%以上の企画競争・公募について、国会法105条に基づき会計検査院に検査を要請することを理事会で諮る
- 逃げ答弁への切り返し:
  - 「要件に合う主体が1者しかない」→ それなら最初から随意契約の理由を書くべきです。競争の形式を取る理由を説明してください。
  - 「企画競争は価格競争ではない」→ 価格以外で競っていないのに落札率100%です。何を競ったのか答えてください。
- 翌年の検証: 翌年度の契約方式データで、企画競争・公募の応募1者率と落札率を再集計する
- 問う価値: 1者応札の議論は一般競争に偏りがちで、企画競争・公募の1者応募はほとんど問われていない。金額は一般競争の1者応札9,036億円より大きい。

- 注意: 公募は補助先・委託先を広く募る形式で、要件に合う主体が1者しかない場合が多い。応募者数と落札率は府省の入力どおり。

### Q13. 賃上げ税制（台本つき）

- 委員会・答弁者: 財務金融委員会／財務大臣・財務省主税局参考人
- 目的: 事実確認・一覧要求・約束／答弁者: 参考人・大臣・主意書
- 要約: 賃上げ税制の適用額9,560億円は2年で1.9倍。2027年3月の期限前に、追加性の推計を公表してから延長を判断するか
- このサイトで分かっていること（通告・事前レクで固める数字）:
  - 賃上げ促進税制の適用額は2022年度5,040億円→2024年度9,560億円（29.4万件）。大企業向け4,507億円、中堅企業向け1,723億円、中小企業向け3,330億円
  - 財務省の検証資料にはパネル分析とマクロ分析があるが、パネル分析は「逆因果の課題」、マクロ分析は「有意差なし」と記載
  - 補助金・基金の見直し約20件・170億円に対し、賃上げ税制1本で56倍の規模
- 参考人への事実確認:
  - 2024年度の適用額9,560億円のうち、税制がなくても起きた賃上げの分をいくらと推計しているか（想定答弁：推計していない）
  - 検証資料の後、税務個票を使った因果推計を行ったか
  - 2,000人の境界で新設した中堅企業枠について、境界前後の企業の給与変化を比較したか
- 大臣への問い: 「補助金・基金の見直しで170億円を積み上げた一方、賃上げ税制1本で9,560億円です。56倍の規模の税制に、効いたかどうかの推計がない。これで2027年の期限延長を判断できますか。」
- 大臣に取る約束: 「2027年3月の期限までに、税務個票を使った追加性の推計を公表し、効果の乏しい区分は縮減する。この順序を約束していただけますか。」
- 質問主意書で求める数表: 賃上げ促進税制の規模別（大企業・中堅・中小）の適用件数・適用額・継続雇用者給与の増加率の分布（2022〜2024年度）
- 逃げ答弁への切り返し:
  - 「賃上げの機運醸成に効果があった」→ 機運は数字で測れません。適用企業と非適用企業の賃上げ率の差を答えてください。
  - 「税務情報は守秘義務がある」→ 集計結果の公表を求めています。国税庁の共同研究では研究開発税制の明細を提供しています。
- 翌年の検証: 2027年2月提出の適用実態報告書で適用額を更新する。租税特別措置の画面で年度別の推移と検証資料の公表の有無を見る
- 問う価値: 歳出の行政事業レビューは租税特別措置を扱わない。適用額の規模を歳出の見直し額と並べるだけで、検証の非対称が数字で示せる。
- 画面: `/tax-expenditures`（租税特別措置の適用額と試行評価を見る）
- 注意: 適用額は税額控除の額で、廃止すれば同額の増収になるわけではない。適用額の大きさ自体は政策の失敗を意味しない。
### 使い方の順序（提案）

1. Q1 記載の穴（約束型）。既存データだけで今すぐ質問にでき、翌年のシートで検証が完結する
2. Q2 1者応札・Q3 基金は主意書を先行させ、答弁書（7日）が出てから質疑に立つ。Q2 は委員会の検査要請（国会法105条）を併用する
3. Q4 補正予算・Q5 防衛費は所管委員会で参考人に事実確認してから大臣に評価を問う
4. 残りの5本は同じ型で、所管委員会の日程に合わせて使う
5. いずれも「このサイトで誰でも再現できる」ことを添え、答弁後に画面を更新して追跡する

## 4. 再集計の手順

数値は次のファイルを Node で読んで集計した（スクリプトは scratchpad で実行、恒久化していない）。

| 示唆 | ファイル | 集計 |
|------|----------|------|
| 1者応札 | `contract-methods-2025.json` | `m` が `open-tendering-*`/`selective-*` で `ap` あり → `ap===1` の件数・金額。`br` の平均。府省は `project-quality-scores-2025.json` の `ministry` |

| その他 | `others-counts-2025.json`、`project-quality-scores-2025.json` | `n`・`a` の合計、`opaqueRatio` の `spendTotal` 加重平均、`cnFillRatio` の `recipientCount` 加重平均 |

| 検査 | `audit-report.json`、`budget-execution-audit.json` | `byPid` の交差、`reflectionAmount` の合計 |

| 長期継続 | `rs2025-project-details.json` | `startYear`・`noEndDate` |
