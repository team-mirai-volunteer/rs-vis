# 概算要求と RS 事業の対応、府省別一覧、LP 広報カードの原資料化

## 依頼
1. 概算要求の明細を RS の事業詳細から見られるようにする（翌年度要求を事業詳細に出す）
2. 府省別の要求額一覧を出す
3. 資料一覧は「どういう PDF か」が分かるように精査する。要求ではない補足資料が混じっている
4. LP の広報カードは FNN 報道の転記のままで意味がないので、当サイトの数字と原資料で組み直す

## 分かったこと

- RS のレビューシート 2-2 は事業ごとに 所管・組織・項・目 と、当初予算額・翌年度要求額を持つ。サイトはすでに 2025 年版の翌年度要求額（2026 年度要求）を評価一覧の仮想年度 2026 と「要求→査定ビュー」で使っている。RS 公開 API の 2026 年版（暫定）には要求額が無いので、2027 年度要求は自動取得した明細表だけが情報源
- 明細表は 項・目 単位（事業単位ではない）。RS の 目 の名前で突き合わせると、取得できた 28 府省で鍵の 85% が一致し、2,972 事業中 2,424 事業に対応がつく。目 は複数事業で共有されるので事業ごとに按分はしない
- **報道の「広報費 10 倍」の正体**: 内閣官房「令和9年度予算概算要求の概要」の表で内閣広報室は 2026 年度予算 7.0 億円 → 2027 年度要求 72.3 億円（7,228 百万円）。うち 64.8 億円（6,484 百万円）が「強く豊かな日本」投資枠で、通常要求分は 7.4 億円と横ばい。投資枠一覧では「官邸からの情報発信及び収集分析経費」58.7 億円、「内閣広報充実強化研究調査等経費」6.2 億円。歳出概算要求額明細表（内閣広報室の表 r9_11.pdf）の各経費は前年度とほぼ同額。概要の説明は「国民に届きやすい多彩な動画発信を強化」で、成果の測り方の記載はない。内閣府「政府広報室」は 78.7 億円で横ばい
- 内閣官房の掲載ページ（cas.go.jp/jp/yosan/index.html）は自動取得時に 404 だったが現在は 200。法務省も 200。経産省・公取委は bot の User-Agent だけ 403（ブラウザ UA では 200）

## 作ったもの

| 場所 | 内容 |
|---|---|
| `scripts/generate-budget-request-links.ts` | RS 2-2 と明細表の突き合わせ。`npm run generate-budget-request-links` → `public/data/budget-request-links-2027.json.gz`（209KB） |
| `types/budget-request-links.ts` | 対応データの型 |
| `app/lib/api/budget-request-links-loader.ts`、`app/api/budget-request-links/[pid]`、`app/api/budget-requests/summary` | 事業ごとの対応、府省別の総計 |
| `client/components/unified-budget/ProjectBudgetRequest.tsx` | 「2027年度概算要求」の段（目ごとの要求額・前年度・増減・原資料のページリンク、3 件で折りたたみ）。サンキー図の詳細パネルと政策評価の詳細に配置 |
| `app/budget-requests/view.tsx` | 先頭に「府省・組織別の要求額（明細表の総計行）」の表。資料カードに「資料の種類」バッジ、絞り込みを「資料の種類」に（`documentKind`） |
| `app/lp/insights.ts` | 広報カードを原資料ベースに書き換え（図の数字 64.8 億円、見出し「広報費『10倍』の正体は投資枠 64.8 億円。通常要求は横ばいで、政府広報室も横ばい」） |
| `tests/budget-request-links.test.ts` | 突き合わせの単体テスト（合算、目の一意一致、未取得府省） |

## 残っている穴
- 厚労省（明細表に文字層がない）、経産省・公取委（403）、内閣官房（取得時 404）は対応がつかない。内閣官房・法務省は今なら取れるので、手動起動で再取得してから `generate-budget-request-links` を再実行する
- 概要・要望一覧・投資枠一覧は数値未抽出のまま（自由レイアウト）。広報カードの投資枠の数字は原資料を直接読んで書いた
