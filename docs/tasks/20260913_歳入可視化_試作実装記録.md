# 歳入・国民負担可視化の試作

`/tax-burden` を追加。設計の全フェーズ完了ではなく、確認済みの資料から画面・制度計算・改革比較を試せる実装。Phase 0の未完了事項は[確認記録](./20260913_歳入可視化_Phase0確認記録.md)に記載。

## 実装した機能

- 6類型（単身、ひとり親子2人、片働き夫婦と共働き夫婦それぞれ子なし・子2人）。大人20〜64歳、子6歳・8歳を固定。年収0〜2,000万円、所得按分、賞与を切替。
- 2025年OECD説明書ベースの参考計算。所得税、住民税、標準報酬表による本人保険料、児童手当・児童扶養手当を年額で計算。モデル適用範囲は就労者ごとに判定。非就労配偶者は判定から除外。
- 複数曲線、年収選択、負担額・純負担率・内訳表。適用範囲外は薄線と理由を表示。年収0円は率を未定義として金額のみ表示。
- 改革案：所得税の基礎控除追加、本人保険料倍率、児童手当額、世帯単位の給付付き控除（年額・逓減開始・逓減率）。改革案カーブと世帯1件あたりの税収差・保険料差・給付支出差を表示。
- URL共有。モデル版・制度年・世帯・年齢・年収・按分・賞与・表示・改革パラメータを復元。無効値は既定値に戻して理由を表示。localStorageは使用していない。
- 歳入：既存の管理済みMOF `.gz` にある一般会計税目別収入を再利用。UIは2025年度、API・生成データは2017〜2026年度。保険料・地方税を足さない。
- 共通ナビ、出典・条件のダイアログ、読込・エラー・再試行、実態統計未収録の空状態。

## データと構成

- `scripts/data/tax-burden-params-2025.json`: 手入力パラメータ、出典、未照合事項。原本PDFのハッシュは未取得を表す `null`。基準版の定数を黙って最新制度に更新しない。
- `npm run generate-tax-burden-data`: パラメータと一般会計歳入をJSONと`.gz`に生成。古いraw形式の混入を避け、MOFは管理済み`.gz`から読み込む。
- `npm run validate-tax-burden-data`: 金額・適用範囲・恒等式と10年度の税目合計を検証。R8照合済みとは報告しない。
- `app/lib/tax-burden/`: React・HTTPに依存しない計算。APIは既存の`readDataJson`・`API_CACHE_CONTROL`を使用。
- `client/components/tax-burden/`: チャート・コントロール・内訳・歳入。API呼出しと状態はページに集約。
- `compress-data`には本機能の圧縮処理を追加。`decompress-data.sh`の既存`.gz`一括同期で本番の`data/server`に同梱される。

## 検証

- `npx tsc --noEmit`。
- `npm run test:tax-burden`: 計算の境界・符号・未定義率・消費税仮定・URL・実APIハンドラ。
- `npm run validate-tax-burden-data`: 48,024計算点と2017〜2026年度の税目合計。
- `npm run test:tax-burden:browser`: Chromiumで実Reactページと実生成データを使用。NextのLink/Imageだけをアダプタに置換し、HTTPをメモリ内で応答。改革操作、リロードでURL復元、ダイアログ、実歳入表示、統計空状態、390px幅、年収0円を確認。これはNextサーバー統合テストの代替ではない。
- `tests/e2e/tax-burden.spec.ts`: 通常環境向けNext統合テストを追加。この環境はソケット待受がEACCESのため未実行。
