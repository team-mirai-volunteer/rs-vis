# 歳入・国民負担可視化の試作（実装記録）

`/tax-burden` の実装記録。2026-09-13 の初版（別セッション）に、2026-09-14 の検証（[検証結果](./20260914_0725_歳入可視化_試作実装の検証結果.md)）で見つかった修正と、追加ビュー（年齢軸・税目別ヒートマップ・消費税推計・OECD 比較・実態統計）を反映した現状を記す。設計は [設計書](./20260913_0512_歳入・国民負担率可視化（所得階層×年齢×家族構成別の税負担、翁カーブ）設計.md)。

## 計算モデル（`app/lib/tax-burden/`）

- モデル版は `prototype-2025-3`（住民税の前年所得課税と老人控除対象配偶者の調整控除を反映。旧版の共有URLは既定値に戻り警告を表示）。
- `household-tax.ts`: 共通コア。大人（給与・年金・年齢・被用者保険の有無）と子の年齢配列から、所得税・住民税・保険料・給付を計算。給与所得、公的年金等控除（65歳未満／以上）、基礎控除（2025年改正の段階表）、配偶者（特別）控除・老人配偶者控除、扶養控除（一般・特定）、ひとり親控除、住民税非課税判定（1級地）、調整控除（**法定の人的控除差**：基礎5万円ほか）、均等割4,000円＋森林環境税1,000円、児童手当（3歳未満1.5万円・3歳〜18歳1万円）、児童扶養手当（所得＝給与所得−8万円、令和6年度係数）、被用者保険（標準報酬表）、国民健康保険（特別区）、後期高齢者医療（東京都広域連合）、第1号介護保険（国の標準13段階×全国平均基準額）、年金生活者支援給付金。
- `simulate.ts`: 現役世帯（ビューC/D）。子は大人32歳・34歳時に生まれ23歳で独立（大人40歳で8歳・6歳＝従来と同じ）。
- `simulate-lifecycle.ts`: 年齢軸。老齢基礎年金満額＋報酬比例（平均標準報酬額×5.481/1000×480か月）、在職老齢年金、ライフステージ判定、ヒートマップ格子。**住民税は前年所得課税**（その年に納めるのは前年の所得・社会保険料で計算した額。就労初年度は0、減収・退職の翌年は前年の給与で課税）。国保・後期・第1号介護も実際は前年所得基準だが当年所得で計算しており未対応。
- `heatmap-items.ts`: ヒートマップのセル値（すべて現役期年収比、受け取りは負値）と、その世帯で支給され得る給付だけを表示対象に絞る判定。
- `consumption-tax.ts`: 税込支出×r/(1+r)、十分位バスケットの年収比を線形補間、支出比の検証は使用税率から動的算出。
- `fiscal-impact.ts`: 区分別の収支差。消費税差額は法定配分（国78：地方22）。バスケットが無ければ `uncomputed`。

## 照合（R8）

`npm run validate-tax-burden-data` が OECD Taxing Wages 日本2025年の8定点で所得税・地方税・本人保険料・現金給付を照合する。差はすべて OECD 側の簡略化（保険料を総給与に定率 9.15%＋5%＋0.55%、介護保険なし、森林環境税なし）で説明でき、保険料差に誘発される税差の範囲内。ひとり親は OECD 2025 行がひとり親控除を適用していないため給付のみ比較。翁カーブ原図（NIRA No.89）とは前提（夫婦按分・子の年齢・制度年）が異なるため「再現」とは称さない。

## 未提供・注意

- 全国財政総額（復元世帯数と母集団一致の確認待ち）、年齢×年収×家族構成の統計クロス表、高齢者世帯の実測値、1億円の壁、金融所得課税。
- 国保・後期・第1号介護の料率は令和6〜7年度の公表値を転記したが特定自治体の計算例との照合は未完了。年金は再評価率・経過的加算・繰上げ繰下げを未反映。
- 消費税推計は二人以上の勤労者世帯の支出構成を全類型に当てている（単身は参考値）。
- 現金給付は児童手当・児童扶養手当・年金生活者支援給付金・改革案の追加給付のみ。生活保護・住宅手当・就学援助・現物給付は未実装。年金生活者支援給付金は満額基礎年金（83.2万円）が所得要件（78.9万円）を超えるため常に0で、補足的老齢年金生活者支援給付金も未実装。
- OECD 比較の連続系列は片働き（配偶者収入なし）と単身のみ。共働きは OECD が定点しか公表していないため、画面でも定点のみ表示する（按分もOECD側は60:40・50:50で固定）。
