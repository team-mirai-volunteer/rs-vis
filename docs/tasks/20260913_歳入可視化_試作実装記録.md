## 計算モデル（`app/lib/tax-burden/`）

- モデル版は `prototype-2025-4`（住民税の前年所得課税、老人控除対象配偶者の調整控除、被用者保険の賃金要件と国民年金を反映。旧版の共有URLは既定値に戻り警告を表示）。
- 改革案のレバーは制度の形に合わせる。定率のもの（住民税の所得割、年金・医療・介護・雇用の本人保険料率、消費税の標準・軽減税率）は料率そのもの、累進の所得税は基礎控除の上乗せ、給付は児童手当と給付付き控除。保険料率の変更は国保・後期高齢者医療・第1号介護保険料にも同じ比率で反映するので、1本のスライダーが分解表示の1行に対応する。住民税の均等割と森林環境税は定額なので動かない。各スライダーには数値入力欄があり税率を直接打ち込める。基礎控除は「追加額」ではなく選択中の年収に適用される現行額（58〜95万円のいずれか）を表示し、そこからの差額を全階層に足し引きする（下げる操作も可、控除は0円で下げ止まり）。負担カーブ・年齢・ヒートマップの3ビューすべてに効く。
- `household-tax.ts`: 共通コア。大人（給与・年金・年齢・被用者保険の有無）と子の年齢配列から、所得税・住民税・保険料・給付を計算。給与所得、公的年金等控除（65歳未満／以上）、基礎控除（2025年改正の段階表）、配偶者（特別）控除・老人配偶者控除、扶養控除（一般・特定）、ひとり親控除、住民税非課税判定（1級地）、調整控除（**法定の人的控除差**：基礎5万円ほか）、均等割4,000円＋森林環境税1,000円、児童手当（3歳未満1.5万円・3歳〜18歳1万円）、児童扶養手当（所得＝給与所得−8万円、令和6年度係数）、被用者保険（標準報酬表。賃金要件は月8.8万円＝年105.6万円で、これ未満なら国民年金第1号＋国民健康保険に切り替わる。配偶者が被用者保険なら第3号で保険料なし。国民年金は申請免除の4段階を判定）、国民健康保険（特別区。子どもも均等割の対象）、後期高齢者医療（東京都広域連合）、第1号介護保険（国の標準13段階×全国平均基準額）、年金生活者支援給付金。
- `simulate.ts`: 現役世帯（ビューC/D）。子は大人32歳・34歳時に生まれ23歳で独立（大人40歳で8歳・6歳＝従来と同じ）。
- `simulate-lifecycle.ts`: 年齢軸。老齢基礎年金満額＋報酬比例（平均標準報酬額×5.481/1000×480か月）、在職老齢年金、ライフステージ判定、ヒートマップ格子。**住民税は前年所得課税**（その年に納めるのは前年の所得・社会保険料で計算した額。就労初年度は0、減収・退職の翌年は前年の給与で課税）。国保・後期・第1号介護も実際は前年所得基準だが当年所得で計算しており未対応。
- `heatmap-items.ts`: ヒートマップのセル値（すべて現役期年収比、受け取りは負値）と、その世帯で支給され得る給付だけを表示対象に絞る判定。
- `incidence.ts`: 法人税の賃金への転嫁（仮定）。全国の法人所得課税 × 帰着シェア ÷ 賃金・俸給を給与に掛ける。既定シェアは0%で計算に入らない。
- `consumption-tax.ts`: 税込支出×r/(1+r)、十分位バスケットの年収比を線形補間、支出比の検証は使用税率から動的算出。
- `fiscal-impact.ts`: 区分別の収支差。消費税差額は法定配分（国78：地方22）。バスケットが無ければ `uncomputed`。

## 照合（R8）

`npm run validate-tax-burden-data` が OECD Taxing Wages 日本2025年の8定点で所得税・地方税・本人保険料・現金給付を照合する。差はすべて OECD 側の簡略化（保険料を総給与に定率 9.15%＋5%＋0.55%、介護保険なし、森林環境税なし）で説明でき、保険料差に誘発される税差の範囲内。ひとり親は OECD 2025 行がひとり親控除を適用していないため給付のみ比較。翁カーブ原図（NIRA No.89）とは前提（夫婦按分・子の年齢・制度年）が異なるため「再現」とは称さない。

## 未提供・注意

- 全国財政総額（復元世帯数と母集団一致の確認待ち）、年齢×年収×家族構成の統計クロス表、高齢者世帯の実測値、1億円の壁、金融所得課税。
- 国保・後期・第1号介護の料率は令和6〜7年度の公表値を転記したが特定自治体の計算例との照合は未完了。年金は再評価率・経過的加算・繰上げ繰下げを未反映。
- 消費税推計は二人以上の勤労者世帯の支出構成を全類型に当てている（単身は参考値）。
- 子どもの出産年齢は第1子・第2子それぞれスライダー（18〜45歳・既定32歳と34歳、第2子は第1子以降）。年齢を軸に取るビュー（年齢で見る・税目×年齢×年収）にだけ置いている。児童手当も扶養控除も子の年齢で決まるため、年齢軸のどこで給付・控除が切れるかは制度ではなく出産年齢の置き方で決まる。既定では児童手当は親52歳まで、扶養控除は親56歳まで。
- 年齢で見るビューは、グラフも表も「割合→金額（年額）」の順に揃えている。
- 負担率の分母は左パネルで切り替える。既定は「その年の総収入（給与＋年金）」で、ふつうの負担率の読み方。年金は分母に入るため、年金だけの年でも純負担は正（本モデルで10〜17%）に出る。もう一方の「現役期の年収」は、どの年齢も現役期の世帯年収で割り公的年金の受給を負担のマイナスとして扱う置き方で、同じ所得階層の人が生涯でどれだけ払い受け取るかを1つの尺度で見るためのもの。年金受給期は大きな負の値になる。総収入の分母では「公的年金の受給」のヒートマップ表は出さない（年金だけの年は必ず-100%になり負担の情報が無いため）。
- 働いていない年齢の住民税は2種類。退職の翌年に前年の給与で計算した額が1回乗る分（前年所得課税）と、66歳以降も続く公的年金への課税分。後者は公的年金等控除後の合計所得が非課税限度額を超える世帯だけで、片働き夫婦・子2人なら現役期年収800万円以上で年約4.7万円、500万円以下は0。66歳以降の住民税が段階的に下がるのは2つの理由による。71歳の段差は配偶者が70歳で老人控除対象配偶者になる分（前年所得課税なので翌年に出る）、76歳の段差は75歳で医療保険が後期高齢者医療に替わり、世帯で等分する国民健康保険と違って個人単位で保険料が決まるため、社会保険料控除が年金の多い側へ寄る分（現役期800万円の片働き夫婦で 4.74万 → 71歳 3.99万 → 76歳 3.73万）。
- 負担カーブの縦軸は10%刻みの目盛りで、消費税を含める／含めないの両方を収める範囲を取る。トグルを切り替えても目盛りは動かず線だけが動く。
- ヒートマップの濃淡は緑（負担）と橙（差し引き）で別々に、その表に出てくる値の最小〜最大へ広げる。純負担は現役期が+12〜44%、年金期が-93%まで届くため、0〜最大の一本の尺度では現役期がすべて同じ薄さに潰れていた。
- 給与だけの世帯では、賃金要件（年105.6万円）未満の給与所得は最大40.6万円で国民年金の全額免除基準（67万円）を下回るため、この年収帯の年金保険料は0になる。国民年金の一部免除（4分の3・半額・4分の1）は給与のみの世帯では発動しない。学生納付特例・納付猶予・産前産後免除、国保の未就学児軽減は未実装。年収がごく低い側で負担率が上がり続けるのは国民健康保険の均等割（軽減は最大7割で、単身でも年約2.5万円が残る）が所得に関わらずかかるため。この水準は実際には生活保護の対象で国保の適用外になるが、生活保護は未実装。国保の適用除外のうち、被用者保険の被扶養者と後期高齢者医療は実装済み、生活保護世帯と国保組合は未実装。薄線（適用範囲外）の境目はフルタイム最低賃金（219万円）ではなく被用者保険の賃金要件（105.6万円）。これを超えれば厚生年金・健保に入るので計算は確定し、下回る帯だけが生活保護・無保険・被扶養者のどれになるかで変わる。縦軸は-50%で頭打ちにして、ひとり親の低所得側が図全体を潰さないようにしている。生活保護を入れるには生活扶助基準額表（第1類・第2類・逓減率・級地）と住宅扶助の扱い（実家賃か上限か）の決めが要る。
- OECD Taxing Wages の値は所得税・本人社会保険料−現金給付だけで、消費税も事業主負担も含まない。そのため消費税または法人税の転嫁を入れている間は、同じ項目を OECD の帯・平均・日本の線にも足して比較の分子を揃える（`app/lib/tax-burden/oecd-overlay.ts`）。消費税は日本の線に日本の税率（標準10%）、OECD の帯と平均に加盟国の標準税率の平均（19.3%）を当て、支出構成は両方とも家計調査の日本のものを使う（各国の課税・軽減・非課税の範囲は違うが、比較可能な国別バスケットが無いため。軽減税率は標準の0.8倍＝日本の8/10と同じ比率と仮定）。法人税の転嫁は日本の線に日本の比率（2024年11.9%）、OECD の帯と平均に加盟33か国の平均（2022年10.8%）を当てる。年が違うこと、ノルウェーの石油課税が平均を押し上げていること（中央値8.5%）は注記で明示。国ごとの消費税率・法人税の違いは帯の幅には反映していない。事業主負担はどちらにも含まない。
- 法人税の転嫁は利用者が置く仮定で、既定は50%。労働への帰着シェアに確立した値は無い。日本を対象にした分析では土居丈朗（RIETI DP 16-E-022, 2016）が1年で労働所得に6割弱・長期で約90%、事業税の付加価値割・資本割を加えた同（RIETI DP 17-J-051, 2017）が1年で約27%・長期で約78%と試算しており、いずれも動学的一般均衡モデルのシミュレーションで個票による実証推計ではない。公的機関の分配分析の慣行は米国CBO・JCT 25%、米国財務省 18%。既定の25%は、土居（2017）の1年の帰着（約27%）と公的機関の分配分析の慣行（18〜25%）に合わせた保守的な置き方で、スライダーで0〜100%に動かせる。同じ分析でも長期の推計は78〜90%と大きく違う。全国の賃金に一律の率として配分し、年齢・賃金による帰着の違いは置いていない。
- 現金給付は児童手当・児童扶養手当・年金生活者支援給付金・改革案の追加給付のみ。生活保護・住宅手当・就学援助・現物給付は未実装。年金生活者支援給付金は満額基礎年金（83.2万円）が所得要件（78.9万円）を超えるため常に0で、補足的老齢年金生活者支援給付金も未実装。
- OECD 比較の連続系列は片働き（配偶者収入なし）と単身のみ。共働きは OECD が定点しか公表していないため、画面でも定点のみ表示する（按分もOECD側は60:40・50:50で固定）。
