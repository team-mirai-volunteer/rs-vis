## 実装と照合した事実（ポリシーの根拠）

- 意見投稿は本文（1,000 字以内）・事業 ID・年度・投稿日時・`ip_hash`（ソルト付きハッシュ）・`status` を Supabase（東京）に保存。対話全文（transcript）は `insertComment` で常に `null`（`app/lib/comments/comments-store.ts`）。
- レート制限は `rate_limits` テーブルで 1 時間 5 件。古い窓は次回呼び出し時に 2 時間で掃除（`supabase/schema.sql`）。
- 投稿前のスクリーニングはルールベース（URL・連絡先・記号連打）。NG は `hidden` で保存し非公開。
- BYOK のキーは IndexedDB（`client/lib/ai/api-key-store.ts`）。会話はブラウザから OpenRouter へ直接。
- サイト提供 AI は `app/api/ai/interview` と `app/api/ai/sankey-chat` を経由して OpenRouter へ。利用ログ（`app/lib/api/usage-log.ts`）はローカル開発時のみ書き込み、Vercel と production では無効。
- 解析ツール・Cookie の実装なし（`@vercel/analytics`、GA、Sentry などは不検出）。localStorage は表示設定（`mof-kou:year`）のみ。
- ソースコードは GitHub で公開（AGPL-3.0）。

## 法務確認で見てほしい点

1. **運営主体の表記**: 「チームみらい（当団体）」でよいか。政党としての正式名称や所在地の記載が必要か。まるみえ・みらい議会は所在地を載せていない。
2. **問い合わせ先**: support@team-mir.ai を流用した。このサイトの窓口として使えるか。
3. **意見投稿の利用許諾（第4条2項）**: 「政策の検討」「集計・分析と公表」まで含めた無償・無期限の許諾と著作者人格権の不行使が、みらい議会の運用と整合するか。公開同意の取り方（投稿ボタンの直上に文言）で足りるか。
4. **引用・転載の許可範囲（第6条3項・4項）**: 出典明記を条件に引用・転載を許すのはサイトの目的（国会質問・報道での利用）に合わせた独自の条項。まるみえは私的利用のみ。競合サービスの禁止条項の要否と表現。
5. **元データの利用条件**: RS の公共データ利用規約（PDL1.0）、政府標準利用規約の求める出典表示・加工表示がページ側で満たされているか（LP とトップのフッターに記載）。
6. **AGPL-3.0 との関係**: コード公開と規約の知的財産条項（第6条1項）が矛盾しない表現になっているか。
7. **IP アドレスのハッシュ**: ソルト付きハッシュを保存することを「元の IP は保存しない」と説明してよいか（個人情報該当性の整理）。
8. **ホスティング事業者のアクセスログ**: Vercel のログを「取得する情報」に含めたが、委託先として書く粒度（会社名・国）が適切か。越境移転の記載が必要か（Vercel は米国法人、Supabase は東京リージョンだが米国法人）。
9. **AI 事業者への送信**: BYOK ではユーザー自身が OpenRouter と契約している整理でよいか。サイト提供 AI では当団体が OpenRouter に委託している整理でよいか。モデル提供元（学習利用の有無）について追加の説明が必要か。
10. **保管期間**: 「運営に必要な期間」でよいか、年限を切るべきか。まるみえ・みらい議会は政治資金規正法を根拠に 7 年としているが、このサイトには寄付がない。
11. **未成年**: 年齢制限や保護者同意の記載を入れるか（投稿機能がある）。
12. **免責（第7条）**: 「故意または重大な過失がある場合を除き」の限定が消費者契約法上の観点で妥当か。
13. **規約の変更（第8条）**: 掲示をもって効力とする扱いが、民法の定型約款の変更要件（周知）を満たすか。

## 更新のしかた

- 文言の変更は `app/terms/page.tsx` と `app/privacy/page.tsx` を直接編集し、`app/lib/legal.ts` の日付を更新する。
- 解析ツールの導入、投稿データの保存内容の変更、AI の接続先の変更をしたときは、プライバシーポリシーの第 2・4・5・6 項を必ず見直す。

## 改定（2026-10-10）: みらい議会の粒度に揃える

- プライバシーポリシーと利用規約第5条から、事業者名（Vercel・Supabase・OpenRouter）、ブラウザ内の保存方式（IndexedDB）、BYOK とサーバー経由の方式ごとの送り先の説明を削除。「外部の AI サービスで処理し、当団体は保存しない」「ホスティング・保管・AI 応答の生成を外部サービスに委ねている」という一般的な記述に置き換えた。
- 理由: みらい議会・まるみえと同じ水準に合わせる。事業者名を公開文書に書くと攻撃者に構成を教えることになり、将来ホスティングやデータベースを替えたときに改定が必要になる。
- 構成は 9 項（定義、取得する情報と利用目的、第三者への提供、安全管理、Cookie とブラウザ内の保存、保管期間と削除、開示等の請求、お問い合わせ、改定）。
- 法務確認の論点 8（委託先の記載粒度・越境移転）は、事業者名を書かない前提で「外部サービスへの委託がある旨で足りるか」に読み替える。

## 改定（2026-10-10）: 対話ログを保存する（みらい議会に合わせる）

- 投稿 API が受け取っている対話ログ（transcript）を、意見文とあわせて非公開で保存するよう変更（`app/lib/comments/comments-store.ts` の `transcript: null` を解除）。公開ロールには列権限が無いので外に出ない（`supabase/schema.sql`）。
- 画面の同意文を「対話内容は公開せず、当団体が運営・政策の検討・不正対策のために保存します」に変更（`client/components/comments/InterviewDialog.tsx`）。
- 利用規約 第4条を「意見の投稿と対話ログの取り扱い」に改め、みらい議会 第3条に倣って、対話ログの内部利用、第三者提供なし、権利の帰属または無償の利用許諾、著作者人格権の不行使を明記。
- プライバシーポリシー 2 項に対話ログの取得と利用目的、3 項に「対話ログは公開せず第三者に提供しない」、6 項に保管期間「原則 7 年」を追加。
- 法務確認の追加論点: みらい議会の 7 年は政治資金規正法を根拠にしているが、このサイトには寄付が無いので法令の根拠は書いていない。期間の妥当性と根拠の要否を確認してほしい。対話ログを将来オープンデータ化する場合は、みらい議会のように公開同意の UI と別規約が要る。

## 改定（2026-10-10）: 社内レビューの指摘への対応

### 直した点
1. 規約第5条1・ポリシー2項「AI 機能への入力」: 「意見投稿で送信された対話ログを除き、当団体は保存しない」と但し書き。外部 AI サービスが自社条件で一時保持することがある旨も追加。BYOK モードの画面表示を「会話は投稿するまでサーバーに送られません」に修正
2. ポリシー2項の IP: 「復元できない形に加工」をやめ、「当団体だけが持つ秘密の値を加えたハッシュ値に変換して保存（生の IP は保存しない）」に。実装は秘密ソルト + SHA-256（`hashClientIp`）
3. 規約第4条3: 権利の「帰属」をやめ、無償・無期限の利用許諾（複製・加工・翻案を含む）のみに。著作権法 27・28 条の明記は帰属構成をやめたので不要。著作者人格権の不行使は維持
4. 規約第7条2（変更・中断・終了の免責）に「故意または重大な過失がある場合を除き」を追加（消費者契約法 8 条 1 項）
5. 規約第8条・ポリシー9項: 変更内容と効力発生日を事前に掲示する形に（民法 548 条の 4）
6. 細かい点: 第4条2 を「ポリシー第3項に定める場合を除き第三者に公開・提供しない」に、ポリシー3項2 に「次項の委託先を除き」を追加

### 法務に判断してもらう論点（レビューからの追加）
- 外国にある第三者への提供（個人情報保護法 28 条）: DB とサーバーは国内（東京）だが、AI は米国の事業者を経由し、既定モデルは米国企業。ポリシーは「外部のサービスに委ねている」とだけ書いている。政治団体の適用除外（57 条）に当たるか、当たるとしても移転先の国名などをどこまで書くか
- 公表事項（32 条）: 団体の住所と代表者の氏名が無い。党本体のポリシーにも無いので、党全体で揃えるか
- 保管期間「原則 7 年」: 党本体の 7 年は政治資金規正法が根拠。匿名の意見と対話ログには同じ根拠が無いので何年にするか
- 第三者提供の例外「不正アクセスや本規約違反への対応のために必要な場合」: 法律上の例外（27 条 1 項）より広く読める。党本体と同じ書き方なので党全体で判断
- 匿名投稿の削除依頼の本人確認: 投稿は公開されているので日時と内容を言えば本人でなくても削除を頼めてしまう。投稿時に削除用コードを出す実装か、「当団体の判断で対応」と規約に書くか
- OpenAI の利用規約と政治活動の関係（既定のインタビューモデルが OpenAI）
