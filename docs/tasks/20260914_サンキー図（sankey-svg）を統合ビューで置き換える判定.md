# サンキー図（/sankey-svg）を統合ビュー（/budget-sankey）で置き換える判定

## 結論

置き換え可能。統合ビューの「RSのみ」プリセットは所管 → 事業 → 事業(支出) → 支出先で、
サンキー図本体と同じ流れを同じデータ（sankey-svg-2025-graph）から描いている。
サイドパネルの事業詳細（意見・政策評価・事業概要・予算執行・再委託・法人番号）も移し終えた。
ただし下の 6 点を埋めてから切り替える。いずれも既存コードの移植で、設計変更は要らない。

## 残っている差分

| # | サンキー図にあって統合ビューに無いもの | 対応 |
|---|---|---|
| 1 | **年度**: シート 2024（= 2023 年度執行・支出先）。統合ビューの執行年度は 2024 のみ | 予算年度 2023 の統合グラフを生成（MOF 2023・linkage-2023 は既存。linkage-2023 は旧形式なので rsSheetYear 付きで再生成） |
| 2 | **絞り込み**: 予算額・支出額の上下限、事業名・支出先名の正規表現、再委託の有無/階層、政策評価スコア（総合・費用対内容・必要性）の範囲、省庁クリックでの絞り込み | `UnifiedViewFilter` に項目を追加し `applyFilter` に純関数で実装（sankey-svg-filter.ts の関数を流用）。UI は絞り込みパネルへ |
| 3 | **AI チャットパネル・探索履歴**（フィーチャーフラグ。公開ミラーでは非表示） | 統合ビューの選択状態・URL 状態に接続し直す。公開先で使っていないなら後回し可 |
| 4 | **狭幅（スマホ）レイアウト**（isCompactWidth 分岐） | 統合ビューは PC 前提。置き換え時に最低限の折り返しを入れる |
| 5 | **深いリンクの互換**: `sel=ministry-〇〇` / `fm=` などサンキー図固有のパラメータ。API の `links.sankeyWeb`、再委託ページ・バブルチャート・AI ツール・sitemap・トップページ CTA が `/sankey-svg` を指す | `/sankey-svg` を残してパラメータを統合ビューへ写像するリダイレクトにする（`project-budget-{pid}` は同じ ID。省庁は `ministry-` → `min-`）。`app/lib/api/links.ts` と `pages.ts` を差し替え |
| 6 | **e2e**: サンキー図に 13 本、統合ビューに 0 本 | 同じシナリオ（検索・選択・年度切替・表示範囲・deep link）を統合ビュー向けに書き直す |

## 進め方（順番）

1. 統合ビューの e2e を先に書く（移植の受け皿。既存 spec を写す）
2. 絞り込みの移植（#2）。データは既に持っているので UI と純関数の追加のみ
3. 予算年度 2023 の生成（#1）。年度セレクトが 2023〜2026 になる
4. `/sankey-svg` をリダイレクトに変え、リンク元・API・sitemap・ナビを更新（#5）。ページ本体（5,000 行）と `client/components/SankeySvg/*` の一部を削除
5. AI チャット（#3）は公開先で必要になった時点で

## 実施結果（2026-09-14）

- **e2e**: `tests/e2e/budget-sankey.spec.ts`（13 件）と `tests/e2e/sankey-svg-redirect.spec.ts`（2 件）を追加。旧 `sankey-svg.spec.ts` は削除
- **絞り込み**: 予算額・支出額の上下限、事業名/支出先名の正規表現（再委託先を含めて判定）、再委託の有無と階層、政策評価スコアの範囲を移植。
  URL は fbmin/fbmax/fsmin/fsmax/fpq/fpr/frq/frr/frs/fsub/fsd/fso/fsx/fsn。事業ノードに subcontractDepth / subcontractRecipients を同梱
- **2023 年度**: 予算年度 2023（シート 2024 = 2023 年度執行）の 3 基準を生成。ただし RS シート 2024 の CSV は rssystem.go.jp から再取得できず
  （ダウンロード一覧が無い）、目↔事業の紐づけは旧形式の `mof-rs-kou-moku-linkage-2023`（5,933 リンク）のまま。
  そのため会計〜目側の未突合率が高い（当初 16.6%・決算 20.4%）。RSのみプリセットには影響しない。validate は 2023 の当初・決算だけ閾値 25% で通す
- **リダイレクト**: `/sankey-svg` は旧パラメータを統合ビューの語彙へ写して 307。`fm`（RS 府省庁名）は MOF 所管と体系が違うため写さない。
  API の `links.sankeyWeb` 系、再委託・バブル・MOF 各ページ、トップページ CTA、サイトマップ、ナビを統合ビューへ差し替え
- **削除**: 旧ページ本体（5,000 行超）、`sankey-svg-ids.ts`、`sankey-svg-year-selection.ts`、`exploration-label.ts`、`useTopNSettings.ts`、`ExplorationHistory.tsx`
- **未対応**: AI チャットパネル（`AiChatPanel` は残置。統合ビューへの接続は必要になった時点で）、狭幅レイアウト、RS 部分だけの軽量読み込み

## 置き換えで消えるもの

- `app/sankey-svg/page.tsx`（5,000 行超）と、そこだけが使っていた `app/lib/sankey-svg-*.ts` の一部
- ページ固有の TopN/オフセット UI（統合ビューの RangeWindowRow に統合済み）

## 注意

- 統合ビューの 2024 年度グラフは 20MB（サンキー図は 16MB）。RSのみで開く場合も全体を読む。
  置き換え時に列プリセット別の軽量ファイル、または RS 部分だけ先に読む分割を検討する
- `/sankey-svg` の URL は外部に共有されている可能性があるため、削除ではなくリダイレクトで残す
