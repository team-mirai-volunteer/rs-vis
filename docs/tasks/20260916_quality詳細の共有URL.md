# 評価一覧の事業詳細を共有する

詳細の選択がReactの状態だけに保存されており、URLのコピーや再読み込みで復元できなかった。

- `/quality?year=2025&detail=1503` で年度と事業を指定し、一覧データの取得後に詳細を開く。
- 詳細を開閉すると履歴に反映し、戻る・進むでも選択を復元する。
- 既存の `pid=` は一覧検索のまま保持する。詳細の解決は検索・ページ送りとは独立して全事業から行う。
- モーダル内に「詳細URLをコピー」を追加。コピーAPIが使えない場合は選択できるURLを表示する。
- 存在しないIDは一覧に戻る案内を出す。2026年度は予算要求モードとして既存の未収録表示を維持する。
- 年度変更時には古い取得を中止し、別年度の一覧データから詳細を表示しない。

本番ビルドと型チェックが成功。関連ブラウザテスト10件が成功し、共有URL、クリップボードの成功・失敗、再読み込み、開閉・年度をまたぐ履歴、2024〜2026年度、未存在IDを確認した。2026年度の未収録表示・通常年度の意見再取得・意見インタビューの既存テストも含む。
