# 概算要求の自動取得・検索（初期実装）

## 実装範囲

- main `fbc14c2` から開始し、公開前に最新main `eea9157` へrebase。既存のNext.js 15.5.27へのセキュリティ更新（PR #23）とLP向けPR #21・#22を保持し、本PRの差分は概算要求機能のみ
- 財務省の公式年度索引から概要・一般会計・特別会計の掲載先を発見し、各府省の公開リンクを取得
- 取得状態、原URL・掲載元URL、取得日時、SHA-256、改訂履歴を保存。HTTP403/404・容量超過・未対応形式を隠さない
- 標準の歳出概算要求明細をPDF座標で抽出し、単位・年度・桁・前年比較・小計を検証。CSV/TSVと既存MOF XMLの明示的な表ヘッダーにも対応
- `/budget-requests` と `/api/budget-requests` で府省・機関等、項目名、資料名、取得状態、資料種別、金額枠を検索・絞り込み
- 各行から原文・原ページ・ハッシュ・警告に戻れる。未取得資料やRS未照合の項目も残す
- Actions更新の設定を追加。レビューを受けて週次・専用ブランチの更新PRへ変更（詳細は末尾）。mainへの直接push・自動マージはしない。新しいAPIキー、外部LLM、追加サービスは不要

## 初回同梱データの範囲（レビュー修正前）

2026年10月8日（UTC）に実取得したスナップショットです。

- 全国リンク表から34府省・機関等、1,453資料/掲載ページを発見
- 取得成功歴241件（HTML等の掲載ページ111件、ファイル130件）
- 57資料、26府省・機関等から21,147行を抽出
- うち17資料は対応レイアウトの抽出が警告なしで完了、40資料は一部抽出
- 未取得1,144件、取得失敗15件。これらも検索できる資料カタログに残す
- 未対応/対象外と年度不一致による抽出失敗も別状態で表示

初回取得は160ファイル上限で開始しましたが、132件までのバッチ保存後に実行環境側で処理が終了したため、その取得済み原本をオフライン再抽出して最終スナップショットにしました。追加の取得成功を装っていません。再抽出では元の取得日時と改訂を保持します。初回の設定は2,000ファイル上限でした。レビュー後は原本・チェックポイントを保持する小さな週次バッチに変更しています。

これは全府省の全要求額を収録したデータではありません。資料/行の件数は、概算要求金額の網羅率でも事業数でもありません。27行で小計不一致、その他で未解決フォントや明細行の警告があり、一部抽出として残します。原文の数値を小計に合わせて勝手に補正しません。

## 実原本から得た回帰

- 内閣府政府広報室3ページ: 37行。通常要求額7,884,742千円＝78.84742億円
- 財務省一般会計歳出152ページ: 1,242行。表紙・総表等は未対応として一部抽出扱い
- 文部科学省一般会計歳出410ページ: 3,412行
- 内閣法制局、宮内庁、カジノ管理委員会などの原本で、前年度の負数記号が項目名に結合されるPDF.jsの文字項目を回帰化。符号の実座標を再構成し、34件の前年比較不一致を解消
- 未解決の前年比較不一致が残る場合は、原文を保持したうえで金額を `extraction_failed` にする安全側の処理を追加

概要の280.49億円と通常要求書78.84742億円を混ぜません。内閣官房72.3億円という報道の額を内閣府/国際広報の額として入れていません。内閣官房の掲載先は今回404で、原資料未検証の報道額は同梱データに使用していません。

## 対象外と制約

- 自由配置の概要・要望/投資枠一覧、画像PDF/OCR、Excel、ZIP内包表の数値抽出
- RSの自動紐付け（全件unmatchedのまま表示）、既存AI評価の引継ぎ、概算要求から成立予算・執行額への読み替え
- 資料横断、親子、通常要求・要望・投資枠の金額合計
- 次年度への自動切替、本番へのマージ/デプロイ、ブランチ保護や権限の変更

- 1440px/390px、戻る/再読み込み、条件クリア、原文開閉、失敗からの再試行をE2Eに追加
- ローカルChromiumは `socket() failed: Operation not permitted` で起動不可。HTTPページ/API・OG画像は確認済み。インタラクティブE2Eは当該コミットのGitHub CIで確認する
