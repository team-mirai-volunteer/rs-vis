# チームみらいデザインシステム適用（Tailwind v3 移植）

`.claude/skills/`（mirai-design スキル）で定義されたチームみらいのデザインシステムを、rs-vis の全公開ページに適用した。

## 前提と方針

- スキルは Tailwind v4（`@theme inline`）+ shadcn 前提。rs-vis は Tailwind v3.4・shadcn 無しのため、トークンを **CSS 変数 + `tailwind.config.ts` の `extend.colors`** に移植した。
- 情報密度の高い可視化ツールなので、**サイズ・余白・高さは現状維持**し、色・角丸・影・フォント・ボタン実装を揃えることを目的とした。
- データ可視化のエンコーディング色（Sankey ノード/リンク、意味色 `semantic-colors.ts`、スコア色、TagChip 意味色、会計区分バッジ）は UI chrome ではないので据え置き。
- 常時ライト固定（`html { color-scheme: light }`）。`dark:` バリアントは全削除。

## 基盤

| ファイル | 内容 |
|---|---|
| `app/globals.css` | トークン定義（`--primary: #2aa693`、warm gray `--background: #f7f4ee`、`--mirai-*`）、フォーカスリング、`.bg-mirai-gradient` |
| `tailwind.config.ts` | トークンを `bg-primary` / `text-mirai-text-muted` / `border-mirai-border` 等のクラスとして公開。`shadow-xs` / `shadow-soft`、`font-sans` = Noto Sans JP |
| `app/layout.tsx` | `next/font/google` で Noto Sans JP（400/500/700）+ Lexend Giga を注入。body `bg-background text-foreground`。`themeColor: #2aa693` |
| `components/ui/button.tsx` `badge.tsx` `card.tsx` | mirai-gikai 正典の cva 実装を v3 に移植。Button は forwardRef・既定 `type="button"`・追加サイズ `xs` / `icon-sm` |
| `lib/utils.ts` | `cn()` |

### 不透明度修飾子の制約

Tailwind v3 は `var(--x)` の hex を alpha 分解できないため、`bg-primary/10` などは **RGB チャンネル変数**（`--primary-rgb: 42 166 147`）を `rgb(var(--x-rgb) / <alpha-value>)` で結んだトークンだけ有効:
background / foreground / card / primary / primary-accent / destructive / mirai-text / mirai-text-muted / mirai-border / mirai-surface / mirai-surface-teal。他は solid で使う。
