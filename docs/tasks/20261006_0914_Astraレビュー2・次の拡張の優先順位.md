# Astraレビュー2：次の拡張の優先順位

外部レビュー（基金・RSの周辺資料・財投・未突合の内訳）の指摘を、手元のデータと公開APIで確認した結果と、次に作るものの優先順位。

## 指摘の確認結果

| 指摘 | 確認結果 |
|------|----------|

## 次に作るものの優先順位

1. **基金の小さな修正**（半日）
   - 一覧に「最新シート年度」の絞り込みを付け、既定は最新年度だけにする。終了した基金は切り替えで出す
   - 同名の基金は、府省・保有法人を名前の横に出し、まとめ版のシートがあるか確認する
2. **基金の支払先**（1〜2日）
   - 取得済みの支払グループを `funds.json` に取り込み、基金の詳細に「誰にいくら」を年度別に出す
   - 法人番号で既存の支出先データ（法人の説明・受注履歴）とつなぐ
   - 国→基金の交付額と、基金→支払先の額は同じお金の別段階なので、合計に足さない
3. **セグメントシート**（2〜3日）
   - 独立行政法人で止まっていた運営費交付金を、法人内の事業区分まで追えるようにする
   - サンキー図では、独法の支出先ノードの先に事業区分をつなぐか、詳細パネルの内訳として出すかを設計で決める
4. **未突合の内訳と基準の明示**（1〜2日）：既存データの組み替えが中心
5. **財政投融資**（大）：計画額・実行額・残高を、歳出とは別の集計として扱う設計から
6. 地方基金の執行状況表・出資状況表は、入手方法を調べてから判断する

予算執行調査（財務省）と決算検査報告（会計検査院）は、このレビューの後に `dev` へ入れた。外部の評価の取り込みとしては、この2つが先行している。
