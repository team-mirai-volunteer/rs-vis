# 社会保険料減税の賃金帰着・長期労働反応（2026-09-24.5）

## 修正した問題

旧15年試算は、社会保険料の本人・事業主配分を50%ずつに分け、本人分だけを家計の直接効果へ反映していた。事業主分は法人減税の代理マクロ反応へ接続する一方、賃金への転嫁と追加的な労働反応は初期0。さらに5年目の公表反応をGDP・貿易・雇用・金利とも延長していた。これは社会保険料減税の長期実証結果ではない。

今回、継続する所得の帰着と長期労働反応を明示し、公表期間後の全政策共通の接続条件を編集可能にした。特定政策が必ず最適になるように係数を合わせていない。

## 研究が示す範囲と中心条件

- [小林ほか・RIETI 13-E-067](https://www.rieti.go.jp/jp/publications/nts/13e067.html)：日本の企業データで健康保険料増と雇用構成を分析。全体の雇用量効果は有意でなく、企業属性で異なる。関連研究の賃金への帰着も論じる。
- [児玉・横山・RIETI 17-E-093](https://www.rieti.go.jp/jp/publications/rd/119.html)：2003年の総報酬制導入を分析し、雇用人数・時間・年収が異なる方向へ反応することを示す。保険料増の局所効果を全国一律減税へ符号反転するだけでは不十分。
- [Saez・Schoefer・Seim（2019）](https://www.aeaweb.org/articles?id=10.1257/aer.20171937)：スウェーデンの若者向け事業主保険料減税で、対象年齢と比較年齢の賃金差に効果が見られず、雇用率は2〜3ポイント改善。企業内の利益分配による広い賃金上昇もある。対象限定政策であり、日本全国の雇用弾力性を直接与える研究ではない。
- [Chettyほか・NBER 16729](https://www.nber.org/papers/w16729)：労働供給の研究整理の補償弾力性は時間0.3・参加0.25。所得効果を含む日本全体の減税反応とは異なるため、その数値を直接採用しない。

数値は `INSURANCE_DEFAULTS` に集約する。次は研究で確認した機序を使った感度の中心であり、メタ分析で推定した日本の係数ではない。

| 条件 | 中心 | 慎重 | 強め |
| --- | ---: | ---: | ---: |
| 事業主軽減の賃金転嫁率 | 50% | 25% | 75% |
| 賃上げの手取り残存率 | 70% | 70% | 70% |
| 調整年数 | 5年 | 5年 | 5年 |
| 時間弾力性 | 0.10 | 0.05 | 0.20 |
| 参加弾力性 | 0.05 | 0.025 | 0.10 |
| 残余雇用コストへの雇用弾力性 | 0.20 | 0.10 | 0.30 |

「追加反応なし」も選べる。これらは確率や信頼区間ではなく、複数の未推定条件を同時に動かす比較例。「強め」で全指標が必ず改善するとは限らない。賃金転嫁を増やすほど企業に残るコスト軽減は減る。

## 帰着と家計

当年有効な減税額をB、本人配分をs、賃金転嫁率をw、調整年数をAとする。

```
本人軽減 = B × s
事業主軽減 = B × (1−s)
賃上げ = 事業主軽減 × w × min(1, 政策開始からの年数 / A)
残余コスト軽減 = 事業主軽減 − 賃上げ
手取り賃上げ = 賃上げ × 手取り残存率
```

本人軽減＋賃上げ＋残余コスト軽減＝総減税額。一つの軽減を賃金と雇用コストへ二重に全額計上しない。同じ設定の政策を分割しても合算結果は同じ。終了後の賃上げ・軽減は0で、過去の減税を資産として蓄積しない。これは賃金硬直性まで推定した終了モデルではない。

所得分布では手取り賃上げを就労世帯の推定社会保険料に比例配分し、退職世帯には配らない。労働所得と世帯構成の同時分布がないための代理配分。本人減税の既存配分方法は維持する。静的な2024年所得・価格・人口構成を使い、一般的な将来賃金、雇用者数、物価による所得分布変化は加算しない。相対的貧困線は中央値から再計算されるため、手取りが増えても相対的貧困率が上がる場合がある。

手取り残存率で差し引いた税・保険料と企業利益減による減収の差は未校正。家計への帰着比較には使うが、財政へ追加税収として別加算しない。所得分布への帰着から消費乗数を新たに足すこともしない。

## 長期労働反応

公表期間H（EF2026は5年、ESRI2022は3年）までは、追加の専用労働反応を0とする。その後 `ramp = min(1, (年−H)/A)` で立ち上げる。公表反応に含まれる雇用等を短期から重ねないための接続仮定で、観測された調整速度ではない。

```
手取り比 = 1 + (本人軽減 + 手取り賃上げ) / 基準手取り労働所得
費用比 = 1 − 残余コスト軽減 / 基準総雇用コスト
時間倍率 = 手取り比 ^ (時間弾力性 × ramp)
参加倍率 = 手取り比 ^ (参加弾力性 × ramp)  # 参加率100%で制限
企業需要倍率 = 費用比 ^ (−雇用弾力性 × ramp)
追加雇用倍率 = min(参加倍率, 企業需要倍率)
生産へ使う労働倍率 = 時間倍率 × 追加雇用倍率
```

所得・雇用コストの分母は名目GDPに対する既存の40%・55%という換算仮定で、経済成長と物価上昇に合わせて増える。毎年の減税額は名目固定なので相対的効果は薄くなる。GDP比固定の恒久料率改革とは異なる。

生産へ使う労働を既存の生産関数に一度だけ渡す。TFPには変換せず、設備や電力が制約ならGDP効果が小さくなる。雇用者数は新規参加と企業需要の小さい方に制限し、両者を足さない。既存の共通弾力性を非ゼロにした項目は専用の対応反応を0にして二重計上を防ぐ。共通感度は従来の短期・潜在供給への接続なので、専用長期経路と同じ動作ではない。

出生の手取り所得経路にも賃金転嫁後の純額を渡す。出生の弾力性は既存の人口動態条件に従う。主試算と最適化は同じ `simulate`、`povertyScenario` を利用する。

## 全政策共通の公表反応の終端条件

`macroTailYears` は初期5年。公表最終年Hを超える年tで、公表反応に `max(0, 1−(t−H)/macroTailYears)` を掛ける。0なら旧来の末尾据置。5年で消えるという実証推定ではなく、短期モデルを15年へ無期限外挿しないための比較条件。

GDP・輸出入・物価水準・雇用・参加・時間・為替・金利を共通で扱う。利払いだけを小さくする変更ではない。消費税の機械的な直接価格効果は分離して継続させる。減税・支出の当年額、手取りの直接効果、教育等の別途設定した供給経路も消さない。

金利は借換・新規発行にだけ適用し、既発債のクーポンを途中で書き換えない。基準金利・外生金利ショックは残る。累積債務が増える財政費用も残る。債務のリスクプレミアムはこの仮定から推定できず、金利ショック等で比較する。短期金融引締めが解消する一方、物価「水準」も基準へ戻すので、途中のCPIに逆向きの変化が出ることがある。

主画面の15年試算は上記の共通接続を使う。その先の `longRunScenario` は引き続き利用者が指定した成長率・物価・金利・実現率を使う別シナリオで、主試算の完全な再現ではない。初期の公表反応5年解消という方針は揃えたが、起点や終端条件を混同しない。
