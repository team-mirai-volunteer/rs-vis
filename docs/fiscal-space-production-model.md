# 生産関数と政策供給の接続（2026-09-15.5）

政策の投入変化を `policyProduction` に集約し、短期の潜在GDP・最大GDP、追加1兆円の供用開始時比較、長期シナリオで共通に使用する。旧 `supplyResponse` / `supplyTotal` は出典係数を解釈する参照換算用で、実際の潜在GDPへ直接加算しない。

## 通常稼働と最大稼働

初期最大投入を `x0`、初期TFPを `A0`、選択関数を `F`、基準潜在GDPの経路を `Yb(t)` とする。関数の同次次数を `d`（通常は1）、`q=[A0 F(x0)]^(1/d)` とし、通常稼働の初期投入を `x0/q` に校正する。初期労働生産性は有効労働に含める。

- 政策後の最大投入：`x(t)=x0 × 政策別投入倍率`
- 通常稼働の潜在GDP：`Yb(t) × A(t) × F(x(t)/q)`
- 最大稼働のGDP：`Yb(t) × A(t) × F(x(t))`

初期潜在GDPは全モデルで一致する。政策の投入変化は関数ごとに評価され、レオンチェフでは非拘束の投入を単独で増やしても供給能力は増えない。不足投入を増やせば、次の投入が拘束するまで増える。潜在GDPの増分をさらに最大GDPの基準へ掛けて二重計上しない。

通常稼働を初期投入構成の比例利用とみなす校正であり、実際の設備稼働率・労働時間・参加可能人口を組み合わせた潜在GDP推定ではない。投入指数も仮定である。コブ＝ダグラスは中間財を含まないため、代替関係以外に投入範囲も異なる。

## 投入への換算

名目支出は支出年の期首価格で実質化し、供用遅れ・減耗・寿命・追加性を各世代に適用する。短期終了後の支出には長期物価経路を使い、過去の購入量を変更しない。

| 経路 | 生産関数へ渡す変化 |
| --- | --- |
| 公共投資 | 同じ資本の残存額を合算し、参照弾力性0.122等を固定の資本弾力性0.35で有効設備指数へ換算 |
| 研究 | 残存研究費×収益係数をTFPへ換算 |
| 教育・保育 | 就学・利用人数から追加の有効労働を計算 |
| 税・社会負担の軽減 | 仮定した労働時間・参加の反応を有効労働へ反映。全モデル共通の労働倍率の0.5乗は使わない |
| 産業事業 | 純稼働寄与を固定の参照資本弾力性0.35で設備指数へ換算 |
| 発電・送電網 | 重複と運転費を控除した燃料節約等を固定の参照エネルギー弾力性0.15で有効エネルギー指数へ換算 |

換算は `Δx=(1+参照寄与/基準潜在GDP)^(1/参照弾力性)−1`。参照弾力性を選択モデルの値に付け替えて出力効果を固定することはしない。公共資本は同一の供給条件の残存額を合算してから換算し、その後に生産関数を適用する。異なる支出期間で資本を分離しない。

発電の確実供給GWが設定されている場合、燃料節約からの有効エネルギー増分を、確実供給GW／初期確実供給GWの増分で制限する。両方を別便益として足さない。確実供給が未設定の場合は金額からの換算にとどまる。全国の投入産出・設備・電力需給を実測校正した係数ではなく、比較のための橋渡しの仮定である。

短期GDPは公表需要反応を使い、供給能力を上回る部分だけを抑制する。投資供給を短期GDPへ自動加算しない。事業の直接貿易は需要経路で一度だけ実現させる。長期の供給便益は選択関数による通常稼働能力の差に実現率を掛けるため、非拘束投入の増加から便益が発生しない場合もある。

## 稼働率による物価補正

圧力関数を `C(u)=[max(0,min(1,u)−u0)/(1−u0)]²` とする。追加価格水準は次式。

`s × { [C(政策後需要/政策後最大能力)−C(政策なし需要/政策なし最大能力)] − [C(参照政策需要/参照最大能力)−C(政策なし需要/参照最大能力)] }`

参照政策需要は政策なし需要＋同じ公表反応・事業需要。参照最大能力は `Yb(t) × referenceCapacityRatio`。既定値は `s=0.005`、`u0=0.85`、`referenceCapacityRatio=1.10`。すべて未推定の変更可能な仮定で、元の公表モデルの稼働率や価格式を同定したものではない。稼働率と潜在GDP・インフレを結ぶ実証モデルの例は [IMF: Estimating Potential Output with a Multivariate Filter](https://www.imf.org/en/publications/wp/issues/2016/12/31/estimating-potential-output-with-a-multivariate-filter-24493) にあるが、この実装の係数の出典ではない。

政策による混雑の全量を公表物価反応に加えず、参照条件からの増分差だけを使う。価格水準に一度加え、前年比へ変換する。政策なしと参照能力に一致する場合の補正は0。供給拡大・余力・政策終了時の需要減により補正が負になることもある。強度0で公表反応だけを確認できる。二重計上回避はこの条件付きの差分設計によるもので、元モデルとの厳密な構造一致を保証するものではない。

## 検証

関連テストは、レオンチェフの不足投入の交代、CESの代替、初期潜在GDPの校正、供給の二重計上防止、確実電力の上限、支出年別価格、長期・供用開始時の生産関数の一致、政策なし・参照能力での価格補正0、天井未達でのCPI差を確認する。

15兆円配分例では、年5に共通の研究TFP効果だけが残るため潜在GDP効果は同じになる。公共投資を追加すれば、非拘束の設備増を吸収できないレオンチェフと代替を認めるモデルで供給効果が分かれる。結果の差を強制する機能ではない。
