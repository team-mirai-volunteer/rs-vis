CPI出典：[総務省2024年平均](https://www.e-stat.go.jp/stat-search/file-download?fileKind=2&statInfId=000040263552)、[2026年7月冊子・表3](https://www.stat.go.jp/data/cpi/sokuhou/tsuki/pdf/zenkoku.pdf)。コアコアは生鮮食品及びエネルギーを除く総合で、加工食品を含む。「食料」は生鮮食品、酒類、外食を含む。将来の食品・コアコアCPIは推計せず、総合CPIの制約にこの観測値を代入しない。

食料自給率出典：[農水省2025年度結果・過年度表](https://www.maff.go.jp/j/press/kanbo/anpo/260807.html)。カロリーは供給熱量ベースで、別指標の摂取熱量ベースと区別する。生産額自給率は国内価格上昇でも上がり、物的供給能力の増加とは限らない。

輸出139.4023兆円・輸入145.0667兆円は両版とも2024年の財・サービスのSNAフロー。基準値、年別結果、年次推計表に両方表示。将来経路には公表マクロモデルの政策に対する輸出反応を追加した。分野固有の輸出・国内代替は事業別の条件付き試算で別表示する。

冒頭のGDPギャップには短期最大GDPの基準値も併記。公表推計と符号を統一し、`(実際−最大)/最大` とする。最新優先の初期値では約−6.76%、2024年版では約−7.41%。初期入力・年次表・結果も同じ符号に修正し、通常のGDPギャップは `(実際−潜在)/潜在`。マイナスが不足、プラスが超過。最大生産能力は投入量から計算した仮定値であり実測ではない。

債務比較は[OECD経済見通し118・付表36](https://www.oecd.org/content/dam/oecd/en/topics/policy-sub-issues/economic-outlook/eo-dec-2025/EO118_Annexes_E.pdf)の2024年欄：OECD公表集計111.2%、同定義の日本222.0%。時価等の定義差があるためモデルのIMF額面総債務と直接差し引かない。2025年以降の予測値は採用しない。付表37のユーロ圏平均をOECD平均と取り違えない。純債務と同じ控除資産範囲のOECD平均、食料・エネルギー自給率の同一定義・同年のOECD全体平均は未取得。確認できた主要国だけの平均で代用せず、画面にも未取得と表示する。

切り替え時は経済状態（GDPギャップ、初期CPI、建設利用率、確実供給）を選択先の初期値へ戻し、政策・ショック・閾値を引き継ぐ。「初期条件に戻す」は選択中のデータ版を保ったまま操作をリセットする。年0は選択した初期状態、年1以降は経過年であり、最新版を2024年の実績と呼ばない。

公表GDPギャップは（実際−潜在）÷潜在。モデルの操作値・余力は（潜在−実際）÷潜在なので、＋0.7%を−0.7%の余力として取り込む。潜在GDP＝初期実質GDP÷1.007。GDP水準は2次速報、GDPギャップは最新公表の1次速報後推計という公表時点の違いを注記する。

実質GDPは選択した初期状態の価格で名目GDPと等しく正規化する。最新版では2026年4〜6月期価格であり、公式の2020年連鎖価格の実質GDP額599.0兆円とは別。初期成長率は前期比の実質0.4%・名目1.3%を `(1 + 前期比)^4 - 1` で年率換算する参考値で、将来成長率の仮定には流用しない。四半期の季調年率額を2026年通年の実績と表示しない。

更新を保留する項目も明示する。

- 財政は歳入・歳出・利子・資産との整合性を優先し、一般政府の2024年の一式を継続採用する。2026年1〜3月期の四半期債務等は公表されているが、最新期の歳入・歳出が同時に揃うわけではない（[内閣府 SDDS Plus](https://www.esri.cao.go.jp/en/sna/sddsplus/sddsplus_top.html)）。最新版の財政/GDP比は2024年の財政額÷2026年4〜6月期のGDP年率であり、同一時点の公表比率ではない。予算・予測を実績に代用しない。
- SNA対外フローは、輸出入・所得・移転・経常収支の一式が揃う2024年の勘定体系を維持する。最新の四半期輸出入や国際収支統計の月次フローへの一部置換は行わない。
- エネルギー需給の最新確報は2024年度。エネルギー輸入費も2024年の概算を維持する。

CPI総合は初期インフレ率のスライダーで変更できる。将来の基準インフレ率2%、前年の乖離の持続率25%は別のモデル仮定である。コアCPIは初期状態の参考指標で、総合CPIの操作とは連動しない。

## 計算への対応

- 財政額は同じ資料のGDP比×GDPで円換算する。丸め済みの総収入と内訳との差はその他の非利子収入へ含め、会計恒等式を維持する。
- PB＝税・社会負担収入＋その他非利子収入−非利子支出。借入＝−PB＋支払利子−受取利子＋SFA。GFNはSFAを除く借入に満期元本を加える。
- 債務恒等式の実効金利は純利子（支払−受取）÷期首債務。負担率の「利払い/GDP」「利払い/税・社会負担収入」は支払利子を使用する。
- 総債務は連結・額面ベース。`financialAssets` は純債務の控除対象資産（総債務−純債務、GDP比72.8%）で、株式等を含む金融資産総額119.6%ではない。流動資産は同資料の現金・預金20.0%。
- 実質GDPは選択した初期状態の価格に正規化するので年0で名目GDPと等しい。2024年版は2024年価格。2020年連鎖価格の実質額ではない。
- 一次エネルギーは国内供給を100とする指数。海外依存分＝100−16.3であり、輸入の物理量の実測ではない。
- 輸出入・所得収支は同じSNA表で揃える。SNAの経常対外収支は国際収支統計の経常収支と異なる。NIIPは財務省の国際収支統計を使用し、将来はSNA経常収支を累積する近似。評価替え・両統計の調整は行わない。

## 残る仮定

乗数・労働反応の変更は [校正の監査記録](fiscal-space-calibration.md) を参照。公表モデルの反応を再現する比較条件と、政策固有の未同定部分を区別する。

将来の成長率1%・インフレ2%・借換金利2%、期待インフレ、賃金・労働時間、設備・労働等の生産投入指数、産業利用率、確実電力供給・ピーク・再エネ容量、必需輸入費、政策乗数・効果、閾値はモデル仮定。債務ポートフォリオは実績の総額と利払額を満期1〜10年へ均等配分した仮定で、実際の償還予定ではない。

初期値を実績に置き換えても政策効果や財政余力の推計精度を実証したことにはならない。出典表は「公表実績」「実績から換算」「推計」「仮定・設定」を区別し、基準から変更した数値には元の出典を残して「仮定・設定」と表示する。

検証は `npm run test:fiscal-space`、`npx tsc --noEmit --incremental false`、起動したアプリに対する `npm run test:fiscal-space:browser`。基準値、単位・出典、財政・対外収支の整合、受取利子、操作後の表示とリセットを確認する。
