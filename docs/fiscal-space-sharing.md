# 条件・価値観の共有URL

共有ボタンは `#scenario=s1.<base64url>` を生成する。設定を省略せず、固定した基準値との差分を JSON → gzip → base64url に変換する。圧縮・復元はブラウザ内で行い、外部の短縮URLサービスやサーバーへの保存は使わない。

`client/lib/fiscal-share-base-v1.json` は s1 形式の一部であり、初期値の変更に合わせて更新してはいけない。基準値を変更する場合は新しい形式を追加し、s1 の復元処理を残す。モデル版は圧縮データ内に別途保存し、復元後に既存の移行・入力検証を通す。

差分は `[キーの配列, 値]`。値の省略は項目の削除を表し、null・0・false と区別する。配列は全体を置換する。復元時は展開後のサイズ、差分数、パスの深さ、危険なキーを検証する。

従来の JSON を直接含む `#scenario=` URL も読み込める。`panel=optimization` は価値観パネルを開く指定として引き続き使用する。計算結果自体は保存せず、受信時のモデルで再計算する。
