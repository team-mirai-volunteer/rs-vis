# 5年の政策比較と長期投資の年間効果（2026-09-15）

主表は1・3・5年のGDP・CPI・輸出入・国内代替・貿易収支・債務を比較する。経済財政モデル2026年度版は公表期間5年、短期日本経済モデル2022年版は3年に表示・制約評価を限定する。後者の主表5年欄は未推計。状態遷移・選択年の指標・借換比較にも10年の総合予測を表示しない。5年を超えて便益が出る投資は、稼働開始と年間効果の別表に残す。

経済財政モデルの1年限りの政府支出には、公表資料の表①を直接使用する。GDPの反応はGDP比1%の追加に対して1.08、−0.10、−0.20、−0.21、−0.14%。継続支出・税の有限期間変更は従来の継続実験からの差分近似であり、公表モデル全体を再推定したものではない。政策固有の供給・事業条件も別途仮定を含む。

## 計算と重複回避

以下の産出係数は参照換算用。モデル2026-09-15.5から、実際の潜在GDP・長期供給・供用開始時比較は投入変化を選択した生産関数へ渡して計算する。[現行の数式と換算仮定](fiscal-space-production-model.md) を参照。

各支出を政策なしの物価経路で実質化し、支出年別に供用遅れ・寿命・減耗を適用する。公共資本は `Y*[(1+ΔK/K)^α−1]`、研究は残存研究費×収益係数、教育・保育は対象人数→就労・有効労働→労働分配率×1人当たりGDPで換算。教育・保育の有効労働には就業者の10%の上限を置くが、これは対象人口・利用可能な施設数の推定ではない。全国の保育職員・教育供給・立地制約は未校正。

研究成果の商業売上を入力した場合は、研究費の生産性モデルを停止し、事業モデルだけを使う。手入力の旧生産性係数と新供給モデルの重複指定はエラーにする。送電網は燃料節約を国内代替へ換算し、輸入・国内保守費と追加再エネとの便益重複を控除して、貿易・供給へ一度だけ反映する。旧供給ストックへの再加算はしない。計算条件と電源ミックスは [送電網の輸入代替と電源ミックス](fiscal-space-power-mix.md) を参照。

短期公表モデルには公共投資等の供給効果が含まれ得るため、新供給量を短期GDPにそのまま加算しない。期間内の潜在GDPに供給能力を反映し、実現GDPへの追加は抑える。内部計算に残る公表期間後の実現経路は主画面の予測に使わず、別表は稼働開始時の供給能力を示す。

マクロ・財政枠には基準成長率・基準物価の仮定が残る。評価期間は既定5年、短期モデルは最長3年とし、その先の財政持続可能性を保証しない。医療・防衛・現金給付・消費税は政策設計なしに供給の符号・量を決められないため、未推計を数値ゼロとして表示しない。

## 表示

一覧性を優先し、比較表では国内代替・貿易収支・債務GDP比・資源需要・単独の年間上限も列として常時表示する。年次推移も財政・貿易を含めて一覧表示。金額は各セルにも「兆円」を付け、画面が狭い場合は表内を横スクロールし、政策名・年の列を固定する。展開欄は計算条件と長期寄与の解釈に限定する。

国内代替も1・3・5年の実現額を表示する（初期年価格、兆円/年）。半導体は初回支出が年1、稼働開始が年4。そのため1・3年はゼロでも5年には値が出る。太陽光は年3、水力・送電網は年6から稼働する。代替経路が未設定の研究等は「未推計」とし、供給GDP効果をそのまま輸入代替に換算しない。原子力の輸入費は0.95円/kWhという仮定で初期化し、利用者が空欄にすれば未推計へ戻る。置換率ゼロ等を明示した事業の計算結果ゼロとは区別する。

長期投資の別表は、追加1兆円が設定した稼働条件に達する最初の年の、年間供給能力・直接貿易寄与を表示する。公共投資は年3、研究・半導体は年4、教育は年5、送電網・水力は年6、新設原子力は年11が初期条件。効果期間も表示する。稼働後は減耗があり、その値が全期間続く意味ではない。世界需要や将来の景気を予測せず、既存投資と追加投資の供給・輸入代替上限を共同適用した差を計算する。差引輸入＝稼働後輸入原価−国内代替、貿易収支＝輸出−差引輸入。すべて初期年価格で、建設費の回収や投資全体の収益率ではない。

公共投資・研究・教育等の供給量の増加だけから、輸出向け販売、輸入原価、国内の輸入置換を一意に分解できない。事業化条件がない政策は稼働後の直接貿易を「未推計」とし、全国の輸出入/GDP比による機械的な補完はしない。年間の貿易収支は国富そのものではなく、国内資本・対外所得・資産評価も別途必要である。

グラフの縦軸は各目盛りに「兆円」を付け、年0から公表期間の終わりまで表示する。3年支出の政策が4年目に終了すると需要が剥がれることと、投資の供給効果が残ることを説明する。率の増減はユーザー指定の%表示に統一し、2%→3%は+1%と表示する旨を明記（相対変化率ではない）。
