# 全シナリオ共通の電力・火力燃料経路

追加発電を選んだ政策だけでなく、政策なし・減税・給付・産業投資・限界財政枠の探索・ショック比較にも同一の電力需要経路を適用する。入力は `parameters.electricity` に集約する。

## 条件と根拠

- 2024年度の発電量991.1TWh、火力割合67.5%：[経済産業省の確報](https://www.meti.go.jp/press/2026/04/20260414001/20260414001.html)。エネルギー実績を継続採用する最新データ版にも同じ基準を用いる。
- 電力量増加率0.5%/年、ピーク需要増加率0.4%/年：[OCCTO 2026年度需要想定](https://www.occto.or.jp/assets/news/juyousoutei/260121_juyousoutei_r1.pdf)。2025〜2035年度の平均伸びを参考にした一定率のシナリオ。使用端の伸びを総発電量へ適用する近似で、公表年度別経路の再現ではない。参考資料は2026年1月21日公表。
- 非化石発電量の年減少率、政策以外の既定計画による年間追加発電量は初期値0。廃止・再稼働・改修計画を校正済みという意味ではない。追加計画は各年に発生する年間発電量の増分を積み上げ、短い評価期間では減耗しない仮定。
- 火力燃料輸入費9円/kWhは変更可能な仮定。売電価格や国内の保守費を含む発電原価ではない。個別電源の火力置換単価とは別入力で、異なる燃料を置き換える場合に対応する。

## 計算と会計

需要電力量 `D(t)=D0×(1+g)^t`。追加政策なしの非化石発電量 `N(t)=D0×(1−火力割合)×(1−減少率)^t＋既定追加量×t`。必要火力発電量 `F(t)=max(0,D(t)−N(t))`。増強しない場合の燃料輸入増減 `B(t)=(F(t)−F(0))×10^9×輸入単価`。

共通の燃料増減は、政策の影響を含まない基準物価指数（当年期首、年1は1）とエネルギー価格ショックで名目化し、全政策のエネルギー輸入費に加える。CPIへの追加圧力には共通額の前年差を用い、毎年同じ水準差をインフレへ重ねない。

総輸入の基準は従来GDPの名目成長率で延長していたため、その中の基準火力燃料額の成長部分を除き、明示した火力経路に置き換える。具体的な補正は `F(0)×10^9×単価×(共通物価指数−一般輸入の名目成長倍率)`。燃料増減を一般輸入成長に重ねて二重加算しない。財の収支・必需輸入・経常収支にも同じ外部エネルギー費を反映する。

個別政策の発電・送電網の節約は従来の事業経路で計算し、共通経路に残る火力燃料輸入額を上限として一度だけ控除する。火力残高がゼロなら、輸入代替をそれ以上計上しない。輸入単価が電源別に異なる場合も金額上限で制約するが、地域・時間帯・燃料別の運転モデルではない。

ピーク需要は共通増加率で増え、確実供給容量が自動的に増えることはない。燃料を輸入すれば発電設備不足が解消するわけではなく、既存の電力制約で不足を検出する。火力増設費、火力廃止、追加政策別の電力需要や省エネの校正は未実施。一次エネルギー指数は発電量から再構築しないため、輸入費と物量自給率を同一の推計精度とは扱わない。

## 表示と検証

1・3・5年の共通需要、未増強の火力増減、共通燃料輸入増減、現在の政策による稼働時輸入削減、その差引を常時表示する。これは燃料経路の内訳であり、貿易収支全体や政策の総費用ではない。共通額は限界政策比較の差分では相殺されるが、輸入・物価・制約の絶対経路には残る。

全政策（住民税減税を含む14政策）と政策なしで年1の共通輸入増が等しく一度だけ入ること、需要減・非化石減少・既定追加・燃料ショック、代替の火力残高上限をテストする。公表マクロ反応の固定価格再現テストでは、追加の共通需要増を0にして公表実験を分離する。
