# 住民税減税の実装範囲

政策ID `resident-tax` を所得税減税の隣に追加し、操作パネルでは「ほかの8政策を追加する」に含める。初期の追加額は0円、継続方法は恒久。年間減収額の直接入力・スライダー、継続方法と年数の変更、政策比較、単独上限、貿易経路一覧に対応する。

個人住民税の所得に比例する負担軽減という比較条件。本人の手取り増・労働時間・参加率に対する入力済みの感度を適用し、所得税と社会保険料本人分と合算する。事業主分には入れない。減税期間が終了したら直接の手取り増・就労感度は終了する。

需要乗数、物価、輸出入などは選択モデルの個人所得税の年次反応で代用する。住民税固有の実証推計ではない。地方を含む一般政府の税収から入力減収額を一度だけ控除し、政府支出として計上しない。

均等割・非課税判定・所得階層別設計・前年所得課税や徴収の時間差・自治体別の財政、国からの補填・地方歳出の変更は未モデル化。所得税減税と異なる効果を恣意的に付けず、この代用範囲を政策入力と乗数説明に明示する。
